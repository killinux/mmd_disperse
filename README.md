# mmd_disperse

Blender 插件：用几何节点给 MMD 模型做「纳米战衣」式变身／换装。
变身可以从球形扩散、沿身体表面流动或上下扫描，旧服装可以收缩消失，也可以碎成光尘、花瓣、蝴蝶飞走；
新服装可以先以全息投影出现或一块块飞来装上，旧服装可以像装甲一样整块弹开，边界也可以做成闪烁错位的故障风，
还有魔法少女式的光剪影、缠绕手脚的光带，收尾时整身闪光或一道光扫过全身，还可以全屏闪白；
新服装也可以先长成深色内衬、最终外观跟在后面，切口处的内部可以发光。
1.6 加了毒液式的黑色共生体（皮下黑血管、爬在身上的触手、拉丝的黏液）、假面骑士 Build 式的前后两半夹合、
Decade 式的残影汇聚、冰封碎裂、燃烧成灰、方块消散、金币迸发，故障风可以卡音乐节拍。
1.7 加了魔形女式的鳞片翻转（每片鳞片一面是旧服装、一面是新服装）、毒液触手间的蹼和银色的液态金属（T-1000）、
透明的玻璃冰和整身冻住后一起碎开，线框、边缘、收尾闪光和粒子也都能卡音乐节拍。主面板的「预设」一键套用十八种风格。
模型跳舞、整体移动或转圈时也能用：变身波纹、光剪影、光带和毒液触手都贴着身体走，碎片、装甲大块、粒子、新服装飞来的零件和收尾的星星
都可以留在原地，风向固定在世界里。

**效果展示页**：[docs/showcase.html](docs/showcase.html)，二十九段演示视频，每段附带在插件面板里手动做出同样效果的步骤。
用浏览器在本地打开；视频在 `test_output/`（渲染结果不进 git），没有的话先用下面「高清演示渲染」的命令渲染。

技术来自 B 站视频 [【中文配音】一秒换装？用blender几何节点制作蜘蛛侠变身动画](https://www.bilibili.com/video/BV1Yd4y1X7eR/)
（李先生的元宇宙 配音，原作 Hell FX Learn，YouTube `-nAK7OidJFo`）。插件把视频里手搭的节点树用 Python 自动生成，并针对 MMD 模型做了适配。

## 视频步骤 → 插件实现

| 视频里的做法 | 插件里的对应 |
| --- | --- |
| 球形空物体当遮罩，`Object Info` 取位置和缩放 | `MMD Disperse Mask` 空物体，缩放 = 显现半径，自动打关键帧 |
| `Position → Distance → Compare(大于) → Delete Geometry`（0 保留 / 1 删除） | 节点组 `MMDDisperse Target`：删除球外的新服装 |
| 「Displacing Edge」：噪波纹理 + 混合 RGB 扭曲球形边界 | 节点组 `MMDDisperse Field`：噪波扰动距离场 |
| `Map Range` 做边缘梯度，乘 `Normal` 后接 `Set Position` | 「边缘外推」：边缘沿法线鼓起 |
| 第二层：两个遮罩求出边缘带 → `Triangulate` → `Dual Mesh`（六边形）→ `Mesh to Curve` → `Curve to Mesh`（`Curve Circle` 截面） | 「线框层」，和战衣在同一个修改器里用 `Join Geometry` 合并 |
| `Set Curve Radius` 用梯度控制线粗 | 线在边界处最粗，向两侧变细 |
| 输出属性 `gradient`，材质里用 `Attribute` 节点做发光 | 属性 `disperse_edge` → 线框材质 + 新服装边缘发光 |
| 原模型：`Less Than or Equal` + `Set Position(-Normal)` 收缩，再删除内部 | 节点组 `MMDDisperse Base`（旧服装处理） |
| 头部另外处理（形态键缩小塞进头盔） | 「保留共用部分」：按材质名锁定脸、头发等，始终用旧模型的 |

## 视频之外的变身方式（1.1）

参考了业内的做法（钢铁侠 Mark 50、黑豹、灭霸响指等，见 [docs/research.md](docs/research.md)），新增两块：

- **变身路径**：除了视频里的球形扩散，还能「沿体表流动」（从起点贴着身体走，可以同时从手腕、脚踝流出）、
  「从下往上扫」「从上往下扫」。生成时在两套服装合并的体素网格上求最短路径，给每个顶点算出到达距离，
  存为属性 `disperse_arrival`；遮罩空物体的缩放仍然是进度条，关键帧和调参方式不变。
  用体素是因为 MMD 网格被 PMX 按 UV 接缝拆成了几千个不相连的小块（测试模型有 6250 块），没法直接沿网格边走。
- **旧服装退场**：「碎片飞散」让旧服装在变身经过的地方碎成小片，弹出、被风吹走、打旋缩小。
  还可以同时放出花瓣、扇翅膀的蝴蝶或任意物体。碎片和粒子的位置只由「变身前沿经过多久」决定，
  拖时间轴随时正确，不用烘焙；碎片保留衣服本来的贴图颜色。新服装可以留空，整个人直接化成灰。

## 全息、故障、装甲、魔法少女（1.2）

- **全息先行**：新服装先在边界前方以半透明全息出现（横向扫描线、轮廓光、最前端一圈扫描光环），边界扫过后变成实体。
  几何节点只多存一个属性 `disperse_holo`（0 = 实体边界，1 = 全息最前端），外观在材质里注入的一层混合着色器里完成。
- **故障风**：边界附近的一段里，身体切成水平切片，每条按「帧号 + 切片号」掷骰决定显示旧服装还是新服装，并横向错位、闪光。
  随机数在共用的 Field 节点组里算，新旧服装同一条切片只出现一件；故障带在动画开头和结尾自动收窄成零，不会多闪。
  合成器里可以再加一个按帧号驱动的镜头畸变节点做 RGB 色散（简单表达式驱动器，不需要开启 Python 自动运行）。
- **零件飞入 / 装甲弹开**：服装按 3D Voronoi 单元（静止姿态里）切成零件——一条边两侧面的单元号不同就切开
  （用「编号平方的平均 − 平均的平方 > 0」判断，靠几何节点的面→边自动插值，不需要循环）；再用 Mesh Island +
  Accumulate Field 求每块的中心、平均到达距离和朝向。新服装的零件提前起飞、带旋转飞来装上；旧服装的零件整块甩出、翻滚、下落。
- **魔法少女**：旧服装在边界到来前发光成剪影；每段手臂和腿生成一条双股螺旋曲线，按骨骼静止姿态的矩阵绑定到骨骼上（跟着跳舞），
  由一个小几何节点组按遮罩半径修剪（Trim Curve）出生长和消失；粒子新增星光。
- **一键预设**：纳米战衣 / 纳米流动 / 灰飞烟灭 / 全息扫描 / 故障风 / 装甲换装 / 魔法少女。
- 修复：Blender 4.2 起 Curve to Mesh 不再自动按曲线半径缩放截面（新增了 Scale 输入），之前线框「边界最粗、两头变细」
  在 4.2+ 上没有生效，现在把半径接到 Scale 上，和 3.6 一致。

## 收尾闪光、留在原地、跳舞和更多模型（1.3）

- **收尾闪光**：新服装完整出现的那一刻整身闪光，同时从全身迸出星星（魔法少女预设默认打开）。
  闪光和边缘发光共用属性 `disperse_edge`（存 闪光^(1/8)，材质里再 8 次方，所以亮度和闪光成正比）；
  星星和旧服装的粒子共用形状和材质，迸发分支只在闪光期间求值（Switch 的条件是单值，另一支不会算）。
- **留在原地**：碎片和粒子默认跟着身体动；勾选后，生成时把变身这段动画播一遍，记下旧服装每个顶点被边界扫到那一刻的位置
  （属性 `disperse_launch`），碎片和粒子从那里飞出，跳舞时不再跟着手臂甩。
  时刻用一个探针修改器求：它和旧服装共用 Field 节点组，算出的「年龄 = 半径 − 带噪波的距离」和节点树完全一致，
  年龄在两帧之间变号就按比例插值。不用模拟区域和缓存，拖时间轴仍然随时正确，3.6 一样能用。测试模型 100 帧记录约 8 秒。
- **骨骼不完全一样的新服装**：新服装多出裙摆、飘带之类的骨骼时，网格没法直接绑到旧骨架上。
  现在改为保留新服装自己的骨架，给两边都有的骨骼加「复制变换」约束（局部空间），复制旧骨架的姿态，多出来的骨骼跟着父骨骼走。
- **遮罩关键帧自动伸缩**：改飞行时长、粒子、收尾闪光以后，遮罩关键帧的值按比例拉长或缩短，不用重新生成（手动调过的时间点不受影响）。
- **模型缩放**：几何节点在网格自己的坐标里算，所有距离类输入按物体缩放换算（频率和密度反过来换算），
  缩小一半的模型和原尺寸的结果逐顶点一致。同时修了生成时在新服装对齐到旧服装之前就量身高的问题（旧模型缩放过时尺寸会错）。
- **跳舞测试**：用 mmd_tools 给旧模型加载 VMD（`--vmd`）验证了整套流程；另外四套模型
  （Purifier Inase、Reika、Tifa Lockhart AC、Tifa Lockhart Remake）的功能测试全部通过。
- 修复：光剪影的发光范围改成从零开始随半径长出来，第一帧不再提前发亮。

## 装甲留在原地、整体移动、光扫和闪白（1.4）

- **装甲大块留在原地**：「装甲弹开」也能勾「留在原地」。一块装甲在块内顶点的平均年龄变正时整块脱落，
  所以整块要在同一时刻定住。切口上的顶点属于两块、两块的脱落时间不同，位置按面角（corner）存（属性 `disperse_chunk_launch`）。
  探针修改器按 Base 组的切法切一次块，记下每个面角属于哪一块；播放时用 numpy 的 bincount 求每块的平均年龄，变号那一刻整块插值。
  测试里飞出去的装甲每块的形变中位数只有 0.0065（模型高 20.7），整块都没被拉变形。
- **整体移动时留在原地**：脱落位置改成按世界坐标记录。另有一个隐藏空物体「MMD Disperse Motion」记下录制时模型每帧的世界矩阵，
  节点里经由它（Object Info → 反向旋转 → 除以缩放）把世界坐标转回物体坐标。
  给根物体打位置、旋转关键帧（整个人移动、转圈）时，碎片留在空中；生成后再把整个模型挪到别处（每帧同样的偏移），碎片跟着挪，不用重新生成。
- **新服装跟随整体移动**：之前新服装只在生成时对齐到旧模型一次，旧模型的物体动画带不动它（骨架修改器只跟骨骼，不跟骨架物体）。
  现在新服装的根物体用「复制变换」约束跟着旧模型；静止姿态下的球心（遮罩）也用「子级」约束跟着模型走（不继承缩放，缩放就是半径）。
- **收尾光扫**：收尾闪光多了一种「光扫」方式：一道光带沿变身走过的路线从起点扫过全身，星星在光带经过的地方各自迸出。
  Field 节点组多输出一个不带噪波的路径距离给光带用，边是干净的；光带在收尾的前 70% 扫完，剩下的时间留给最后的星星。
- **全屏闪白**：「添加闪白」在合成器里加一个混合节点，收尾开始时把画面混向高亮白色（场景线性 6.0，经过视图变换是纯白）。
  混合系数用驱动器按遮罩缩放算，遮罩半径一过 wave 就闪，所以和收尾闪光同一个时间轴，改时长、调遮罩关键帧都跟着走；
  亮起和退掉的快慢按遮罩在那一刻每帧涨多少换算，约一帧亮起、六帧退掉，不会因为收尾很短而夹在两帧之间漏掉。只用简单表达式，不装插件也能渲染。
- 修复：留在原地把碎片挪到脱落位置以后，「动画姿态」测量空间下的距离会按新位置重算，碎片的飞行时间会乱。
  现在年龄先在身体上算好存成属性，碎片、装甲和粒子都用它，只改位置不改时间。

## 新服装也留在原地、风向固定、深色内衬和背面发光（1.5）

- **新服装的零件和星星也留在原地**：「留在原地」挪到主面板，两套服装一起记录。探针修改器多了「新服装」模式：
  顶点年龄在收尾星星出生时变正，零件年龄（按块平均）在零件起飞时变正，录制流程和旧服装共用。
  星星从出生那一刻身体所在的位置、沿那里的法线迸出；零件从世界里固定的起点飞向身体上的落点（落点跟着身体动），
  模型转圈时飞行中的零件不再跟着绕圈。起点的中心和法线是在节点里把零件临时挪回记录位置量出来的，静止的模型上结果和不勾一样。
- **记录带签名**：每份记录存下它依赖的设置（零件大小、提前起飞、光扫的时机和宽度、内衬宽度），实时同步时对不上就只丢掉那一部分，
  主面板提示重新生成。
- **风向固定在世界里**：节点里用 Self Object 取模型当前帧的旋转，把风、碎片打旋、装甲下落、零件和星星的散开方向从世界坐标换算过来；
  花瓣、蝴蝶、星星的朝向也按世界摆正（实例绕各自位置按模型旋转的逆转回去）。模型转身时风还是往同一边吹。
- **深色内衬**（Mark 50 式的多层叠加）：新服装先在边界处长成一层带发光细网纹的深色金属内衬，最终外观在后面「内衬宽度」处
  沿第二道发光接缝出现。遮罩自动多长出一个内衬宽度，收尾闪光和闪白等最终外观完整后才开始。
- **背面发光**：两套服装都存一个「离切口多近」的属性 `disperse_cut`，材质里把边界附近的背面换成发光色（乘贴图 alpha），
  切开处看到的内部不再是空心的；变身过去以后，裙子内侧这类本来就看得到的背面恢复原样。
- **新预设「纳米战衣收尾」**：从胸口流出深色内衬和六边形线框，战衣在后面成形，最后光扫全身、迸出星星、全屏闪白（预设自动加闪白节点）。
- 注入材质的着色器节点按固定顺序串起来：内衬 → 背面发光 → 全息 → 边缘发光 → 输出，不管先开哪个。
- 修复：Blender 3.6 里，生成时新建的花瓣、星星形状在录制「留在原地」期间第一次被引用，之后 Object Info 一直拿到空几何，
  勾了「留在原地」就没有粒子和星星。现在录制前先求值一次。
- 修复：粒子和星星改为在挪到记录位置之前选面（面积会略变），勾不勾「留在原地」放出的是同一批。

## 毒液、夹合、残影、冰与火、卡节拍（1.6）

- **毒液共生体**（调研见 [docs/research.md](docs/research.md)「四、毒液」）：按电影里的分层来：先是皮下的黑色血管，
  然后黏液漫过身体，伸出触手、拉出黏丝。
  - **触手**：生成时在静止姿态上走线，每一步沿到达时间场往前挪一点，再从上往下打射线落到最外层表面，
    所以能跨过 PMX 拆开的几千个小块。每个点绑到所在三角形的三个顶点（重心坐标），节点里用 Sample Index 每帧取变形后的顶点位置，
    跳舞时紧贴身体。边界经过触手根部后它才伸出来，比边界跑得快，追上来的黏液再把它从根部吞回去；有分叉，尖端会抬起摆动。
  - **黏丝**：生成时找面对面、离得近的两处表面（腋下、两腿之间、裙子和腿之间），两端各自绑定；中间受重力下垂，
    拉长时变细，拉到 3 倍长就断。
  - **黏液外壳**：深色内衬多了「共生体黏液」样式：湿黑色，粗糙度有斑驳变化（DNEG 说的「半干」），边界鼓起不规则的包。
  - 触手和黏丝在一个隐藏网格（骨架）里，设置改了自动重新走线（几十毫秒）。
- **旧服装表面**（新面板）：边界到来前旧服装先变：黑色血管（毒液）、结霜（冰封）或烧焦（燃烧）。
  三种样式共用属性 `disperse_ahead`（远处 0，边界处 1），材质里注入的节点不同：
  血管是扭曲的 Voronoi 网，用噪波挑一部分，越近越粗，最后整片变黑；
  结霜是清透的深色冰面上长出羽毛状的白霜，带少量闪光；
  烧焦是一片片变黑，快到边界时裂纹发光（发光颜色），最后整片烧红。结霜时还能从衣服上沿法线长出冰晶，边界一到就碎掉。
- **前后两半夹合**（假面骑士 Build）：新服装在身前身后两个发光框里从脚往上「打印」出两半，滑进来夹合，接缝发亮；
  旧服装在合上的那一刻退场（碎片模式就是一起炸开），收尾闪光、星星和闪白也在这一刻。两半按静止姿态里身体中面切开，
  用和零件一样的「面→边平均」找切口。
- **残影汇聚**（假面骑士 Decade）：几个半透明的新服装复制品（打开全息先行就是全息）站在身体两侧和后面，从脚往上出现，
  转着向身体收拢，碰到一起时新服装出现。复制品是实例，不实化，几乎不占内存。
- **冰封碎裂 / 燃烧成灰 / 方块消散 / 金币迸发**：新的粒子形状方块、金币、冰片、余烬，加上结霜和烧焦，组成四个新预设。
  金币是金属材质，冰片和冰晶共用冰材质，颜色都跟粒子颜色。
- **故障风卡音乐节拍**：「找节拍」用 Blender 自带的 Audaspace 读音乐（文件，或视频序列编辑器里的第一条音频），
  按每半帧的响度（低音加权）找鼓点：比前后一秒内的起伏明显更大、又高于安静段的底噪，两拍至少隔 0.2 秒。
  节拍写在一个隐藏空物体的关键帧上（X = 节拍脉冲，Y = 拍数），节点组和合成器色散直接读它，不用驱动脚本：
  切片每一拍重新洗牌，拍点上跳得多、闪得多，色散在拍点上冲高。
  点击音轨上 10 拍全中、时间分毫不差；《KARA - Mister》在默认灵敏度下测出 128 拍/分，和原曲一致。
- **飞入零件在空中保持朝向**：勾「留在原地」时，零件飞行中保持起飞那一刻在世界里的形状和朝向，落地前再转成身体当前的样子，
  模型转身、跳舞时空中的零件不再跟着扭。
- 毒液骨架和冰晶形状和花瓣、星星一样放在隐藏集合「MMD Disperse Particles」里，移除效果时一起清掉；
  节拍空物体留着（它属于音乐，不属于某次变身），重新生成后还能用。

## 鳞片翻转、蹼、液态金属、透明冰、卡节拍（1.7）

- **魔形女鳞片翻转**（调研见 [docs/research.md](docs/research.md)「五、魔形女」）：《X战警：逆转未来》里
  Digital Domain 的思路是「一副牌翻过来，牌的一面是变身前的人，另一面是变身后的人」。之前暂缓，是因为两套服装网格不同，
  一张牌两面的贴图对不上。插件把一张牌拆成两半：旧服装的鳞片只翻前半个（平躺到侧立，侧立时消失），新服装同一片鳞片翻后半个
  （侧立到平躺），合起来就是一张牌翻了 180°，各自用自己的贴图。
  - 两套服装在静止姿态里按同一套 3D Voronoi 格子切鳞片（每个面看面中心在哪一格），单元编号取种子点所在的整数格（每轴 8 位，浮点里精确）。
  - 每片鳞片按种子点计时：把 Field 节点组「探测」到种子点上（球形扩散是种子点的距离加边缘噪波，沿体表和扫描是离种子点最近的顶点的到达距离），
    随机先后也按种子点取，两套服装算出来一样，不受同一格里别的部分（比如离身体远的裙摆）影响；只在边界附近一圈的副本上算，再按面的序号写回。
  - 转轴垂直于波推进的方向（干净的路径距离对位置做最小二乘），后沿先抬起往前翻，翻的时候离开表面半片鳞片高，侧立时闪一下。
  - 只有正在翻的那部分才切开：先把 PMX 的 UV 接缝按距离焊上，再按鳞片切开，一片鳞片整片翻；没翻和翻完的部分保持原样，不留切缝。
  - 测试里同一帧旧服装每片侧立的鳞片旁边，一个鳞片大小以内就有新服装侧立的鳞片（中位数 0.2～0.25，鳞片 0.52）。
- **触手间的蹼**：触手分叉的地方，主干和分支之间铺一张 6×4 的面片，自由边向里弯；每个顶点和触手一样落到表面、绑到三角形上，
  跟着触手长出来、被吞回去（骨架网格里多了面）。
- **在动作里找黏丝**：模型有动画时，生成时把变身期间的 4 帧过一遍（只算骨骼变形），在那一帧的姿势里找面对面的表面，
  两端按那一帧的三角形绑定，静止长度就是那一帧的间距。手臂贴着身体、两腿并拢的地方也能拉出黏丝，张开时被拉长、拉断。
- **液态金属**：毒液的黏液多一个「金属感」，1 再配银色就是 T-1000：血管、触手、黏丝、黏液内衬一起变成金属，
  粗糙度提到能接住灯光的程度（太光滑在暗场景里只反射黑色）。新预设「液态金属」。
- **透明的冰**：冰晶和冰片改成会折射的玻璃材质（IOR 1.31，带一点冷光）；结霜时白霜之间的冰也透光（「冰的透明度」），
  能看到下面正在长出来的新服装。EEVEE 4.2+ 用光线追踪折射，3.6 用屏幕空间折射 + Alpha 哈希；材质原来的设置记下来，移除时还原。
- **冻住后一起碎开**：旧服装新增「退场时机」：「最后一起退场」时旧服装留到变身波走完（结霜、血管、烧焦照常跟着波走），
  再一起碎开、弹开或收缩；复用夹合时「同一刻退场」的机制，遮罩自动多长出一点给碎块飞。「冰封碎裂」预设改成了这样。
- **更多效果卡节拍**：节拍单独一个面板。Field 节点组多输出一个节拍脉冲：线框在拍点上变粗变亮，新服装边缘变亮，碎片变亮，
  粒子和星星变大，收尾闪光在之后的每一拍再闪一次，光扫更亮。收尾、两半夹合、残影汇合、冻住后碎开这几个关键时刻推到下一拍
  （最多等 2 秒，提前一帧开始，正好在拍点上最亮），全屏闪白跟着一起。新预设「卡点变身」。

## 针对 MMD 的改进

- 自动识别 mmd_tools 模型（根空物体 / 骨架 / 网格都能选），跳过刚体和关节。
- 新服装绑定到旧模型骨架，两套模型跟着同一套动作走（骨骼名对不上时自动跳过并警告）。
- 默认在静止姿态（`rest_position`）里测距离，跳舞时变身波纹贴在身体上，不会因为手脚进出球体而闪烁。
- 按模型身高自动换算所有尺寸（MMD 模型常常有 20 个单位高）。
- 新服装边缘发光注入到原有材质（乘贴图 alpha，镂空处不发光）；线框不投射阴影。
- 一键 Bloom：EEVEE 4.2+ 没有内置辉光，插件在合成器里加 Glare 节点（兼容 5.x 的新合成器）。
- 一键移除，修改器、骨架绑定、材质、属性、模型位置全部还原。
- 效果本身只有几何节点、关键帧、约束和材质（加上可选的合成器节点），保存后的 .blend 不装插件也能渲染。

## 安装

支持 Blender 3.6 及以上，已在 3.6.15、4.5.10、5.1.2 上测试。两种安装包都可以在
[GitHub Releases](https://github.com/killinux/mmd_disperse/releases) 下载，也可以用下面的命令自己生成（zip 不进 git）：

- **Blender 4.2 及以上**：扩展包 `dist/mmd_disperse-1.7.0.zip`，
  用 `blender --command extension build --source-dir mmd_disperse --output-dir dist` 生成。
  安装：编辑 > 偏好设置 > 获取扩展 > 右上角下拉 > 从磁盘安装。
- **Blender 3.6 ~ 4.1**：传统插件包 `dist/mmd_disperse-1.7.0-legacy.zip`（zip 里是 `mmd_disperse/` 文件夹），
  用 `python -c "import shutil; shutil.make_archive('dist/mmd_disperse-1.7.0-legacy', 'zip', '.', 'mmd_disperse')"` 生成。
  安装：编辑 > 偏好设置 > 插件 > 安装，选这个 zip 后勾选启用。

## 使用

一步步的教程见 [docs/tutorial.md](docs/tutorial.md)，下面是简要步骤。业内其他变身效果的调研和插件的后续路线见 [docs/research.md](docs/research.md)。

3D 视图按 `N`，打开「MMD Disperse」标签页：

1. **旧服装**：变身前的模型；**新服装**：变身后的模型。吸管按钮可以直接用当前选中的物体。
   旧服装可以留空，那样新服装会从无到有地「长」出来；新服装也可以留空，旧服装直接消失。
2. **路径**：球形扩散 / 沿体表流动（出发点：只从起点 / 起点 + 手脚 / 只从手脚）/ 从下往上扫 / 从上往下扫。
   **起点**：骨骼（默认自动选「上半身2」）、3D 游标或模型中心。球形扩散时**测量空间**推荐用「静止姿态」。
3. 设置开始帧、结束帧和方向（穿上 / 脱下）。
4. 点 **生成变身效果**，拖动时间轴预览。
5. 下面的参数改了立即生效：
   - 边缘：噪波缩放 / 细节 / 强度、边缘渐变宽度、边缘外推、边缘发光、背面发光（强度、深度）
   - 线框层：六边形开关、边缘前后范围、线粗、抬升、颜色、发光强度、添加辉光
   - 旧服装处理：退场方式（收缩消失 / 碎片飞散）、碎片大小、飞行时长、风力风向、湍流、旋转、碎片发光，
     保留共用部分（材质名通配符，用 `;` 分隔，改完需重新生成）
   - 粒子：花瓣 / 蝴蝶 / 星光 / 方块 / 金币 / 冰片 / 余烬 / 自定义物体，数量、大小、飞行时长、颜色、扇动速度
   - 全息先行：范围、不透明度、亮度；故障风：范围、切片高度、闪烁频率、错位、闪光、添加色散
   - 音乐节拍：音乐、灵敏度、找节拍、卡音乐节拍（故障风、线框、边缘、收尾闪光、粒子都跟着鼓点）
   - 新服装登场：边缘生长 / 零件飞入（零件大小、飞来距离、提前起飞）/ 前后两半夹合（夹合距离）/
     残影汇聚（残影数量、残影距离）/ 鳞片翻转（鳞片大小、翻转宽度）；旧服装还可以「装甲弹开」「光剪影」，
     退场时机可以选「最后一起退场」
   - 深色内衬：样式（纳米金属 / 共生体黏液）、内衬宽度、颜色、纹路亮度
   - 毒液共生体：触手数量、长度、粗细、速度，触手间的蹼，黏丝数量，黏液颜色、黏液金属感
   - 旧服装表面：无 / 黑色血管 / 结霜 / 烧焦，范围、颜色，结霜时冰的透明度、冰晶数量和大小
   - 光带：圈数、宽度、停留、亮度；收尾闪光：整身闪光 / 光扫、时长、亮度、光扫宽度、星光数量、飞散距离、闪白强度、添加闪白
   - 留在原地（主面板）：跳舞或整体移动时碎片、装甲大块、粒子从脱落的位置飞出，新服装的零件从固定位置飞来，星星从出生的位置迸出
     （生成时记录，改了动作要重新生成）
6. 点垃圾桶按钮移除效果并还原模型。

线框层是最重的部分：边界扫过高面数区域时，单帧求值约 0.9 秒（4.5）；3.6 的几何节点更慢，测试里每帧 1.6～2.6 秒
（同时也在算两套模型的刚体物理）。碎片模式下旧服装每帧再多约 1 秒。在视口里调动画时可以先关掉线框层，渲染前再打开。

Blender 3.6 的区别：辉光用 EEVEE 自带的泛光（Bloom），线框用材质的「阴影模式：无」不投阴影；4.2 以后用合成器 Glare 节点。

## 高清演示渲染

`demo/render_hd.py` 把模型的 MMD 卡通材质换成 PBR 材质（Principled BSDF），用上模型自带、但 PMX 材质用不到的
法线 / 粗糙度 / 金属度贴图：皮肤加次表面散射，乳胶战衣用光泽 + 清漆，头发用带 alpha 的 PNG。
再加上工作室 HDRI 反射、主光 + 青色轮廓光、反光地面和缓慢环绕的镜头，渲染 1080×1920、200 帧（第 10～185 帧变身）。

```bash
blender -b --factory-startup "$D/Tifa Gantz 18 V2.blend" --python demo/render_hd.py -- \
  --target-blend "$D/Tifa Gantz 18 V1.blend" --target-root "Tifa Gantz 18 V1" --base-root "Tifa Gantz 18 V2" \
  --out test_output/demo_hd/frames --anim 1:200 --save test_output/demo_hd/tifa_suitup_hd.blend
```

材质的对应关系是按贴图文件名猜的（`xxx_tex` → `xxx_rough` / `xxx_met`，球面贴图槽里放的是法线贴图），只针对这个模型调过。
`--set 设置名=值` 可以换用新的路径和退场方式（生成前后各应用一次），例如 1.1 的三段演示：

```bash
--set path=SURFACE --set seeds=ORIGIN_LIMBS                                   # 从胸口和手脚流出
--set path=UP --set exit_style=FRAGMENTS --set particles=PETAL                # 从下往上，化成光尘和花瓣
--set path=DOWN --set exit_style=FRAGMENTS --set particles=BUTTERFLY --set particle_color=0.45,0.8,1.0  # 从上往下，化成蝴蝶
--set path=UP --set holo_enable=1 --set wire_enable=0                         # 1.2：从下往上的全息扫描
--set glitch_enable=1 --set wire_enable=0 --glitch-fx                         # 1.2：故障风 + 合成器色散
--preset ARMOR                                                                # 1.2：装甲换装
--preset MAGICAL                                                              # 1.2：魔法少女（1.3 加了收尾闪光）
--preset MAGICAL --set leave_behind=1 --vmd "回レ！雪月花.vmd"                 # 1.3：边跳舞边变身
--preset ARMOR --set leave_behind=1 --vmd "回レ！雪月花.vmd"                   # 1.4：边跳舞边弹开装甲，大块留在原地
--preset MAGICAL --set leave_behind=1 --spin 720 --spin-frames 10:120         # 1.4：边转圈边变身，星光甩成螺旋
--preset NANOTECH --set finale=1 --set finale_style=SWEEP --set finale_length=0.3 --white-flash  # 1.4：光扫 + 闪白
--preset NANO_FINALE --white-flash                                            # 1.5：纳米战衣收尾（内衬 + 光扫 + 闪白）
--preset ARMOR --set leave_behind=1 --spin 360 --spin-frames 10:150           # 1.5：边转圈边换装甲，零件从固定位置飞来
--no-base --set use_lock=0 --set path=UP --set inner_glow=1 --set layer_enable=1  # 1.5：从无到有，内衬扫描 + 背面发光
--preset VENOM --vmd "回レ！雪月花.vmd"                                        # 1.6：边跳舞边被毒液覆盖
--preset CLAMP --white-flash --angle -55 --orbit 8                            # 1.6：前后两半夹合（斜侧机位）
--preset GHOSTS --white-flash                                                 # 1.6：残影汇聚
--preset ICE / --preset BURN / --preset DEREZ / --preset COINS                # 1.6：冰封、燃烧、方块、金币
--preset GLITCH --vmd "回レ！雪月花.vmd" --music wav.mp3 --glitch-fx            # 1.6：故障风卡音乐节拍（视频再合进音乐）
--preset MYSTIQUE                                                             # 1.7：魔形女鳞片翻转
--preset VENOM --vmd "回レ！雪月花.vmd"                                        # 1.7：边跳舞边被毒液覆盖（蹼、动作里的黏丝）
--preset LIQUID_METAL                                                         # 1.7：液态金属
--preset ICE                                                                  # 1.7：整身冻成透明的冰，再一起碎开
--preset BEAT_DROP --vmd "回レ！雪月花.vmd" --music wav.mp3 --glitch-fx --white-flash  # 1.7：卡点变身
```

`--vmd` 用 mmd_tools 把舞蹈动作加载到旧模型的骨架上（新服装跟着旧骨架动）；模型是 MMD 原始尺寸时 `--vmd-scale` 用默认的 1，
用 mmd_tools 默认 0.08 导入的模型要传 `--vmd-scale 0.08`。`--spin 角度` 给旧模型的根物体打旋转关键帧（物体动画），
`--spin-frames` 是转圈的起止帧；`--white-flash` 在合成器里加收尾闪白；`--no-base` 隐藏旧模型，让新服装从无到有地长出来；
`--angle` 把镜头整体转到模型侧面（度，看前后两半夹合时用 -55，避开地面反光）；
`--music` 找这首歌的节拍（从第 1 帧开始），渲染完用 ffmpeg 把歌合进视频（`demo_v8/render_v16.sh` 里有现成的命令）。
