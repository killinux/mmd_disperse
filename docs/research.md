# 业内变身效果调研

调研时间：2026-10-02。目的：找出纳米战衣以外还有哪些好看的变身方式，看哪些能加进插件。

## 结论

业内的变身效果拆开看，都是四件事的组合：

1. **前沿怎么走**：从哪里开始、沿什么路线推进；
2. **旧衣服怎么退场**：收缩、碎掉、飞走；
3. **新衣服怎么登场**：直接长出、全息先行、零件飞入；
4. **前沿上加什么装饰**：线框、光环、电弧、粒子。

（2026-10-05 第三轮调研发现还有第五件：**什么时候、由什么触发**，比如跟着舞蹈里的拍手、转身换装，见「七」。）

（2026-10-06 第四轮调研又补上第六件：**镜头、时间和周围的世界**，比如甩镜头、定格环绕、熄灯追光、把舞台换成另一个世界，见「八」。）

（2026-10-11 第五轮调研的认识：新意从「衣服怎么变」转到了「什么东西在什么时候挡住、照到、扫过这里」，生成时逐帧采样可以做成通用模块，一次带出一整组新前沿，见「九」。）

（2026-10-17 第六轮调研的认识：观众记住的是「先挡住、再打开或放出一样东西」的那一下，要补的是一个覆盖判定，生成时算出每一帧人被挡住了多少；多套连换第一次有了节奏数据，见「十」。）

插件现在是「球形扩散 × 收缩删除 × 直接长出 × 六边形线框」。补上两块底层能力，大部分效果都能做成预设：

- **到达时间场**：决定前沿怎么走；
- **碎片运动**：决定旧衣服怎么退场。

两块都能在 Blender 3.6 里实现。

## 一、业内常见的变身方式

### 1. 纳米 / 科技战衣（插件现在做的这类）

- **钢铁侠 Mark 50**（《复仇者联盟3》，特效 Framestore）：
  - 概念设计师 Phil Saunders 的设计：纳米从胸口主反应堆和身上几个副反应堆同时流出。
  - 按人体结构分层：先铺神经和血管状的线路，再长肌肉纹理，最后堆出肌肉块和外骨骼，层与层像波浪一样叠着推进。
- **黑豹**（Method Studios）：纳米粒子从项链里生成，沿身体向下展开。
- **和插件的差距**（调研时）：只有一个球形起点，没有多起点、沿体表流动和多层叠加。
  1.1 补上了多起点和沿体表流动，1.5 补上了多层叠加（先长深色内衬，最终外观跟在后面）。

### 2. 消散 / 碎裂

- **灭霸响指**（Weta）：
  - 身体化成碎屑被风吹走，碰撞体逐帧更新，让风绕着身体打旋。
  - 先散哪里由导演定，比如蜘蛛侠「手先散，脸要留到最后」。
- **《创：战纪》derez**：碎成成千上万个立方体素，像碎玻璃一样散落。
- **《头号玩家》**：角色被击败时爆成金币。
- **二次元和仙侠常见的变体**：化成花瓣、蝴蝶或羽毛散去；燃烧成灰；冰晶长满后碎裂。

### 3. 扫描 / 全息 / 打印

- **全息实体化**（科幻片和游戏，比如《命运2》的传送登场）：先出现发光线框和扫描线，再变成实体。
- **《西部世界》片头**（Elastic）：用 3D 打印的方式逐层打印出骨骼、肌腱和肌肉。
- **假面骑士 Ex-Aid**：角色选择面板从身体穿过去，穿过的地方就变身完成。

### 4. 装甲组装（特摄 / 机甲）

- **假面骑士 Kabuto 的「Cast Off」**：外层厚装甲炸开飞走，露出里面的轻装。
- **假面骑士 Build**：前后两半装甲从身前身后夹合。
- **假面骑士 Zero-One**：机械蝗虫拆成装甲片扣到身上。
- **假面骑士 Decade**：几个全息残影汇聚到身上。

### 5. 有机 / 液体

- **毒液**（DNEG）：触手爬满全身。做法是先做一个能动画的团块绑定，伸出触手，再在上面叠多层特效模拟。
- **T-1000 液态金属**（《终结者2》）。
- **魔形女**（《X战警》）：鳞片像波浪一样翻过来，鳞片两面是不同的材质。Blender 市场上已有几何节点版本（Mystique Scales Effect，支持 3.6–5.2）。

### 6. 动画 / 风格化

- **魔法少女变身**：
  - 身体变成纯色发光的剪影，光带缠绕手脚，变出手套和靴子。
  - 按部位依次换装，周围有闪光粒子，最后定格摆姿势。
  - 《美少女战士 Crystal》第一季的变身用 3DCG 制作，观众反响一般，后来改回了手绘。
- **《蜘蛛侠：平行宇宙》的「故障」**：把画面切成格子，每格用不同相机和不同风格渲染，再拼起来。
- **闪白遮挡**：用一道强光盖住换装的瞬间。动画里最常用，也最省事。

## 二、映射到插件：两块底层能力

### ① 到达时间场：决定前沿怎么走

现在的 Field 节点组用的是「静止姿态里到球心的距离」。

- 这个距离是在静止姿态里量的，所以不会随动作变化。生成时可以用 Python 给每个顶点预先算好「前沿走多远才到这里」，存成顶点属性。
- 节点组读这个属性代替球形距离。遮罩空物体的缩放继续当进度条，关键帧、缓动、实时调参都不用改，播放时几乎不增加计算。

预计算可以支持这些走法：

| 走法 | 效果 | 对应 |
| --- | --- | --- |
| 球形 | 现在这种 | 蜘蛛侠教程 |
| 平面扫描 | 从脚到头或从头到脚 | 扫描、3D 打印 |
| 多起点 | 胸口、两只手腕、两只脚踝同时出发 | 钢铁侠的副反应堆 |
| 沿体表流动 | 从项链或胸口出发，贴着身体表面走，手臂交叉时不会直接跳到手上 | 黑豹 |
| 按部位 | 手脚先，躯干后，脸最后 | 灭霸响指、魔法少女 |

**沿体表的难点**：MMD 模型是很多不相连的零件。PMX 会按 UV 接缝把网格拆开，测试用的 Tifa 一个网格就有 6250 个零件岛，没法直接在网格上求最短路。

**办法**：把两套服装一起体素化，在体素网格上求最短路，再插值回每个顶点。新旧服装在同一个位置拿到的到达时间一致，生成时只算一次。

### ② 碎片运动：决定旧衣服怎么退场

- **做法**：把前沿扫过的面拆开（Split Edges），缩成碎片（Scale Elements）。碎片的位置只取决于「前沿扫过这里多久了」：先弹出，再顺风漂，再加噪波扰动，最后缩小消失。
- **无状态**：随便拖时间轴都对，不需要烘焙，3.6 也能用。如果要「风绕着身体打旋」这种真实感，再加模拟节点（Simulation Zone）做可选项。
  （1.3 里跳舞时让碎片留在原地，没有用模拟节点，而是生成时记录每个顶点脱落那一刻的位置，见下面的「1.3 跟进」；
  1.4 扩展到装甲大块和整个模型的移动，见「1.4 跟进」；1.5 扩展到新服装飞来的零件和收尾的星星，见「1.5 跟进」。）
- **贴图颜色白送**：碎片保留原来的 UV 和材质，颜色天然就是衣服的贴图颜色。别家把「粒子带贴图颜色」当卖点。
- **换成实例**：碎片换成实例，就是花瓣、蝴蝶、立方体素、金币，都是同一套运动。
- **按零件飞**：用 Mesh Island 找零件、用 Accumulate Field 求零件中心，就能做装甲飞入，或者 Kabuto 那种 Cast Off。

### 节点核对

在 3.6.15、4.5.10、5.1.2 里逐个创建节点确认过。

| | 3.6 | 4.5 / 5.1 |
| --- | --- | --- |
| Simulation Zone、Shortest Edge Paths、Edge Paths to Curves | 有 | 有 |
| Split Edges、Scale Elements、Mesh Island、Accumulate Field | 有 | 有 |
| Blur Attribute、Curve Spiral、Points/Mesh to Volume、Sample Nearest Surface | 有 | 有 |
| Repeat / For Each 循环、Bake 节点、Index / Menu Switch、Sort Elements | 没有 | 有 |

所以设计里不用循环，保持 3.6 兼容。

### 1.4 跟进

| 项目 | 做法 | 状态 |
| --- | --- | --- |
| 装甲大块留在原地 | 一块装甲在「块内顶点的平均年龄」变正时整块脱落，所以整块要在同一时刻记录。切口上的顶点属于两块，两块脱落时间不同，所以按面角（corner）存位置。探针修改器按 Base 组的切法切一次块，记下每个面角属于哪一块；播放时用 numpy 的 bincount 求每块的平均年龄，变号那一刻整块插值 | 已完成 |
| 整体移动模型时留在原地 | 位置改成按世界坐标记录。一个隐藏空物体记下录制时网格物体每帧的世界矩阵，节点里经由它（Object Info + 反向旋转 + 除以缩放）把世界坐标转回物体坐标。根物体做移动、转圈动画时碎片留在原地；生成后再整体挪动模型（每帧同样的偏移），碎片跟着挪 | 已完成；顺带让新服装用「复制变换」约束跟随旧模型的整体移动（之前只在生成时对齐一次，物体动画带不动新服装） |
| 收尾光扫 | Field 组多输出一个不带噪波的路径距离；光带位置 = 收尾进度 ÷ 0.7 ×（wave + 光带宽度），沿变身路径从起点扫过全身，剩下 30% 的时间留给最后迸出的星星。星星在光带经过时各自出生 | 已完成 |
| 全屏闪白 | 合成器里加一个混合节点，把画面混向高亮的白色（场景线性 6.0，经过视图变换后是纯白）。混合系数用驱动器按遮罩缩放算，和收尾闪光同一个时间轴；亮起、退掉的快慢按遮罩那一刻每帧的增量换算成约 1 帧 / 6 帧，收尾再短也不会漏帧。只用简单表达式，不装插件、不开 Python 自动运行也能渲染 | 已完成 |

另外修了一处：留在原地把碎片挪到脱落位置以后，「动画姿态」测量空间下的距离会按新位置重算，碎片的飞行时间会乱。现在年龄先在身体上算好存成属性，碎片、装甲和粒子都用它，只改位置不改时间。

原因是每加一个节点、每连一条线，Blender 都把整棵四千多节点的树更新一遍，总时间随节点数平方增长。同一个文件只搭一次。
以后可以把各项功能拆成子节点组（每组小，更新快），估计能快好几倍，留待讨论。

### 1.12 跟进

第五轮调研（下面「九」）推荐的七组里做完了六组半，同样都在 Blender 3.6 上实现，没有烘焙。先做了五项实测：
半透明的分身用「混合」并关掉背面最好（3.6、4.5 都对；「哈希」会让叠加的分身消失，叠加加背面会把头发片叠成白色）；
倒带时物理速度 1、慢放 0.25 没问题，硬切回音乐会让头发连抽三帧，快进（约 3.8 倍，物理同样加速）就很干净，物理冻住而身体在动会炸；
风力场能吹动 mmd_tools 的刚体；六个 PMX 里五个有标准的腕／ひじ／手首骨骼，英文骨骼名的按层级找；
最短边路径在 17 万面上每次 0.13～0.18 秒。

## 四、毒液（共生体）

调研时间：2026-10-04。

### 电影里怎么做

- **《毒液》（2018，DNEG）**
  - 做法：先做一个能动画的团块绑定，可以伸出触手；特效师在上面跑几十遍流体、肌肉、皮肤模拟。
  - 变身是分层的。特效总监 Paul Franklin 的原话大意：「从皮下开始，能看到黑色的血管在 Eddie 皮肤下蠕动，然后黏液漫过皮肤表面，接着是一波波的组织和牙龈那种网状结构。」
  - 质感是「半干」：湿，但不是到处一样湿，像抹开的有机物。
  - 参考了海洋生物、软体动物、黏菌、阿米巴、水螅和非牛顿流体。
- **《毒液3：最后一舞》（2024，DNEG）**
  - 皮肤先渗出黑色、整片变黑，作为底层，再往上一层层叠。
  - 特效触手能分叉再合拢，触手之间加蹼。这样改外观不用退回动画部门重做。
  - 有一个角色的触手，是用绑在头上的一根简单管道驱动特效触手的走向。
- **《蜘蛛侠3》（2007，Sony Imageworks）**
  - 黑色黏液是动画师手 K 的：每个动画师搭自己的黏液绑定，一组做主干的丝和荚，另一组再加荚，用跨度或小薄膜把荚连起来，有的带动力学。
  - 最后在 Houdini 里用 metaball 做出黏液的质感。
  - 最难的是让黏液紧贴身体：匹配移动差一点，黏液就穿进身体里看不见了。

### Blender 社区的做法

- **Ivy Generator**（Blender 自带的常春藤插件）：生成曲线，动画曲线的起止点让它「长出来」。
- **几何节点最短路**：用 Shortest Edge Paths + Edge Paths to Curves 在网格上找路径，让曲线沿路径长出来（Graphical Ninja 的教程）。他的付费版 Venom Morph System 支持 3.6+，还按这些曲线位移网格，做出大块黏液。
- **材质**：黑色 Principled，粗糙度接近 0，加一点凹凸。

### 放到 MMD 上的难点

1. 最短路要求网格连通。PMX 按 UV 接缝把网格拆成几千块（Tifa 有 6250 块），Shortest Edge Paths 走到块边就断了。
2. Ivy 生成的曲线是静止的，模型一跳舞就离开身体，正是 Sony 说的「黏液必须紧贴身体」。

### 插件里的做法

| 层 | 对应电影里的 | 做法 |
| --- | --- | --- |
| 黑色血管 | 皮下渗出、皮肤变黑 | 旧服装的材质里，在边界前方一段画扭曲的 Voronoi 细线（静止姿态坐标，贴着身体），越靠近边界越粗、越黑，最后整片变黑 |
| 触手 | 伸出的触手、分叉 | 生成时在静止姿态上走线。每一步沿到达时间场往前（推进的方向）挪一点，再从上往下打射线落到最外层表面，所以不管网格连不连通都能走过去。每个点绑到最近三角形的三个顶点（重心坐标），节点里用 Sample Index 取当前帧变形后的顶点位置，跳舞时也紧贴身体。触手在边界经过它的根部后伸出，跑到边界前面，再被追上来的黏液吞回去 |
| 黏丝 | 跨度、薄膜、牙龈网 | 生成时找面对面、离得近的两处表面（腋下、两腿之间、裙子和腿之间、手指之间），两端分别绑定。拉长时变细，中间受重力下垂，拉到 3 倍长就断开 |
| 黏液外壳 | 漫过皮肤的黏液 | 新服装的深色内衬多一种「黏液」样式：湿的黑色，粗糙度有斑驳变化，带凹凸，边界处鼓起不规则的包 |

不用模拟：拖时间轴随时正确，3.6 也能用，不用烘焙。节点里只是按索引取顶点位置，每帧几乎不增加计算。

工作量中等：一个新节点组（触手和黏丝），一个 Python 模块（走线、找黏丝、绑定），材质里加血管和黏液样式，再加一个「毒液共生体」预设。

## 五、魔形女（鳞片翻转）

调研时间：2026-10-04。

### 电影里怎么做

- **《X战警》（2000）和《X2》（2003），都是 Kleiser-Walczak**
  - 2000：演员的身体扫描做成 3D 网格，变身是两套几何体之间的 3D 变形（Maya 里关键帧加程序动画），配合 Rebecca Romijn 的特效化妆。
  - 2003：每片鳞片是带贴图和置换贴图的多边形，有一组动画循环：顶出来、翻折、颤动、躺下。
    按置换加上高光和阴影，让变形看起来有厚度，而不是贴在表面上。
  - 用贴图渐变编排身体哪一块什么时候变，变得快还是慢。
- **《X战警：第一战》（2011，Rhythm & Hues，视效总监 Greg Steele）**
  - 拍两条素材，一条是变身前的人，一条是变身后的人，两条都要手动匹配运动。
  - 鳞片从皮肤（还有头发）里冒出来，再躺下去，拼成新的表面。
  - 鳞片寿命的最后 10%～15%，躺下的过程中慢慢换成实拍素材的颜色。
- **《X战警：逆转未来》（2014，Digital Domain，视效总监 Lou Pecora）**
  - 设计思路是「一副牌翻过来」：牌的一面是变身前的人，另一面是变身后的人。不用划变（wipe），用一片片「羽片」翻。
  - David Corral 在 Maya 里做了实时绑定，可以精确控制翻牌的前沿和后沿，按镜头远近放大缩小羽片、调翻转的速度；
    羽片大小有随机变化，给动画师留出调整的余地。
  - 变成两个以上的人时，中间的溶解放在画面外。

### 放到 MMD 上的难点

一张「牌」两面要分别贴两套服装的贴图。两套服装是不同的网格：顶点、UV、材质槽都不一样，
要把一套贴图对位采样到另一套网格上，这是之前暂缓的原因。

### 插件里的做法

把一张牌拆成两半，各用各的网格：

| 半边 | 做法 |
| --- | --- |
| 旧服装 | 只翻前半个：平躺 → 侧立，侧立那一刻消失 |
| 新服装 | 只翻后半个：同一片鳞片、同一根转轴，侧立 → 平躺 |

合起来就是一张牌翻了 180°，正面是旧服装、背面是新服装，各自用自己的贴图，不用对位。要让两半对得上：

- **同一片鳞片**：两套服装都在静止姿态里按 3D Voronoi 切，每个面看面中心落在哪个单元，所以两套服装重叠的地方切出的是同一片。
  单元的编号用它的种子点所在的整数格（每轴 8 位，24 位整数在浮点里是精确的）。
- **同一个时刻**：每片鳞片按种子点计时：Field 节点组「探测」到种子点上（球形扩散是那里的距离加边缘噪波，沿体表和扫描是离种子点最近的顶点的到达距离），
  再加一点按种子点取的随机先后，两套服装算出来一样。
- **同一根转轴**：轴垂直于波推进的方向。推进方向用「干净的路径距离 × 位置」在每片鳞片上做最小二乘求出来。
  后沿先抬起，往前翻，就是 DoFP 说的前沿和后沿；翻的时候沿法线抬起半片鳞片的高度，不会插进身体。
- **PMX 的小块**：PMX 按 UV 接缝把网格拆成小块，直接翻的话一片鳞片碎成好几张小纸片。
  翻转中的部分先把接缝按距离焊上，再按鳞片切开，一片鳞片整片翻；手臂和身体侧面这种只是挤在同一个单元里、并不相连的部分，各翻各的。
- **只切正在翻的部分**：还没翻和已经翻完的部分保持原样，不会因为切开而在接缝处出现阴影。
- **光泽**：鳞片侧立时闪一下发光颜色。

测试：同一帧里，旧服装每一片侧立的鳞片，在一个鳞片大小以内都能找到新服装侧立的鳞片
（Tifa 上两者距离的中位数是 0.2～0.25，鳞片大小 0.52）。

## 七、第三轮调研：还能做哪些变身

调研时间：2026-10-05（晚）。1.9 之后分四路再找一轮：日本（特摄、动画、歌舞伎）、中国（动画、游戏、抖音和 B 站）、欧美（影视特效），以及游戏、AI 视频特效模板、VRChat 着色器和 Blender 社区。
下面只列前面各版本和「六」里都没有的，都能在 Blender 3.6 上做，例外单独说明。

这一轮最大的收获是第五件事：**什么时候、由什么触发**。前面的效果都是前沿按设好的时间走；短视频里最火的换装反过来，由舞蹈动作本身触发：拍手、飞吻、转身、手一扫。

### 大众口味：AI 视频特效模板

2024–2026 年 AI 视频 App 的特效模板（Pika、可灵、Vidu、Higgsfield、PixVerse 等）反映了大众现在爱看什么：

1. 卡通物理：充气（Pika 的 Inflate 发布时在 X 上爆红）、压扁、融化、爆开、撕开；
2. 变成玩具或别的材质：毛绒（可灵 FuzzyFuzzy）、蛋糕（Pika 的 Cake-ify）、黏土、纸片、像素、液态金属；
3. 英雄战衣：毒液、机甲、翅膀展开；
4. 换装：转圈换装、红毯换装；
5. 魔法：花开、仙子、灵魂出窍、分身。

液态金属、像素（方块）、毒液和大部分战衣插件已经有了，融化在计划里；充气、毛绒、花开、翅膀、灵魂出窍还没有，上面都列了做法。

Transition FX 是目前最接近的产品，但它给任意物体加转场装饰，不支持 3.6，也不处理「两套服装互换 + MMD 骨架」。插件的位置没有变。

### 暂不推荐、需要讨论

- **被挡住时换**（川剧变脸用扇子、袖子一挡就换；抖音的甩头变装；《龙与地下城：侠盗荣耀》里 ILM 用的「Texas switch」）：从镜头看，手、头发、裙子挡住哪里就趁那时换。
  要逐帧从镜头往每个顶点打射线，生成会很慢。先做「手扫过的地方换」。
- **来回换、多套连换**（《睡美人》里跳舞时裙子在粉色和蓝色之间来回变；抖音的多套卡点连换）：插件现在一次只处理一对服装，前沿只往一个方向走，要改架构，单独讨论。
- **三头六臂**（哪吒：用渐隐的粒子流做「似有还无」的手臂，灵感来自敦煌飞天）：要按骨骼权重复制手臂，费工。
- **剪贴拼贴**（蜘蛛朋克：身体各部分用不同帧率）、**形状轮换**（《史蒂文宇宙》重生时闪过几种旧形态）、**头发编成战衣**（猎天使魔女）、
  **蒸着后慢放**（宇宙刑事 Gavan 0.05 秒换好再慢放一遍，属于剪辑手法）：效果窄，或者不是插件该做的。
- 需要新版本：螺钿、彩虹结界的珠光用 4.2+ 的薄膜（Thin Film）更好，3.6 用色带近似；灰姑娘那种被裙摆搅动的粉尘涡流要模拟，3.6 用公式路径近似。

### 推荐下一批

「六」里还没做的五项（随机斑点、剥落卷起、融化滴落、护盾收缩、光学迷彩）仍然在计划里。和这次的新发现放在一起排，建议 1.10 先做：

1. **跟着舞蹈动作变**：拍手、飞吻、甩头触发，转身时换，手扫过的地方换。最贴合 MMD 跳舞，也是抖音、B 站最常见的换装方式，别的工具做不了。

3. **花苞绽放**：哪吒的莲花，国内观众一眼就认得。
4. **金蝉脱壳**：旧的自己定在原地，人换好衣服接着跳。
5. **冲击帧、集中线、地面冲击波**：便宜，给所有预设加力度。
6. 小项：**从腰部往上下分开**、**一件一件换**、**魂环**。

## 八、第四轮调研：还能做哪些变身

调研时间：2026-10-06。1.10 之后分五路再找一轮：
- 日本和韩国；
- 中国；
- 欧美（影视、动画、游戏）；
- 舞台、时装和短视频的镜头转场；
- 技术社区（Blender、VRChat、手游特效拆解）和 AI 视频特效模板。

下面只列前面各版本和「六」「七」里都没有的，都能在 Blender 3.6 上做，例外单独说明。
这一轮的网页搜索额度中途用完，后半程只能直接打开已知网页核对。没查透的有四块：西方动画剧集、MMD 圈的 MME、VTuber 的 3D 新衣装公开、偶像 3D 演唱会。

这一轮最大的收获是第六件事：**镜头、时间和周围的世界**。插件到现在只改人：镜头照走，舞台不变，舞蹈一直按原速跳。短视频换装、手游大招和特摄变身却大量靠这几样：
- 甩镜头；
- 定格环绕；
- 熄灯追光；
- 把整个舞台换成另一个世界。

插件知道变身的时刻，也读得到整段舞蹈，这些都能自动做。两个前提在 3.6 上实测过：
- NLA 片段的「动画化片段时间」能让舞蹈停住，再跳回音乐对应的位置；
- 刚体世界的速度能打关键帧，设成 0 时刚体停在半空，恢复后接着动。定格时头发、裙摆也能一起停住。

### 大众口味（更新）：AI 视频特效模板

2025–2026 年 AI 视频 App（PixVerse、Pika、Higgsfield、可灵、Vidu、海螺等）的特效模板又有了变化：

1. 变成收藏品：自拍变 3D 手办（2025 年 8 月 Nano Banana 带起，几周里给 Gemini 带来 1000 多万新用户、2 亿多次图片编辑），装进盒子、变成娃娃；
2. 卡通物理还在主推：压扁、挤碎、充气、融化、切蛋糕、剥开、撕开；
3. 镜头模板：子弹时间 360°（Higgsfield、可灵、Vidu）；
4. 换成玩具材质：黏土（抖音近 300 万用户参与）、乐高和 Minecraft、像素、金属；
5. 换装本身：Vidu 的 ai_outfit、outfit_show、dynasty_dress；PixVerse 的 Flora Nymph Gown（发光的线先描遍全身，停半拍，下一拍爆开成花裙）；
6. 节日：可灵 2026 马年的红包、元宝模板；剪映 2025 年的 AI 特效用了 10 亿多人次。

PixVerse 的毒液模板在社交平台播放超过 10 亿，插件 1.6 已经有毒液。AI 换装视频的主流做法是出几套衣服、用首尾帧串起来，所以「多套连换」的需求是有的。

### 需要新版本、要实测或要讨论

- **倒影先换、影子先变**：
  - 3.6 手册说 Light Path 的 Is Glossy Ray 在反射平面里有效，但另一处又说一些输出要求辐照度体积和烘焙的间接光；影子要用只投影的替身。要先在 3.6 上实测。
  - 4.2 起物体有光线可见性（相机看不见、照样投影），做起来简单得多。
- **定格和变速**：要动用户的舞蹈（放进 NLA 片段）和物理设置，移除效果时要完整还原。做的时候先在四套模型上看刚体停住、接上是不是都对。
- **Datamosh**（Higgsfield 的模板）：要逐帧累积上一帧的画面，和「拖到任意一帧都对」冲突，3.6 的 EEVEE 也没有运动矢量通道。用已有的故障风近似。
- **漫画分格**（绝区零）：每格多渲染一遍，渲染时间按格数成倍增加。
- **多套连换**：仍然要改架构，单独讨论。这一轮又多了几个出处，需求是有的：
  - 逆水寒手游的自定义变装，自动卡点、每段一套；
  - AI 换装视频用首尾帧串几套衣服；
  - 假面骑士 Zeztz 的「七変化」；
  - K-pop 的舞台混剪。
- **薄膜的珠光**（泡泡、结界的彩虹）：4.2 起的 Thin Film 更好，3.6 用色带近似。

## 九、第五轮调研：还能做哪些变身

调研时间：2026-10-11。1.11 之后分四路再找一轮：
- 日本动画、特摄、国漫和现场舞台；
- 游戏（包括换装游戏）；
- 短视频、AI 特效模板和 MMD／VRChat 圈；
- 影视、MV 和专业工具。

下面只列插件已做的和「六」「七」「八」里都没有的；标「列过」的，是前几轮列过、这轮有了新证据或更便宜做法的。都能在 Blender 3.6 上做，例外单独说明。
这轮的资料条件比上一轮差：Pretty Cure、仮面ライダー 的 Fandom 维基返回 402，抖音、小红书、可灵、海螺的热榜由脚本渲染、读不到，热度主要靠 B 站当天读到的播放量、上映日期和票房。也没有看视频：下面的画面是照文字描述给 MMD 模型改编的设计，做法都没在 3.6 上实测。

这一轮最大的认识是：变身的新意从「衣服怎么变」转到了**什么东西在什么时候挡住、照到、扫过这里**，比如雨伞、颜料、水袖、发丝、相纸、光锥、喷雾，甚至舞者自己动作的快慢。插件的到达时间比当初想的更通用：只要生成时能逐帧回答「这个顶点什么时候被碰到」，就是一种新前沿，而且仍然拖到任意一帧都对。

四路的收获各不相同：
- **国风最集中**：法相、三头六臂、太极、变脸、皮影、符箓、书法字幕。背后是《哪吒之魔童闹海》（全球票房最高的动画电影）和国风变装短片的热度；
- **短视频** 2025–26 年的爆款几乎都是「一个便宜道具或一个手势，加一首歌」：颜料、雨伞、闪光灯、吧唧、拍立得。MMD 用不了真人道具，插件要把道具做成 3D 物体或画面效果；
- **游戏**贡献了换装之后怎么亮相（写真、抽卡），和两个反复出现的主题（人偶、幽灵）；
- **影视和工具最少**：剪辑插件 2025–26 年的更新里，只有 Sapphire 2026 的胶片烧穿是新样子；也没有哪款产品做「两套衣服之间、带前沿路线的换装」。

### 重新考虑的点子和更便宜的做法

第三轮把三个点子放进了「暂不推荐」，三条理由现在都不成立了：
- **三头六臂**当时说「要按骨骼权重复制手臂，费工」：1.11 的分身对跳已经在节点组里复制当前帧的身体，分出手臂只是生成时多存一个「属于哪条手臂」的属性；
- **蒸着后慢放**当时说「属于剪辑手法」：1.11 已经能在场景里控制时间（定格、慢放、一拍二用的 NLA 片段时间），倒带重放只是另一条时间曲线；插件的节点树只看遮罩半径的当前值，半径往回走，碎片就自己倒飞回身上；
- **变脸**当时说「要逐帧从镜头往每个顶点打射线」：变脸每一次都是整身切换，只要找出遮挡最大的那一帧。

证据也比当时强：《哪吒之魔童闹海》以超过 159 亿元成为全球票房最高的动画电影；2025 年春晚重演了《千手千眼》；《封神第二部》殷郊的法相就是三头六臂；ギャバン 2026 年作为超级战队后继企划 PROJECT R.E.D. 的第一部回归；朱铁雄 2026 年 7 月标「川剧」的国风变装有 494 万播放。

另有几项列过、还没做的，这轮找到了更便宜的做法：
- **纹路**（第三轮的「螺钿纹路」）：把毒液的皮下血管换成发光的纹身样式，跑在前沿前面；
- **绕身体转一圈**（第三轮）：改在身体正面的平面里量角度，就成了一块真正的表盘；
- **来回变色**（第三轮）：只换颜色、不换网格，不用等多套连换；
- **倒影先换**（第四轮）：原本要先在 3.6 上实测反射平面里的 Is Glossy Ray；镜子里的人直接用分身的镜像副本，就不需要真的反射。

只有 Q 版仍然不做，这轮只多了兔田佩克拉一个出处。

### 三套现有功能接得住大部分新效果

插件这十一个版本攒下的几套功能，比当初设计时想的更通用：
- **生成时逐帧采样**：motion.py 的 play() 只播骨骼，每帧把两套服装蒙皮后的顶点交给一个回调；1.10 的回调问「手的胶囊碰到这个顶点没有」。把问题换掉，就是一整组新前沿：顶点投到画面上，在不在擦除线、圆孔、扇形、笔触、颜料抹痕、烧穿焦边里；在不在这一拍亮起的光锥里（追光、镜面球）；累加的喷涂量、运动量有没有超过阈值（喷涂成衣、动得快的地方先亮）。下游的遮罩关键帧、碎片、装饰和拍点同步一律不用改；
- **挂在相机前的片**：1.10 的集中线（Child Of 相机，材质读物体属性）。打碎画面、飞布、烧穿、破框的墙、雨伞、书法字幕、抽卡亮相卡都是它的变体；真正要新写的只有「这片盖住了多少画面」的判定，让换装落在盖满的那一刻（变脸、雨伞、飞布共用）；
- **复制当前帧的自己**：1.11 的分身对跳和手办。法相（放大、挪到身后）、三头六臂（只要手臂和头，扇形排开）、迷幻多重曝光（同心放大几层）、画里的自己（压扁、缩小、放进相框）、倒影先换（镜像副本），都只是给副本换一个变换和材质；新服装的节点组要加一个同样的分支。

再加上 1.11 的时间曲线，和这轮要新做的一个小部件（注入材质的换色节点），这轮的新效果大多不需要新系统。

| 现有功能 | 现在用在哪 | 这轮能用它做的 | 要新加的 |
| --- | --- | --- | --- |
| 生成时逐帧采样 | 1.10 手扫、1.11 绸带扫到哪变到哪、舞蹈动作触发 | 画面上的前沿（擦除、圆孔、扇形、笔刷、颜料、烧穿）；追光、镜面球；喷涂成衣、动得快的地方先亮；对视、碰饰品、捶胸 | 可替换的判断条件：投到画面上的形状、这一拍亮着的光锥、累加量超过阈值 |

### 需要新版本、要实测或要讨论

- **满屏油画**：合成器的 Kuwahara 滤镜 4.0 起才有。本机实测 3.6.15 没有 CompositorNodeKuwahara，4.5.10 有。3.6 上只能给人物做油画材质，够做「画中人活过来」，但做不出整幅画面的厚涂感，满屏版待讨论。
- **彩虹薄膜**（格琳达泡泡、结界的彩虹、闪耀暖暖的薄膜皮肤）：Principled BSDF 的 Thin Film 4.2 起才有，3.6 继续用菲涅尔加色带，4.2+ 可选真薄膜。
- **多套连换**：仍要改架构，但这轮又多了九个出处，是需求最明确、插件还做不了的一项：
  - 抖音「高热快速变装」话题总播放量破 60 亿；
  - Higgsfield 的 Urban Cuts（「Beat-synced AI outfit videos」）和 ClipCut（一张自拍出换装短片）；
  - CapCut 排第一的换装模板被用了 59 万次；
  - B 站「40 秒六民族丝滑变装」281 万播放；
  - 星瞳用 UE5 直播时三连跳卡点变装；
  - 《The Fate of Ophelia》一首歌换了七八身；
  - 英雄联盟手游剑圣「风驰」系列在对局中轮换三种形态；
  - 无限暖暖五星套装的进化 1／2／3 加焕新；
  - 漫威争锋的浩克三种形态。

  建议 1.12 之后专门开一次架构讨论，不再排在待讨论的末尾。在那之前，变脸和颜色拉锯可以用换色节点假装。
- **多格拼贴**（Higgsfield 的 Scrapbook collage）：每一格多渲一遍，维持待讨论。Datamosh、Q 版维持不做。
- 动手之前要先在 3.6 上试五件事：
  - 法相、多重曝光这类复制品和本体叠在一起时，EEVEE 混合透明的前后排序；
  - 倒带那几帧刚体停住、重放时再接上，会不会抖；
  - 风力场能不能吹动 mmd_tools 的刚体头发和裙子；
  - 英文骨骼名的模型，能不能按顶点组分出手臂；
  - Shortest Edge Paths 在十万面以上的模型上够不够快。

和「八」留下的 1.12 清单合并重排。排序看四条：2025–26 年的热度，合不合「跟着舞蹈变」这条主线，工作量，能不能和别的项共用同一套功能。逐帧采样的通用模块排第一，不是因为哪个效果最火，而是它一次带出整组画面上的前沿，后面的追光、喷涂、随动显形也都要用它。

1. **逐帧采样做成通用模块，加画面上的前沿**：擦除（划变）、圆孔、扇形（折扇）、笔刷（巨笔），加颜料抹开、胶片烧穿的焦边。
2. **法相与三头六臂·千手开屏**：2025 年国内大片、手游皮肤和 AI 模板里反复出现，三路调研各自找到，做法全建立在 1.11 的分身上。
3. **结界罩和泡泡**：和护盾收缩、糖纸、水壳共用一套外壳，顺手加纹身纹路先兆和闪粉。《KPop 猎魔女团》是 Netflix 观看最多的电影。
4. **照到、喷到、动到哪变到哪**：追光、镜面球光斑、喷涂成衣，加动得快的地方先亮；熄灯、闪光灯、镜头光条跟着这组一起做。
5. **挡住镜头的那一刻**：打碎画面、飞布盖镜头，加雨伞、破框而出。嫌 1.12 太重，可以整组挪到 1.13。
6. **收尾亮相**：写真定格、抽卡出金。给全部 73 个预设都多加一层；B 站 MMD 换装的主角多是二游角色，抽卡出金一眼就懂。
7. **小项**：卡通爆炸；对视时换装、切片拼装、表盘跳针、太极阴阳；倒带重放（先测刚体）。

1.13 再做：
- 打铁花（连同第二轮的随机斑点）：很热，2025 年春晚开场就用了它，但它不和 1.12 的任何功能共用；
- 人偶（断线木偶、人偶活过来）；
- 变脸连变、颜色拉锯；
- 画里和镜里先换好：亮图入画、画中人活过来、倒影先换；
- 幽灵化、皮影；
- 钻进瞳孔、地球拉远、世界折叠；
- 皮肤和细节：反差 AB 面、迷幻多重曝光、书法大字幕、符箓燃尽、藕断丝连、梦境领域，碰饰品、捶胸两种触发。

前几轮留下的老项（剥落卷起，连同撕衬衫、ぶっ返り、引抜き；融化滴落和充气爆开；形变，含裙摆落下；碎开再熔合；长羽毛和花；光学迷彩）已经顺延两轮，这轮几乎没有新的热度证据，继续排在 1.13 之后。想先清老账的话，剥落卷起这一族最值得先做，藕断丝连、符箓燃尽这类细节都要挂在它上面。暂缓的是毛振り、巨人化和衣橱水晶（等多套连换）。

竞争也在变。MMD 圈 2026 年开始出现「MMD 加 AI 视频」的换装作品（B 站「雪莲の猫猫换装」九天 104 万播放），AI 应用把「一张照片出卡点换装短片」做成了标配。插件守得住的是 AI 还做不稳的部分：严格踩在舞蹈动作和拍点上，同一个人从头到尾不走样，镜头和时间可控，能出 4K。1.12 的采样模块读的正是舞蹈本身，正好加强这些长处。

第六轮调研（2026-10-17）把留给 1.13 的清单和新发现合在一起重新排了一次，见「十」的推荐下一批。

## 十、第六轮调研：还能做哪些变身

调研时间：2026-10-17。1.12 之后分五路再找一轮，专查前几轮没查透的方向（第四轮记下的四块空白，加上真人舞台）：
- VTuber 的 3D 新衣装公开和 3D 直播；
- 偶像游戏和音游的 3D 演出；
- 西方动画和影视；
- MMD 圈的 MME 和技术社区；
- 真人舞台的快速换装。

下面只列插件已做的和「六」到「九」里都没有的；标「列过」的，是前几轮列过、这轮有了新证据或更便宜做法的。都能在 Blender 3.6 上做，例外单独说明。
这轮的网页搜索额度几乎用完，大部分数字改从网页自己的接口读：YouTube 的播放量和「最多重播」热度曲线，B 站的播放和弹幕，niconico、BowlRoll、BOOTH 的计数，都是 2026-10-17 当天的数。欧美动画的画面大多来自粉丝维基 TV Tropes。仍然没有看视频：下面的画面是照文字描述给 MMD 模型改编的设计，做法都没在 3.6 上实测。

这一轮最大的认识是：观众记住的不是衣服怎么一点点变，而是**先挡住、再打开或放出一样东西**的那一下。Drag Race 冠军从斗篷里放出一群黑气球，扇舞的两把羽扇，演唱会的彩带和火柱，偶像 MV 里从天而降的老虎机，B 站 MMD 圈的 emoji 贴纸、像素打码和编辑器光标，都是这样。它们和 1.12 留下的「挡住镜头的那一刻」要的是同一个还没做的部件：**覆盖判定**，生成时算出每一帧人被挡住了多少，让换装落在挡得最满的那一刻。

五路的收获各不相同：
- **VTuber 和偶像游戏**：新东西几乎都在编排上，不在特效上。观众描述换装那一刻只用「変身」「まばゆい光」「暗転」「ガラッと変わる」；偶像游戏官方的曲中换装都是整身一次换，大多落在全曲 60–75%，靠跳跃、离场或一件大道具挡住。十场 VTuber 3D 直播的 YouTube 热度曲线里，能确定换装时刻的六场有四场，换装那几秒是全场重看最多的前三个点；
- **真人舞台**：drag 圈公认最好的几次 reveal，打动人的是「放出一样东西」或「挡住再打开」；时装这边，衣服本身成了屏幕；
- **MMD 圈**：B 站的换装爆款几乎都是 10–20 秒的竖屏模板，换的那一下靠像素、emoji、白光或风扇叶挡住。2024–26 年的新 MME 没有新的换装手法，MMD 杯 2022 年之后没再办。连续前沿仍有观众（《胡桃的渐变换装》37.6 万播放，热评「钢铁侠是吧」），只是做的人很少；
- **欧美影视**：2025–26 年最受热议的两段，《罪人》和《创：战神》，变出来的都是人周围的东西；成人向动画几乎没有正式的变身段落；
- **多套连换**第一次五路都找到了，节奏也有了数，见下面单独一节。

### 一段里连换好几套

多套连换从第三轮起每轮都在「要改架构、单独讨论」里。这一轮第一次五路都找到了，而且有了节奏：每套停多久，怎么收尾，什么样的连换会被当成失败。

| 节奏 | 代表 | 每套多久 |
| --- | --- | --- |
| 快：每次一个遮挡物 | 快变魔术（Solange Kardinaly；吉尼斯「一分钟最多快变」25 次）；Seedance 2.0 风扇模板（每 2 秒一套，共四套）；30 套以上的粉丝一键换装 | 2–5 秒 |
| 主流：一个乐句 | B 站「一键换装」：同一段官方 MV 按同样的镜头录很多遍再剪（学マス 9–11 秒一套；あんスタ Knights 7 套，约 19 秒一套，24.3 万播放）；B 站 MMD 多套短片 10–33 秒换 3–4 套 | 9–19 秒（120–150 BPM 下 4–10 小节） |
| 慢：一段一套 | 演唱会按歌换（PLAVE 每首歌连衣服带舞台一起换，Beyoncé 一晚约 10 套）；亚北音留换装×12 按声库段落换 | 一首歌或一段 |
| 一首歌里走马灯 | さくらみこ生誕祭 2026：《咲き誇れアイドル》后半从巫女服依次换过历代偶像服，最后停在新的樱色礼服上（79 万次观看，重看高点就在这里） | 整串约一分钟 |
| 主换加差分 A→B→B′ | 鷹嶺ルイ的生日 3D LIVE：第四首唱到一半换新衣装，第六首中途出「パターン違い」 | 两次相隔约 6 分钟 |
| 倒序剥层 | 《阿加莎》第 1 集越撕越旧 | 文字没写 |

三个共同点：
1. **最后一套停得最久**：Seedance 模板最后停 2 秒，みこ停在新礼服上，粉丝剪辑常是「快切几套、最后一次大变身」；反过来「第一次完整、后面一闪」也有出处（希曼、希瑞）。
2. **每一层都要落在音乐上**：层多但不卡点的 drag 连揭被列进了失败榜。
3. **遮挡物有两种用法**：同一种遮挡反复用（风扇、变脸），或每一套换一个道具（Solange 的丝巾、包装、粉布、画框）。

要连换的主要不是官方作品，而是插件用户这类人：偶像游戏的 MV 基本只在周年曲做一次 A→B；连换好几套的是 VTuber 的生日演唱会、粉丝剪的一键换装、短视频模板和快变魔术。粉丝现在靠重录 MV、手工剪辑来连换，B 站最热的几条一键换装能到二十几万播放。

最便宜的一版不用每两套之间都走一遍前沿：几套衣服跟着同一套动作，按「每 N 小节」或自动切镜头硬切，每一下用一个遮挡物盖住（风扇、emoji、彩带、闪光），换装帧由覆盖判定挑，只有最后一套用前沿正式换上。可以先给五个节奏模板：
- **走马灯**：每 1–2 拍一套，最后一套走前沿，再接写真定格；
- **魔术**：每两小节一套，每套一个不同的遮挡物；
- **乐句**：每 4–8 小节一套；
- **段落**：按时间线标记换，每套配一个领域展开的世界；
- **主换加差分**：先完整换一次，过几个八拍只关掉外套、换发型。差分连第二个模型都不用，同一个模型关几个材质就行。

要先查清三件事：N 套衣服的遮罩和录制怎么管；几个模型叠在同一位置时刚体会互相干扰（2015 年用 MME「変身シェーダー」的人就提过）；生成时间和显存。

### 同类产品（更新）

仍然没有「两套衣服、带前沿路线、跟着舞蹈」的产品。Superhive（原 Blender Market）2026 年还在更新的新品几乎都要 4.2 或 4.5 以上：最接近的 Beam It In（4.5–5.2）能给走动中的绑定角色做扫描、全息、逐步显形，但只处理一套衣服；Break It Any Way（4.5–5.2）把消散倒放成重组；Outfit Refit（4.2–5.2）把衣服套到别的身体上，和 MMD 圈的 PmxDressup 一样是插件的上游。还支持 3.6 的只剩 Magic Transitions Shader、Quick Vanish、The Tapestry 这类老品，插件先保证 3.6 反倒更少见了。MMD 圈的做法还是两个模型叠在一起、用一个表情一下切换（2015 年的「変身シェーダー」，2025 年还有人拿它配《ビビデバ》），或者两个模型硬切、用闪光挡住。AI 那边，Seedance 2.0 的换装模板和猫猫换装的提示词教程，已经把「挡一下就换」做成了流水线。

### 需要新版本、要实测或要讨论

- **没有一项新效果要 4.0**：用到的 Raycast、String to Curves、Pixelate、Cryptomatte、Glare 3.6 都有。次元切换的写实皮肤 4.2 起更好看；剥落卷起如果走 2025-12 的新教程（几何节点改钉固权重，再交给布料模拟）就要烘焙，和插件「拖到任意一帧都对」冲突，仍待讨论。满屏油画（4.0 的 Kuwahara）、彩虹薄膜（4.2 的 Thin Film）不变。
- **多套连换**：这一轮已经能定参数。覆盖判定该不该一次返回一串换装帧，换色节点该不该按「第几套」管理，都取决于做不做连换，所以这个决定最好放在 1.13 动工之前。
- 动手之前要先在 3.6 上试三件事：覆盖判定每帧把遮挡物和人投到画面上算覆盖率要多久；次元切换在 MMD 贴图上好不好看；历代舞伴这种 3–6 个分身同时跳时的性能。

### 推荐下一批

和「九」留给 1.13 的清单合并重排。排序沿用上一轮的四条（热度、合不合跟着舞蹈变、工作量、能不能共用功能），再加一条：B 站 MMD 圈是不是已经在用，因为那里就是插件的用户。**覆盖判定排第一**，理由和 1.12 先做采样模块一样：1.12 留下的「挡住镜头的那一刻」、这一轮的新遮挡物、变脸连变，以后多套连换的每一次硬切，都要它。

1.13：
1. **覆盖判定加相机前的遮挡**：打碎画面、飞布盖镜头、雨伞、破框而出（加画框爆羽），加风扇叶片、emoji 遮脸；
2. **画面上的小把戏**：像素打码、编辑器光标。最便宜，热度又最集中在 MMD 圈（141.8 万、105.7 万）；
3. **衣服变屏幕**：LED 点阵、电子纸鳞片。全在材质里，天生跟着拍子变；
4. **舞台的机关**：彩带炮、气球放飞（加张开双臂触发）、羽扇遮身、台口火柱、落幕，加 1.12 留下的镜面球光斑；
5. **换色一组**：变脸连变、颜色拉锯，加历代舞伴，三项共用一个新的换色节点；
6. **多起点一组**：打铁花、随机斑点，加信物上身，共用「每个起点有自己的起始时刻」这个新部件（嫌重可以整组挪到 1.14 打头）；
7. **小项**：换装时刻建议、按音乐推进的前沿、分段揭晓的上摇镜头、长高变壮。

1.14：画里和镜里先换好；雾中图腾、老虎机开奖；次元切换；人偶、幽灵化、皮影；激光打印；钻进瞳孔、地球拉远、世界折叠。
（次元切换和激光打印已经在 1.14 做完，见上面「三」里的「1.14 跟进」；雾中图腾和老虎机开奖在 1.15 做完，见「1.15 跟进」；画里和镜里先换好（除了拍立得）、人偶、幽灵化、皮影在 1.16 做完，见「1.16 跟进」。）人偶以下几组这一轮没找到新证据，后三项还要新的环境几何。
