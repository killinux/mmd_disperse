通用准备

每段视频都先做这几步，再按各自的设置调整。界面名称以中文 Blender 为准。

  1. 安装插件。安装包在 GitHub Releases 下载。Blender 4.2 及以上：编辑 › 偏好设置 › 获取扩展 › 右上角下拉 › 从磁盘安装，选 dist/mmd_disperse-1.12.0.zip。Blender 3.6～4.1：偏好设置 › 插件 › 安装，选 mmd_disperse-1.12.0-legacy.zip，再勾选「MMD Disperse」。
  2. 导入两个模型。用 mmd_tools（文件 › 导入 › MikuMikuDance 模型 (.pmd, .pmx)）导入 旧服装（变身前，视频里是 V2）和新服装（变身后，V1）。位置随意，生成时新服装会自动对齐到旧服装上。
  3. 跳舞的话先加载动作。只给旧模型加载：选中旧模型脚下的根物体，文件 › 导入 › MikuMikuDance 动作 (.vmd)，缩放和导入模型时一致。要在生成之前加载，新服装生成后会跟着旧骨架一起跳。
  4. 选模型。3D 视图按 N，打开 MMD 变身 标签页。选中旧模型的任意部分， 点 旧服装（变身前） 右边的吸管；同样设好 新服装（变身后）。 跟随旧模型骨架 保持勾选。
  5. 时间。开始帧 10、结束帧 185（演示一共 200 帧），方向 穿上（旧→新）， 缓动 缓入缓出。
  6. 共用部分。展开 旧服装处理，勾选 保留共用部分， 材质 填 Face*;Hair*;Eye*;*Brows*;Eyelashes*;Mouth*;*Teeth*;Inners*， 脸和头发始终用旧模型的。
  7. 按下面每段视频的设置调好，点 生成变身效果。所有尺寸按模型身高自动换算，不用手调。
  8. 辉光。展开 线框层 面板，点 添加辉光 （4.2 及以上在合成器里加 Glare 节点；3.6 打开 EEVEE 泛光）。
  9. 渲染。Ctrl + F12。之前可以切到「材质预览」视图，按空格看效果。

视频里的 PBR 材质、工作室灯光、反光地面和环绕镜头，是演示脚本 demo/render_hd.py 布置的。 插件只负责变身本身，模型保持原来的 MMD 材质也一样能用。每段下面的「演示参数」是这个脚本用的命令行参数，方便原样重渲。
