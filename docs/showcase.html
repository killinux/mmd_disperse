通用准备

每段视频都先做这几步，再按各自的设置调整。界面名称以中文 Blender 为准。

  1. 安装插件。安装包在 GitHub Releases 下载。Blender 4.2 及以上：编辑 › 偏好设置 › 获取扩展 › 右上角下拉 › 从磁盘安装，选 dist/mmd_disperse-1.5.0.zip。Blender 3.6～4.1：偏好设置 › 插件 › 安装，选 mmd_disperse-1.5.0-legacy.zip，再勾选「MMD Disperse」。
  2. 导入两个模型。用 mmd_tools（文件 › 导入 › MikuMikuDance 模型 (.pmd, .pmx)）导入 旧服装（变身前，视频里是 V2）和新服装（变身后，V1）。位置随意，生成时新服装会自动对齐到旧服装上。
  3. 跳舞的话先加载动作。只给旧模型加载：选中旧模型脚下的根物体，文件 › 导入 › MikuMikuDance 动作 (.vmd)，缩放和导入模型时一致。要在生成之前加载，新服装生成后会跟着旧骨架一起跳。
  4. 选模型。3D 视图按 N，打开 MMD 变身 标签页。选中旧模型的任意部分， 点 旧服装（变身前） 右边的吸管；同样设好 新服装（变身后）。 跟随旧模型骨架 保持勾选。
  5. 时间。开始帧 10、结束帧 185（演示一共 200 帧），方向 穿上（旧→新）， 缓动 缓入缓出。
  6. 共用部分。展开 旧服装处理，勾选 保留共用部分， 材质 填 Face*;Hair*;Eye*;*Brows*;Eyelashes*;Mouth*;*Teeth*;Inners*， 脸和头发始终用旧模型的。
  7. 按下面每段视频的设置调好，点 生成变身效果。所有尺寸按模型身高自动换算，不用手调。
  8. 辉光。展开 线框层 面板，点 添加辉光 （4.2 及以上在合成器里加 Glare 节点；3.6 打开 EEVEE 泛光）。
  9. 渲染。Ctrl + F12。之前可以切到「材质预览」视图，按空格看效果。

视频里的 PBR 材质、工作室灯光、反光地面和环绕镜头，是演示脚本 demo/render_hd.py 布置的。 插件只负责变身本身，模型保持原来的 MMD 材质也一样能用。每段下面的「演示参数」是这个脚本用的命令行参数，方便原样重渲。

纳米战衣 · 视频原版

从胸口长出一个带噪波的球，发光的六边形线框沿边界扫过全身，新战衣跟着长出来，旧服装缩到下面消失。就是 B 站教程里的做法。

手动操作

  1. 主面板最上面的 预设 选 纳米战衣（和默认设置一样）。
  2. 路径 球形扩散，起点 骨骼 （骨骼栏留空，自动用胸口的「上半身2」），测量空间 静止姿态。
  3. 线框层 标题栏勾上，六边形 勾上，发光颜色 青色。
  4. 旧服装处理 › 退场方式 收缩消失。

演示参数：（默认设置，不加参数）

1.1沿体表流动起点 + 手脚线框层

纳米流动

变身贴着身体表面流动，从胸口和两只手腕、两只脚踝同时出发，绕过躯干、顺着四肢流开，像钢铁侠 Mark 50 的纳米战衣。

手动操作

  1. 预设 选 纳米流动；或者手动设置下面两项。
  2. 路径 沿体表流动，出发点 起点 + 手脚， 起点 骨骼。
  3. 其余保持默认（线框层打开，收缩消失）。生成时会给每个顶点算一次到达距离，测试模型大约 1 秒。

演示参数：--set path=SURFACE --set seeds=ORIGIN_LIMBS

1.1从下往上扫碎片飞散花瓣

从下往上 · 碎成花瓣

一条水平的边界从脚扫到头，旧服装碎成发光的小片被风吹走，同时飘出樱花花瓣。

手动操作

  1. 路径 从下往上扫。
  2. 旧服装处理 › 退场方式 碎片飞散 （碎片发光 保持勾选）。
  3. 粒子 子面板 › 粒子 花瓣， 数量 1200。
  4. 线框层保持打开。

演示参数：--set path=UP --set exit_style=FRAGMENTS --set particles=PETAL --set particle_count=1200

1.1从上往下扫碎片飞散蝴蝶

从上往下 · 化成蝴蝶

边界从头扫到脚，旧服装碎开，飞出一群各自扇着翅膀的浅蓝色蝴蝶。

手动操作

  1. 路径 从上往下扫。
  2. 旧服装处理 › 退场方式 碎片飞散。
  3. 粒子 蝴蝶，数量 900， 粒子颜色 浅蓝 R 0.45 / G 0.8 / B 1.0， 扇动速度 用默认的 1.5。

演示参数：--set path=DOWN --set exit_style=FRAGMENTS --set particles=BUTTERFLY --set particle_color=0.45,0.8,1.0 --set particle_count=900

1.2从下往上扫全息先行关闭线框

全息扫描

从脚往上扫描。新服装先以半透明的全息投影出现，带横向扫描线、轮廓光，最前端还有一圈扫描光环；边界扫过后才变成实体。

手动操作

  1. 预设 选 全息扫描；或者手动设置下面三项。
  2. 路径 从下往上扫。
  3. 全息先行 面板标题栏勾上（全息范围、全息不透明度、 全息亮度 可以调）。
  4. 线框层 标题栏取消勾选。Blender 3.6 的旧版 EEVEE 需要「Alpha 哈希」才能透明，插件会临时改好。

演示参数：--set path=UP --set holo_enable=1 --set wire_enable=0

1.2球形扩散故障风色散

故障风

边界附近切成一条条水平切片，在新旧服装之间随机闪烁、横向错位、偶尔闪光；画面再叠一层红绿蓝色散。

手动操作

  1. 故障风 面板标题栏勾上（故障范围、切片高度、 闪烁频率、切片错位 可以调，闪光 保持勾选）。
  2. 线框层 标题栏取消勾选。
  3. 生成后在 故障风 面板点 添加色散（合成器里加一个按帧号驱动的镜头畸变节点）。
  4. 预设 故障风 是同样的组合，只是发光颜色换成了粉色。

演示参数：--set glitch_enable=1 --set wire_enable=0 --glitch-fx

1.2沿体表流动零件飞入装甲弹开

装甲换装

旧装甲切成一块块，整块甩出去、翻滚、落地消失；新装甲一块块从远处飞来装上，像假面骑士的 Cast Off。

手动操作

  1. 预设 选 装甲换装，它会设好下面这些。
  2. 路径 沿体表流动，出发点 只从起点。
  3. 新服装登场 › 零件飞入；旧服装处理 › 退场方式 装甲弹开，碎片发光 勾选。
  4. 发光颜色 橙色。零件大小、飞来距离、 弹开力度 都可以再调。

演示参数：--preset ARMOR

1.2只从手脚光剪影光带星光

魔法少女

手脚先亮成光的剪影，双股螺旋光带缠上四肢，旧服装碎成光尘和星光，新服装从手脚往身体中间换上。

手动操作

  1. 预设 选 魔法少女，它会设好下面这些。
  2. 路径 沿体表流动，出发点 只从手脚； 退场方式 碎片飞散，光剪影 勾选。
  3. 光带 标题栏勾上；粒子 星光；发光颜色 粉色。
  4. 这段是 1.2 录的。1.3 的这个预设还会打开 收尾闪光；想和这段视频一模一样，把它的勾去掉。

演示参数：--preset MAGICAL（1.2 版）

1.3VMD 舞蹈留在原地收尾闪光

边跳舞边变身 · 魔法少女

跳着《回レ！雪月花》变身：星光留在手臂划过的地方，形成一道道弧线；第 128 帧左右变身完成，整身闪一下，迸出一圈星星。

手动操作

  1. 先按「通用准备」第 3 步给旧模型加载 VMD。
  2. 预设 选 魔法少女（1.3 版，包含收尾闪光）。
  3. 旧服装处理 › 勾选 留在原地。
  4. 点 生成变身效果：插件会把这段动画播一遍，记下每片碎片脱落时的位置（测试模型约 8 秒）。 改了舞蹈或帧范围要重新生成。
  5. 收尾闪光的 闪光时长、闪光亮度、星光数量、 星光飞散距离 在 收尾闪光 面板里调。

演示参数：--preset MAGICAL --set leave_behind=1 --vmd "回レ！雪月花.vmd"

1.3VMD 舞蹈只从手脚碎片飞散留在原地

边跳舞边变身 · 灰飞烟灭

手脚先开始，旧服装化成不发光的灰被风吹走。灰留在她跳过的地方慢慢飘散，不会跟着身体甩。

手动操作

  1. 给旧模型加载 VMD（同上）。
  2. 预设 选 灰飞烟灭：沿体表流动 + 只从手脚 + 碎片飞散，碎片发光和边缘发光都关掉。
  3. 勾选 留在原地，再点 生成变身效果。
  4. 想让灰飘得更远，调 风力 和 风向（世界坐标，MMD 模型面朝 -Y）。

演示参数：--preset DUST --set leave_behind=1 --vmd "回レ！雪月花.vmd"

1.4VMD 舞蹈装甲弹开留在原地

边跳舞边变身 · 装甲留在原地

跳着《回レ！雪月花》换装甲：旧装甲一块块整块弹开，留在她跳过的地方翻滚、落下，不会跟着手臂甩； 新装甲一块块飞来装上。每块都在脱落那一刻整块定住，不会被拉变形。

手动操作

  1. 给旧模型加载 VMD（「通用准备」第 3 步）。
  2. 预设 选 装甲换装。
  3. 旧服装处理 › 勾选 留在原地，点 生成变身效果： 插件把这段动画播一遍，记下每块装甲脱落那一刻整块的位置（测试模型约 8 秒）。
  4. 改了 零件大小 以后旧记录对不上，插件会自动丢掉（面板提示重新生成），再点一次生成即可。

演示参数：--preset ARMOR --set leave_behind=1 --vmd "回レ！雪月花.vmd"

1.4物体动画转圈留在原地收尾闪光

边转圈边变身 · 魔法少女

整个人转两圈的同时变身：手脚先亮起来，碎成的光尘和星光留在空中，被甩成一圈圈螺旋； 转完正好面向镜头，整身闪光、迸出星星。转圈是根物体的旋转关键帧，新服装跟着一起转。

手动操作

  1. 选中旧模型脚下的根物体，在第 10 帧给 旋转 Z 打关键帧， 第 120 帧改成 720° 再打一个。
  2. 预设 选 魔法少女。
  3. 勾选 留在原地，点 生成变身效果：脱落位置按世界坐标记录， 另有一个隐藏的空物体记下模型每一帧怎么转。
  4. 新服装的根物体会自动加一个「复制变换」约束跟着旧模型转；生成以后再把整个模型挪到别处，碎片也会跟着挪。

演示参数：--preset MAGICAL --set leave_behind=1 --spin 720 --spin-frames 10:120

1.4球形扩散收尾光扫全屏闪白

纳米战衣 · 光扫 + 闪白

战衣长好的一刻画面闪白，接着一道青色的光从胸口沿球形扩散的路线扫过全身，光经过的地方迸出星星。

手动操作

  1. 预设 选 纳米战衣。
  2. 收尾闪光 面板标题栏勾上，闪光方式 选 光扫， 闪光时长 0.3（扫得慢一点），光扫宽度 可以调。
  3. 粒子颜色 改成浅青 R 0.6 / G 0.9 / B 1.0，粒子发光 3，星星和光带同色。
  4. 点面板最下面的 添加闪白（合成器里加一个混合节点，用驱动器跟着遮罩走）， 闪白强度 默认 0.8。

演示参数：--preset NANOTECH --set finale=1 --set finale_style=SWEEP --set finale_length=0.3 --set particle_color=0.6,0.9,1.0 --set particle_glow=3 --white-flash

1.5沿体表流动深色内衬收尾光扫全屏闪白

纳米战衣收尾（新预设）

从胸口流出一层带发光细网纹的深色内衬，六边形线框在最前面爬；战衣跟在内衬后面沿一道发光接缝成形。 全身长好的一刻画面闪白，一道光沿着流过来的路线扫过全身，光经过的地方迸出星星。

手动操作

  1. 预设 选 纳米战衣收尾：打开沿体表流动（只从起点）、线框层、 深色内衬、背面发光、收尾闪光（光扫，时长 0.3）， 并自动在合成器里加上闪白。
  2. 深色内衬 面板里 内衬宽度 决定战衣落后边界多远， 内衬纹路亮度 调细网纹（颜色用线框层的发光颜色）。
  3. 遮罩会自动多长出一个内衬宽度，收尾闪光和闪白等战衣完整以后才开始。

演示参数：--preset NANO_FINALE --white-flash

1.5物体动画转圈留在原地零件飞入

边转圈边换装甲

整个人转一圈的同时换装甲：旧装甲整块弹开、留在空中往下落；新装甲的零件从空中固定的位置飞过来， 追着转动的身体装上去，不会跟着身体一起绕圈。

手动操作

  1. 选中旧模型脚下的根物体，在第 10 帧给 旋转 Z 打关键帧， 第 150 帧改成 360° 再打一个。
  2. 预设 选 装甲换装。
  3. 勾选主面板的 留在原地，点 生成变身效果：生成时记下旧装甲每块脱落、 新装甲每块起飞那一刻的位置。改了 零件大小 或 提前起飞 要重新生成。

演示参数：--preset ARMOR --set leave_behind=1 --spin 360 --spin-frames 10:150

1.5从下往上扫只有新服装深色内衬背面发光

从无到有 · 内衬扫描 + 背面发光

没有旧服装，新服装从脚往上一层层「打印」出来：先是带网纹的深色内衬，战衣跟在后面。 镜头稍微俯视，能看进切口里，切口内部是发光的，不是空心的壳。

手动操作

  1. 旧服装 留空，只设 新服装；不勾 保留共用部分（脸和头发也一起长出来）。
  2. 路径 选 从下往上扫。
  3. 展开 深色内衬 面板，标题栏勾上。
  4. 边缘 面板勾选 背面发光（强度、深度可以调）。

演示参数：--no-base --set use_lock=0 --set path=UP --set inner_glow=1 --set layer_enable=1

全部玩法

预设只是常用搭配，下面这些选项都可以自由组合。

变身路径 4

  • 球形扩散
  • 沿体表流动（出发点：只从起点 / 起点 + 手脚 / 只从手脚）
  • 从下往上扫
  • 从上往下扫

新服装登场 2

  • 边缘生长
  • 零件飞入

旧服装退场 3

  • 收缩消失
  • 碎片飞散
  • 装甲弹开

粒子 4

  • 花瓣
  • 蝴蝶（会扇翅膀）
  • 星光
  • 自定义物体
  • 也可以不要

叠加开关 9

  • 线框层（六边形 / 三角网）
  • 全息先行
  • 故障风
  • 光剪影
  • 光带
  • 收尾闪光（整身闪光 / 光扫）
  • 深色内衬
  • 背面发光
  • 留在原地（碎片、装甲、粒子、新服装的零件和星星；跳舞或整个人移动、转圈）

其他

  • 穿上（旧→新）/ 脱下（新→旧）
  • 只有新服装：从无到有长出来
  • 只有旧服装：整个人化成灰
  • 渲染：辉光、色散、全屏闪白

路径 × 登场 × 退场 × 粒子 = 4 × 2 × 3 × 5 = 120 种基本组合；再叠加 9 个开关 （收尾闪光有两种方式），理论上有九万多种（「留在原地」在碎片飞散、装甲弹开、开了粒子、零件飞入或收尾星星时起作用）。
