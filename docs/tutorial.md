# MMD Disperse 使用教程

把一个 MMD 模型的服装，用「纳米战衣」的方式变成另一套服装：发光的六边形线框从起点扩散开，新服装跟着长出来，旧服装被吞掉。
也可以让变身沿着身体流动、从下往上扫描，让旧服装碎成光尘、花瓣、蝴蝶、星光，或者像装甲一样整块弹开；
新服装可以先以全息投影出现，或者一块块飞过来装上，也可以先长成一层深色内衬、最终外观跟在后面；边界可以做成闪烁错位的故障风；
还有魔法少女式的光剪影、光带，以及收尾时的整身闪光、光扫和全屏闪白。切开处还可以让内部发光，不显得空心。
1.6 加了毒液式的黑色共生体（见第十节）、假面骑士式的前后两半夹合和残影汇聚（见第七节）、冰封和燃烧（见第十一节），
故障风可以卡音乐节拍。1.7 加了魔形女式的鳞片翻转（见第七节），毒液触手间的蹼和银色的液态金属（见第十节），
透明的冰、整身冻住后一起碎开（见第十一节）；线框、边缘、收尾闪光、粒子也都能卡音乐节拍，关键时刻落在拍点上（见第十七节）。
1.8 加了四个方向的平面扫描和螺旋上升，前沿上可以带魔法阵、火花圈、发光面板、雪花屏或星光彗星（见第五节）；
旧服装可以被吸进胸针，粒子多了音符、扑克牌、羽毛、蝙蝠、墨点（见第六节）；新服装可以进化闪烁、烟雾一闪、从影子里升起，
还有钢铁侠式的反应堆起手和装甲板鼓起（见第七节）；新服装还能先画成线稿再上色，或者水墨晕染（见第十二节）。
1.9 加了落雷和沿边界爬的电弧（见第十三节），数字雨（见第十一节、第十二节），石化、镀金和蚕丝茧（见第十一节），
传送光柱（见第七节）；粒子多了代码字符和碎石（见第六节）。
1.10 可以跟着舞蹈动作变：拍手、飞吻、敬礼、甩头时开始，背对镜头的那一刻一下子换好，或者手扫到哪变到哪（见第十四节）；
路径多了从腰部上下分开和一件一件换（见第五节），新服装可以瞬间换好或者在花苞里换（见第七节），旧服装可以留下一个空壳（见第六节），
还有卡通火焰（见第十五节）、动画式的冲击帧和集中线、地面冲击波、斗罗大陆的魂环（见第十六节）。
1.11 开始动人周围的世界、镜头和时间：领域展开（见第十八节），甩镜头、环绕等运镜，定格、慢放、一拍二，压扁回弹、纸片和卡牌翻面、
浮空（见第十九节），跟着舞步飞的光带、水袖、混天绫和步步生莲（见第二十节），逆光剪影、去色留色、古画三种画面风格（见第二十一节）；
舞蹈动作多了下蹲、起跳、落地、落脚、举手、比心、眨眼、拉绳（见第十四节），旧的自己可以走出来接着跳或者变成手办（见第六节），
新服装可以先以星空纱、黑剪影或冰晶出现（见第七节），旧服装可以变成剪纸窗花、化成纸鸟（见第十一节、第六节），
光环多了浮世绘式的卡通水流（见第五节）。
模型跳舞或者整体移动、转圈时也能用，碎片、装甲大块、粒子、新服装飞来的零件和收尾的星星都可以留在原地，不跟着身体甩（见第六节）。
不想一项项调的话，主面板最上面的「预设」可以一键套用整套风格（见第二十二节）。

界面文字以中文 Blender 为准，括号里是英文界面的名字。

## 一、安装

安装包可以直接在 [GitHub Releases](https://github.com/killinux/mmd_disperse/releases) 下载，也可以用下面的命令生成，放在 `dist/` 目录：

```bash
# Blender 4.2 及以上（扩展包）
blender --command extension build --source-dir mmd_disperse --output-dir dist
# Blender 3.6 ~ 4.1（传统插件包，zip 里是 mmd_disperse 文件夹）
python -c "import shutil; shutil.make_archive('dist/mmd_disperse-1.11.0-legacy', 'zip', '.', 'mmd_disperse')"
```

- **Blender 4.2 及以上**：编辑 > 偏好设置 > 获取扩展（Get Extensions）> 右上角下拉箭头 >
  从磁盘安装（Install from Disk），选 `mmd_disperse-1.11.0.zip`，装好自动启用。也可以把 zip 直接拖进 Blender 窗口。
- **Blender 3.6 ~ 4.1**：编辑 > 偏好设置 > 插件 > 右上角「安装」，选 `mmd_disperse-1.11.0-legacy.zip`，
  然后搜索「MMD Disperse」勾选启用。

## 二、准备两个模型

1. 用 mmd_tools 导入两个模型：变身前的**旧服装**和变身后的**新服装**，位置随意，插件会自动把新服装对齐到旧服装上。
   最理想的是同一个角色的不同服装版本（骨骼相同）。
2. 要跳舞的话，**只给旧服装模型加载 VMD 动作**。生成后新服装会跟着旧模型的骨骼一起动，头发物理也跟着。
   给旧模型的根物体打位置、旋转关键帧（整个人移动、转圈）也一样，新服装跟着走。

## 三、生成变身效果

1. 3D 视图按 `N` 打开侧边栏，切到「MMD Disperse」标签页（中文界面显示为「MMD 变身」）。
2. **旧服装（变身前）**：在视图里选中旧模型的任意部分（根物体、骨架或网格都行），点这一栏右边的吸管按钮。
3. **新服装（变身后）**：同样选中新模型，点吸管。
4. **跟随旧模型骨架**：保持勾选。
5. **路径**：先用默认的「球形扩散」（视频里的做法），其他走法见第五节。
6. **起点**：选「骨骼」，骨骼栏留空会自动用胸口的「上半身2」。
   想从手开始：选「3D 游标」，用 `Shift + 右键` 把游标放到手上。
7. **测量空间**：选「静止姿态」，跳舞时变身波纹会贴着身体走，不会闪。
8. 填**开始帧 / 结束帧**（比如 1 和 100），**方向**选「穿上（旧→新）」，**缓动**用默认的「缓入缓出」。
   下面的**留在原地**先不勾，模型跳舞或整体移动时再用（见第六节）。
9. 如果两个模型的脸和头发一样，先展开「旧服装处理」，勾选**保留共用部分**，脸和头发就始终用旧模型的。
   材质栏填材质名通配符，用 `;` 分隔，例如：`Face*;Hair*;Eye*;*Brows*;Eyelashes*;Mouth*;*Teeth*;Inners*`。
   这一项要在生成之前设好，改了需要重新生成。
10. 点 **生成变身效果**。胸口会出现一个球形空物体 `MMD Disperse Mask`，它的大小就是变身范围，关键帧已经打好。
11. 按空格播放或拖动时间轴预览。切到「材质预览」或「渲染」视图才能看到发光。

## 四、调整效果

下面这些参数改了立即生效：

| 面板 | 参数 | 作用 |
| --- | --- | --- |
| 边缘 | 噪波强度 / 噪波缩放 | 变身边界的不规则程度 / 碎块大小 |
| 边缘 | 边缘外推 | 边缘沿法线鼓起的程度 |
| 边缘 | 边缘发光 / 边缘发光强度 | 新服装边界那条亮线 |
| 边缘 | 背面发光 / 强度 / 深度 | 切开处看到的内部（背面）发光，不显得空心（见下面） |
| 线框层 | 标题栏的勾 | 整个关掉线框层 |
| 线框层 | 线框半径 | 线的粗细 |
| 线框层 | 边缘后方范围 / 边缘前方范围 | 线框带的宽度 |
| 线框层 | 发光颜色 / 发光强度 | 光的颜色和亮度 |
| 线框层 | 六边形 | 关掉后变成三角网 |
| 旧服装处理 | 向内收缩 | 旧服装从新服装下面穿出来时调大 |
| 旧服装处理 | 边缘后删除距离 | 旧服装在边界后面多远处删掉 |

- **自动尺寸**：第一次生成时所有尺寸按模型身高自动换算；调乱了点旁边的按钮恢复默认。
  模型整体缩放过（比如把根物体缩小）也没关系：面板里的尺寸都按世界单位算，插件会换算到网格自己的坐标里。
- 路径、起点、帧范围、方向、测量空间、保留共用部分属于生成时的设置，改完要再点一次「生成变身效果」（已调好的尺寸会保留）。
- 想细调快慢曲线，可以在曲线编辑器里改 `MMD Disperse Mask` 的缩放关键帧。
- **背面发光**：MMD 服装大多是一层薄壳，变身边界把它切开时，从切口能看到里面的背面，像空心的。
  勾选「背面发光」后，边界附近的背面换成发光颜色，切口看起来是亮的、实心的。只在边界附近亮（范围用「背面发光深度」调），
  变身过去以后，裙子内侧这类本来就看得到的背面恢复原样。只有新服装从无到有、或者只有旧服装消失时最明显；两套服装都会加。

## 五、变身路径

「路径」决定变身从哪里开始、怎么走：

| 路径 | 效果 | 适合 |
| --- | --- | --- |
| 球形扩散 | 从起点长出一个带噪波的球，球里面就是新服装（视频原版） | 通用 |
| 沿体表流动 | 从起点贴着身体表面流：绕过躯干、顺着手臂流到手上，不会隔空跳过去 | 纳米战衣、黑豹那种从项链流出 |
| 从下往上扫 / 从上往下扫 | 一条水平的边界从脚扫到头（或反过来） | 扫描、3D 打印、全息投影 |
| 从左往右扫 / 从右往左扫 | 一个竖直的平面从身体一侧扫到另一侧 | 魔法阵、火花圈穿过身体 |
| 从前往后扫 / 从后往前扫 | 一个平面从身前穿到身后（或反过来），像走过一道屏障 | 电视屏障、发光面板 |
| 螺旋上升 | 从脚下绕着身体转上去，每绕一圈升高一个「螺距」 | 灰姑娘、美少女战士的星光 |
| 从腰部上下分开 | 两道水平的边界从腰同时出发，一道往上、一道往下 | Danny Phantom 的两个光环 |
| 一件一件换 | 新服装一件一件地换：每个材质算一件，各自从上往下扫过，换完一件停一下再换下一件 | 偶像动画的换装卡 |
| 手扫过的地方 | 跳舞的手扫到哪里，哪里先换，其余地方从那里沿体表接着变 | 抖音的手扫变装（要有舞蹈动作） |

- 「沿体表流动」多一个**出发点**：
  - **只从起点**：从起点流向全身。起点用 3D 游标时，`Shift + 右键` 直接点在模型表面上，比如项链的位置。
  - **起点 + 手脚**：起点和两只手腕、两只脚踝同时流出，像钢铁侠的主反应堆加副反应堆。
  - **只从手脚**：手脚先变，胸口和脸最后变。
- 球形以外的路径，生成时会给每个顶点算一次「变身走多远才到这里」，存成属性 `disperse_arrival`，
  测试模型（两套服装共约 39 万个顶点）大约 1 秒。之后播放和调参不会变慢。
- 这几种路径下，遮罩空物体的大小只表示「变身走了多远」；扫描时它显示成一个箭头。
- 左右是从正面看画面里的左右（MMD 模型面朝镜头，它的右手在画面左边）。扫描方向按模型自己的朝向算，生成时模型转过身也对。
- 「螺距」在生成时用，改了要重新生成。
- **从腰部上下分开**：腰的高度取「下半身」骨骼的位置（没有这根骨骼就取身高的 53%）。
- **一件一件换**：多一个**换衣顺序**：从上往下、从脚往上或随机（每次生成都一样）。
  - 太小的材质（扣子、饰边，不到新服装面积 4% 的）并到离它最近的那件里，最多六件。
  - 每件衣服占 0.6 个身高的边界，两件之间停 12%；旧服装跟着离它最近的那件新衣服退场。
  - 脸、头发这些锁定的部分不算衣服。
- **手扫过的地方**：生成时把舞蹈动作从开始帧播到结束帧，记下每个地方第一次被手扫到的帧，那里就在那一帧换；
  没被扫到的地方从扫到的地方沿体表接着变。
  - **用哪只手**：两只手、只用左手或只用右手（模型自己的左右）。
  - **手扫到的范围**：手要离多近才算扫到（手是从手腕到指尖的一段，默认约为身高的 7%）。
  - 边界按手的节奏匀速走（缓动不起作用）：一帧走「身高 ÷（结束帧 − 开始帧）」，走完整个身体需要多久，
    结束帧就自动改成多少。测试模型播 120 帧大约 18 秒。
  - 舞蹈动作改了要重新生成。

**光环**（「光环」面板，标题栏的勾是开关）：平面扫描和螺旋上升时，前沿上可以带一个看得见的东西跟着走：

| 样式 | 效果 |
| --- | --- |
| 魔法阵 | 两圈发光的圆环、六芒星和一圈符文，边走边转（假面骑士 Wizard） |
| 火花圈 | 旋转的火圈，往外甩火星（奇异博士的传送门） |
| 发光面板 | 发光的框里一块带网格的半透明屏（假面骑士 Ex-Aid） |
| 雪花屏 | 一片电视雪花，人穿过去就换了衣服（WandaVision） |
| 星光彗星 | 一颗拖着星光尾巴的彗星绕着身体转，每圈升高一个螺距；配合「螺旋上升」，也能配从下往上、从上往下扫 |
| 光环 | 一圈简单的光环；配「从腰部上下分开」时一上一下两个（Danny Phantom） |
| 卡通水流 | 一条蓝白相间的水带跟着前沿绕着身体盘上去，边上起伏、头宽尾细，白色的流线和浪花像浮世绘（鬼灭之刃的水之呼吸）；配「螺旋上升」，颜色是自己的蓝白 |

| 参数 | 作用 |
| --- | --- |
| 光环大小 | 1 正好围住身体；星光彗星是离身体多远 |
| 光环亮度 | 发光强度；颜色用线框层的「发光颜色」 |

- 光环只在前沿经过身体时出现，开始前和走完以后都看不见。球形扩散和沿体表流动没有平面的前沿，不显示光环。
- 光环是一个单独的物体（名字以「MMD Disperse Ring」开头），带自己的小几何节点组，跟着模型走；移除效果或关掉光环时删掉。
- 左右扫描的光环正对着正面的镜头时只是一条竖线，把镜头转到斜侧面看（演示脚本用 `--angle -55 --orbit 8`）。
- 「魔法阵穿身」「火花传送门」「电视屏障」「星光螺旋」「水之呼吸」五个预设各用一种样式。

## 六、旧服装退场：碎片、装甲、吸进胸针、金蝉脱壳、花瓣、蝴蝶、星光

展开「旧服装处理」，**退场方式**有四种：

- **收缩消失**（视频原版）：旧服装缩到新服装下面，然后删掉。
- **碎片飞散**：变身经过的地方，旧服装碎成小片，弹出、被风吹走、打着旋缩小消失。碎片保留衣服本来的贴图颜色。
- **装甲弹开**：旧服装按「零件大小」切成一块块装甲，变身经过时整块沿表面方向甩出去、翻滚、下落、缩小消失
  （假面骑士 Kabuto 的 Cast Off）。用「弹开力度」调甩多远，飞行时长、旋转、碎片发光和碎片共用。
- **吸进胸针**：变身经过的地方，旧服装碎成碎片，绕着起点骨骼（默认是胸口的「上半身2」）转着圈收进去，
  像魔法少女的胸针把旧衣服吸走；粒子也跟着飞进去，胸针的位置一闪一闪地亮着一颗星。目标点跟着跳舞的身体走。
  碎片大小、细分、飞行时长、旋转、碎片发光和「碎片飞散」共用，另外「绕圈数」调转几圈（负数反着转）。
- **金蝉脱壳**（黑神话的「聚形散气」）：换装那一刻，整个旧模型（连脸和头发）原样留在原地，人穿着新衣服接着跳；
  空壳停一会儿，再碎掉或飘走。生成时会把动画播一遍，记下那一刻的姿态（和「留在原地」是同一套记录）。
  - **空壳样式**：蝉蜕空壳（琥珀色、半透明）、灵影（发光的半透明鬼影，颜色用发光颜色）、保持原样（和旧服装一样，表面效果也在）。
  - **之后**：碎散（从头顶往下一片片碎开、被风吹走）或飘走（整个往上飘、慢慢变淡，「灵魂出窍」）。
  - **空壳停留**、**空壳消散**：按整个变身时长的比例算。
  - 新服装在空壳留下的那一刻出现；模型不动的话空壳和人重在一起看不出来，要有舞蹈动作或整体移动。
  - **空壳姿势**（1.11）：原地不动（默认，定在那一刻的姿态）或在旁边跳舞——旧的自己从身边走出来接着跳，和新的自己并排
    （Lady Gaga《Abracadabra》；不用记录，跟着同一套动作）。**走出方向**：画面的右边或左边；**镜像**：跳成镜像，两个人面朝对方；
    **走出距离**：离多远。旁边的人要在画面里，镜头得广一点。
  - **变成手办**（「之后」的第三种，1.11）：空壳缩成七分之一高，跳到旁边一个透明亚克力底座上，一直留在那里
    （2025 年的 AI 手办风潮）；空壳样式选「手办光泽」，就是自己的颜色加一层亮光涂层，像上了漆的手办。

**退场时机**：

- **随边缘**（默认）：边界经过哪里，哪里就退场。
- **最后一起退场**：旧服装一直留到变身波走完再一起退场（收缩、碎开或弹开）。这期间旧服装表面的结霜、血管、烧焦照常跟着波走。
  「冰封碎裂」预设就是这样：整身冻住，再一起碎开。
  - 结霜（透明的冰）时，新服装在冰下面跟着波长出来，隐约看得见；
  - 表面是看不透的样式（血管、烧焦、水墨、石化、镀金、蚕丝茧、数字雨）时，新服装不跟着波长，而是在旧服装退场的那一刻出现，
    不会从外壳里透出来（新服装比旧服装鼓的地方会透出来）。「石化崩裂」「点金术」「破茧而出」就是这样。
- 新服装登场选了「鳞片翻转」时，旧服装跟着鳞片一起翻走，退场方式和退场时机都不起作用。

碎片的参数：

| 参数 | 作用 |
| --- | --- |
| 碎片大小 | 刚碎开时碎片相对原来面片的大小，调小缝隙更明显 |
| 碎片细分 | 把大面片再切碎，面数少的模型用（会变慢） |
| 飞行时长 | 碎片在空中停留多久，按整个变身时长的比例算 |
| 迸出 | 碎片沿表面弹出的距离 |
| 风力 / 风向 | 碎片被吹走的距离和方向（世界坐标；MMD 模型面朝 -Y，默认往上、稍微往后吹） |
| 湍流 | 碎片打旋的程度 |
| 旋转 | 碎片翻滚的角度 |
| 碎片发光 / 碎片发光强度 | 碎片刚碎开时发出发光颜色的光；关掉就是灭霸响指那种灰 |
| 光剪影 / 剪影范围 | 变身边界到来之前，旧服装先亮成一个发光的剪影（魔法少女变身的那种光），亮度用「碎片发光强度」 |

下面的**粒子**子面板可以让旧服装同时放出：

- **花瓣**、**蝴蝶**（蝴蝶各自扇翅膀，速度用「扇动速度」调）、**星光**（四角星），颜色和亮度用「粒子颜色 / 粒子发光」调；
- **方块**（发光的立方体，《创：战纪》的 derez）、**金币**（金属材质，颜色就是粒子颜色，金色要把粒子颜色调成金黄）、
  **冰片**（冰材质，和冰晶共用）、**余烬**（发光的小颗粒，把风向调成朝上它们就往上飘）；
- **音符**（立着朝向正前方、左右摇摆，跳舞时用）、**扑克牌**（正面白底红边、中间一个红方块，背面红色，随风翻滚）、
  **羽毛**（颜色跟粒子颜色：白色是天使，黑色是黑天鹅）、**蝙蝠**（扇翅膀，带暗红色的轮廓光，暗背景里也看得见）、
  **墨点**（水墨用，见第十二节）；扑克牌、蝙蝠、墨点有自己的颜色，不用粒子颜色；
- **代码字符**（数字雨用：发光的数字和镜像的半角片假名，立着朝前，边往下掉边换字，风向调成朝下）、
  **碎石**（石化崩裂用：不发光的小石块，颜色跟粒子颜色）、**纸鸟**（剪纸窗花用：红色的折纸鸟，像蝴蝶一样扇着翅膀飞走，
  有自己的颜色）；
- **自定义物体**：任意网格物体，每个粒子都是它的一个副本。
- **数量**是整件旧服装大约放出多少个粒子，**粒子飞行时长**同样按变身时长的比例算。
- 内置的形状在隐藏集合「MMD Disperse Particles」里，可以直接改它们的形状和材质。
- 粒子在「收缩消失」模式下也能用。

几点说明：

- 碎片和粒子要在结束帧之前飞完，所以生成时遮罩动画会按飞行时长多延长一段，**结束帧是最后一片碎片消失的时间**。
  生成之后改飞行时长、粒子或收尾闪光，遮罩的关键帧会自动跟着拉长或缩短（按比例改关键帧的值，手动调过的时间点不受影响）。
- 方向选「脱下（新→旧）」时，碎片会倒着飞回来，旧服装重新拼好。
- **留在原地**：碎片、装甲大块和粒子默认跟着身体一起动（不做物理模拟，拖时间轴随时正确），舞蹈动作大时，飞出去的碎片会跟着手臂一起甩。
  勾选主面板里的「留在原地」（在「缓动」下面）后，生成时插件会把变身这段动画播一遍，记下旧服装每个顶点被边界扫到那一刻的位置
  （属性 `disperse_launch`，前后两帧之间插值），碎片和粒子就从那里飞出，不再跟着身体走，拖时间轴仍然随时正确。
  新服装飞来的零件和收尾的星星也一样（见第七节、第九节）。
  - 测试模型（旧服装约 20 万个顶点，带刚体物理）记录 100 帧大约 8 秒，生成完成时的提示里会显示用时。
  - 改了舞蹈动作、帧范围或边缘噪波之后要重新生成；改飞行时长时插件会自动丢掉旧记录，碎片先恢复成跟着身体走，
    主面板会提示「需重新生成以记录动作」。
  - 「装甲弹开」的大块整块留下：每块在脱落那一刻整块定住再甩出去，不会因为块里各个顶点脱落的时间不同而被拉变形
    （按面角记录，属性 `disperse_chunk_launch`）。改了「零件大小」以后旧记录对不上，插件会自动丢掉，装甲先恢复成跟着身体走，重新生成即可。
  - 整个模型做移动、转圈的物体动画（给根物体打位置、旋转关键帧）时，碎片同样留在原地：位置按世界坐标记录，
    插件另外用一个隐藏的空物体「MMD Disperse Motion」记下录制时模型每一帧的位置。
    生成以后再把整个模型挪到别处（不改动画），碎片会跟着一起挪过去，不用重新生成。
  - 风向是世界里的方向：模型转身时风还是往同一边吹，碎片的打旋、装甲的下落也按世界的方向；花瓣、蝴蝶、星星的朝向同样按世界摆正，
    不会跟着模型一起转。

## 七、新服装登场：全息先行、零件飞入、前后夹合、残影汇聚、鳞片翻转、进化闪烁、烟雾、影子、传送光柱、瞬间换装、花苞、反应堆和装甲板

**全息先行**（「全息 / 纱」面板，标题栏的勾是开关）：新服装先在变身边界前方以全息投影出现——半透明、发光、带横向扫描线，
最前端有一圈亮的扫描光环；边界扫过以后才变成实体。配合「从下往上扫」就是 3D 打印 / 扫描仪的效果，建议关掉线框层。

| 参数 | 作用 |
| --- | --- |
| 纱的样式（1.11） | 全息：发光的扫描线；星空纱：深蓝底上满是星星的一层纱，像魔法少女的星空裙，之后才变成真的衣服；黑剪影：黑色的人形加一圈细亮边；冰晶：淡青色的冰，带霜纹 |
| 全息范围 | 全息投影比实体超前多远 |
| 全息不透明度 | 全息的浓淡（太浓会挡住下面的旧服装） |
| 全息亮度 | 扫描线、轮廓光和扫描光环的亮度；颜色用线框层的「发光颜色」 |

全息只在新服装的材质里加了一层混合（移除效果时会删掉）。Blender 3.6 的旧版 EEVEE 需要「混合模式：Alpha 哈希」才能透明，
插件会临时改，移除时改回去。

**零件飞入**（「新服装登场」面板选「零件飞入」）：新服装切成一块块零件（3D Voronoi 网格切分，切口跟着身体走），
每块在变身边界到来之前从远处带着旋转飞过来，越近越慢，到位时正好被边界扫过。飞行中的零件微微发光。

| 参数 | 作用 |
| --- | --- |
| 零件大小 | 每块零件的大小（和「装甲弹开」共用） |
| 飞来距离 | 零件从多远处飞来 |
| 提前起飞 | 零件在边界前方多远就开始飞，越大飞得越久 |
| 旋转 | 零件飞行时的翻转角度（和碎片共用） |

「零件飞入 + 装甲弹开」就是假面骑士式的换装：旧装甲崩飞，新装甲一块块装上。

勾了「留在原地」时，生成时会记下每块零件起飞那一刻的位置：零件从世界里一个固定的起点飞向身体上的落点（落点跟着身体动），
模型跳舞、转圈时飞行中的零件不会跟着身体甩；飞行中零件还保持起飞那一刻在世界里的形状和朝向，快落位时才转成身体当前的样子。改了「零件大小」或「提前起飞」，旧记录对不上，插件会自动丢掉，重新生成即可；
「细分」不为 0 时零件是从细分后的网格切出来的，和记录对不上，这时零件仍然跟着身体飞。

**前后两半夹合**（「新服装登场」面板选「前后两半夹合」，假面骑士 Build）：新服装从身体中间切成前后两半，
在身前、身后两个发光的框里从脚往上「打印」出来，然后滑进来夹合；夹合那一刻接缝亮一下，旧服装同时退场
（退场方式选「碎片飞散」就是旧服装一起炸开）。开着收尾闪光的话，闪光、星星和闪白也在这一刻。

| 参数 | 作用 |
| --- | --- |
| 夹合距离 | 两半在身前、身后多远处成形 |

- 时间分配：变身时长的前 30% 左右打印两半，然后滑进来，在 80% 处合上，剩下的时间给闪光和碎片。
- 框的颜色用线框层的「线框颜色 / 发光颜色」；夹合以后框就消失。打开全息先行的话，两半在合上之前是全息的。
- 两半在镜头正前方会互相挡住，侧面看最清楚：渲染时把镜头转到模型斜侧面（演示脚本用 `--angle -55`）。

**残影汇聚**（「新服装登场」面板选「残影汇聚」，假面骑士 Decade）：几个新服装的复制品站在身体两侧和后面（正前方留空，不挡脸），
从脚往上出现，一边转一边向身体收拢；碰到一起的那一刻新服装出现，旧服装退场。打开「全息先行」，复制品就是半透明的全息残影。

| 参数 | 作用 |
| --- | --- |
| 残影数量 | 几个复制品 |
| 残影距离 | 复制品离身体多远 |

**鳞片翻转**（「新服装登场」面板选「鳞片翻转」，魔形女）：两套服装都碎成一片片鳞片，边界经过时一片接一片翻过去，
每片鳞片翻过来的那一面就是新服装，像一副牌翻面：牌的正面是旧服装，背面是新服装。

| 参数 | 作用 |
| --- | --- |
| 鳞片大小 | 每片鳞片的大小 |
| 翻转宽度 | 一片鳞片翻完的时间里边界走多远：越大翻得越慢，同时在翻的鳞片越多 |

- 其实是两半拼成的：旧服装的鳞片从平躺翻到侧立就消失，新服装同一片鳞片从侧立翻到平躺。两套服装按同样的格子切鳞片、
  按同样的时刻翻，所以各自用自己的贴图，不需要两套服装的贴图对得上。
- 鳞片往前翻（后沿先抬起），翻的时候离开身体表面一点，侧立的那一刻闪一下发光颜色（跟着「边缘发光」的开关和强度）。
- 旧服装跟着鳞片一起翻走，「旧服装处理」里的退场方式和退场时机这时不起作用；粒子、旧服装表面、毒液照常可以叠加。
- 两套服装重叠的地方翻得最整齐；只有一套服装的地方（比如只有旧服装有裙子）就只看到半个翻转。
- 「魔形女鳞片」预设：从胸口沿体表流动，鳞片翻转，蓝色的光泽。

**进化闪烁**（「新服装登场」面板选「进化闪烁」，宝可梦的进化）：没有边界。整个人发出柔光，新旧两套服装交替出现，
越闪越快、越来越亮，最后变成一团纯光，新服装定住。刚开始光是柔的，看得出两套服装在交替；快结束时才变成纯白。颜色用「发光颜色」，亮度用「边缘发光强度」；脸、头发这些共用部分也一起发光。

**烟雾一闪**（选「烟雾一闪」，忍术的变身术）：没有边界。卡通白烟（一堆白色的球）从脚下冒起来，越积越高，把人整个盖住；
烟最浓的时候换衣服，然后往上飘、慢慢变透明散开。

| 参数 | 作用 |
| --- | --- |
| 烟团数量 | 这团烟大约由多少个球组成 |
| 烟团大小 | 每个球多大 |

**从影子里升起**（选「从影子里升起」，《雷霆特攻队*》）：没有边界。人从头开始沿灯光的方向倒下去，压扁成地上自己的黑影；
新服装再反过来，脚先立起，从影子里站起来。影子滑动的时候边缘发光（颜色用「发光颜色」）。

| 参数 | 作用 |
| --- | --- |
| 灯光方向 | 光照下来的方向（世界坐标，必须朝下），决定影子倒向哪边 |

**传送光柱**（选「传送光柱」，星际迷航）：没有边界。一道光柱罩住全身，里面的光点上下飘；旧服装一片片闪烁着消失，
新服装再一片片闪烁着出现，正要消失和刚出现的面发光（颜色用「发光颜色」，亮度用「边缘发光强度」）。
脸、头发这些共用部分也跟着消失，再和新服装一起出现。

| 参数 | 作用 |
| --- | --- |
| 光柱光点数量 | 光柱里上下飘的光点有多少（用粒子颜色、粒子大小） |
| 光柱亮度 | 光柱的亮度；颜色用「发光颜色」 |

- 时间分配：变身时长的前 8% 光柱亮起，到一半时旧服装消失完，新服装从 45% 开始出现，到「那一刻」（80%）出齐，光柱随后淡出。
- 光柱正对着看几乎是透明的，两侧发亮、带竖向流动的光纹；它按静止姿态量身体的大小，最宽不超过身高的四分之一（张开的手臂会伸出去）。

- 这四种（进化闪烁、烟雾一闪、从影子里升起、传送光柱）都按时间走：遮罩的大小只当进度条，旧服装在换衣服的那一刻退场
  （从影子里升起是完全躺平的那一刻）。路径和起点对它们不起作用，线框层自动不显示。
  缓动建议用「线性」（预设就是这样），闪烁和起落的节奏才均匀。
- 从影子里升起时所有材质（包括脸、头发）都注入了一个变黑的混合节点，换回别的登场方式或移除效果时去掉。

**瞬间换装**（选「瞬间换装」）：没有边界，到那一刻（变身时长的 80% 处）一下子全换。单用很突兀，配闪白、冲击帧（第十六节）
或者「转身背对镜头」（第十四节）最合适。

**花苞绽放**（选「花苞绽放」，哪吒 2 的七色宝莲）：没有边界。脚下长出内外两圈大花瓣，往里合拢成一个半透明、发光的花苞把人包住，
合着的时候随拍子轻轻起伏；人在花苞里一下子换装、亮一下，花苞再打开，花瓣往外平铺到地上，缩小消失。
「花瓣数」调每圈几片；花瓣颜色用「粒子颜色」，发光用边缘的「发光颜色」。花瓣在 Blender 4.2 以下用 Alpha 哈希透明。

**反应堆起手**（「新服装登场」面板里的勾，钢铁侠 Mark 50）：起点周围的一小块战衣一开始就在，像方舟反应堆一样脉动发光，
其余部分再从这里流出来。出发点选「起点 + 手脚」时，两只手、两只脚也各有一块。「反应堆大小」调这一块多大，颜色用「发光颜色」。

**装甲板鼓起**（同一面板里的勾）：边界后面，新服装按「装甲板大小」切成一块块装甲板，依次抬起、微微倾斜、闪一下光，
再落回原位，像 Mark 50 的装甲一片片锁上。

| 参数 | 作用 |
| --- | --- |
| 装甲板大小 | 每块板的大小 |
| 鼓起高度 | 板抬起多高（负数是往里陷） |
| 鼓起范围 | 一块板从抬起到落回的时间里边界走多远：越大起落得越慢，同时鼓起的板越多 |

- 只有正在起落的板才切开，落回原位以后不留切缝（切法和鳞片翻转一样）。
- 「钢铁侠 Mark 50」预设：胸口和手脚的反应堆先亮，深色内衬带着六边形线框流出，装甲板在后面鼓起、落位，最后一道光扫过全身、全屏闪白。

**深色内衬**（「深色内衬」面板，标题栏的勾是开关）：模仿钢铁侠 Mark 50，新服装先在边界处长成一层深色金属内衬，表面有一层发光的细网纹；
最终外观在后面「内衬宽度」处才出现，交界处有第二道发光接缝（跟着「边缘发光」的开关）。

| 参数 | 作用 |
| --- | --- |
| 内衬宽度 | 最终外观落后边界多远 |
| 内衬颜色 | 内衬的颜色 |
| 内衬纹路亮度 | 细网纹的亮度，颜色用线框层的「发光颜色」；0 就没有纹路 |
| 内衬样式 | 纳米金属，或者「共生体黏液」：湿的黑色黏液，颜色用毒液面板的「黏液颜色」，边界鼓起不规则的包（见第十节） |

- 最终外观要比边界多走一个内衬宽度才能铺满全身，遮罩会自动多长出这一段；收尾闪光和闪白等最终外观完整以后才开始。
- 零件飞入时，零件先以内衬的样子飞来，落位后再换成最终外观。
- 配合线框层和「沿体表流动」就是「纳米战衣收尾」预设的样子。

## 八、故障风

**故障风**：变身边界附近的一段里，身体被切成一条条水平切片，每条随机显示旧服装或新服装，并不停闪烁、横向错位、偶尔闪光。
越靠近已变身的一侧，显示新服装的切片越多。

| 参数 | 作用 |
| --- | --- |
| 故障范围 | 闪烁区域的宽度 |
| 切片高度 | 每条切片的高度 |
| 闪烁频率 | 每帧换几次（0.5 = 每两帧换一次） |
| 切片错位 | 切片横向跳动的距离 |
| 闪光 | 部分切片闪发光颜色（需要「添加辉光」才明显） |

- **添加色散**：在合成器里加一个镜头畸变节点，变身期间随机出现红绿蓝分离（色散）。它用驱动器跟着帧号变化，
  范围是主面板的开始帧到结束帧；改了帧范围再点一次即可。
- 同一位置的新旧服装用同一套随机数，所以一条切片里只会出现其中一件；同一帧每次渲染结果都一样，不会因为跳帧而变化。
- 故障风建议关掉线框层；和全息先行可以同时开。

故障风可以卡音乐节拍：切片每一拍重新洗牌，拍点上跳得多、闪得多，色散在拍点上冲高（见第十七节）。

## 九、魔法少女：光剪影、光带和收尾闪光

- **光剪影**（「旧服装处理」面板）：变身边界到来之前，旧服装先发光，整个人变成一团光的剪影，再换成新服装。
- **光带**（「光带」面板，标题栏的勾是开关）：每段手臂和腿（上臂、前臂、大腿、小腿）各有一条双股螺旋光带，
  变身经过这段肢体时从先变身的那一头开始缠上去，变身过去后变细消失。光带绑在骨骼上，跳舞时跟着肢体走。

| 参数 | 作用 |
| --- | --- |
| 光带圈数 | 每段肢体绕几圈 |
| 光带宽度 | 光带的宽度 |
| 光带停留 | 变身过去之后，光带再停留多远（按变身边界走过的距离算）才消失 |
| 光带亮度 | 发光强度；颜色用线框层的「发光颜色」 |

- 光带需要 MMD 标准骨骼（腕 / ひじ / 足 / ひざ，左右各一），找不到的骨骼会跳过。
- 光带是普通的曲线物体（名字以「MMD Disperse Ribbon」开头），移除效果或关掉光带时会删掉。

**收尾闪光**（「收尾闪光」面板，标题栏的勾是开关）：新服装完整出现的那一刻，整套服装闪一下发光颜色的光，
同时从全身迸出一圈星星，飞散、闪烁、缩小消失。**闪光方式**有两种：

- **整身闪光**：整套服装同时亮起再慢慢暗下去。
- **光扫**：一道光带从起点出发，沿变身走过的路线扫过全身（球形扩散就是从胸口往外，「只从手脚」就是从手脚往身体中间）；
  光带经过哪里，星星就从哪里迸出。光带用的是不带边缘噪波的距离，边是干净的。

| 参数 | 作用 |
| --- | --- |
| 闪光方式 | 整身闪光 / 光扫 |
| 闪光时长 | 闪光和星星持续多久，按整个变身时长的比例算；光扫在前 70% 的时间里扫完全身 |
| 闪光亮度 | 闪光（或光带）最亮时的发光强度；颜色用线框层的「发光颜色」 |
| 光扫宽度 | 光带的半宽（只在光扫时显示） |
| 星光数量 | 迸出多少颗星星，0 就只闪光不出星星 |
| 星光飞散距离 | 星星飞多远 |
| 粒子大小 / 粒子颜色 / 粒子发光 | 星星的大小、颜色和亮度，和旧服装的粒子共用 |
| 闪白强度 / 添加闪白 | 收尾开始时整个画面闪一下白（见下面） |

- 星星朝向正前方（MMD 模型和镜头一般沿 Y 轴相对），各自转一个随机角度并闪烁；模型转圈时也朝着世界的正前方。
- 勾了「留在原地」时，星星从出生那一刻身体所在的位置迸出（整身闪光是收尾开始时，光扫是光带经过时），
  不跟着身体走。改了闪光方式、闪光时长、光扫宽度或内衬宽度，出生的时刻变了，旧记录会自动丢掉，重新生成即可。
- 脸、头发等共用部分不参与闪光。
- **全屏闪白**：点面板最下面的「添加闪白」，插件在合成器里加一个混合节点，收尾开始时把整个画面混成白色，
  一帧左右亮到最高，再用六帧左右退掉（不管收尾多长，都按帧数算）。强度用「闪白强度」调（0 就是不闪）。
  - 混合系数用驱动器按遮罩大小算，所以改了时长、手动调了遮罩关键帧，闪白都会跟着走；重新生成后自动接到新的遮罩上。
  - 驱动器只用简单表达式，不装插件、不打开「自动运行 Python 脚本」也能渲染。
  - 要在视图里看到，把视图着色里的「合成器」设为「总是」；渲染时会自动生效。移除效果时节点会留着但不再闪。
- 「魔法少女」预设一次打开这些：只从手脚出发、光剪影、光带、碎片飞散 + 星光、收尾闪光、粉色发光。

## 十、毒液共生体

「毒液共生体」面板（标题栏的勾是开关），按电影里的分层做（调研见 docs/research.md「四、毒液」）：

1. **黑色血管**：在「旧服装表面」面板选「黑色血管」（见第十一节）。边界到来前，皮肤下先爬出黑色血管，越靠近越粗，最后整片变黑。
2. **触手**：黑色的触手从已经被黏液覆盖的地方伸出来，沿着变身方向爬到边界前面，有的会分叉，尖端抬起来摆动；
   黏液追上来以后把它们从根部吞回去。触手贴着旧服装的表面，模型跳舞时也紧贴着身体。
3. **黏丝**：腋下、两腿之间、裙子和腿之间这类面对面、离得近的地方，边界经过两头以后拉出黏丝；身体动起来时黏丝被拉长变细，
   中间往下坠，拉到三倍长就断。
4. **黏液外壳**：「深色内衬」面板选「共生体黏液」样式，新服装先是一层湿的黑色黏液，后面才是最终外观。

| 参数 | 作用 |
| --- | --- |
| 触手数量 | 大约长多少根触手（每根还可能分叉） |
| 触手长度 | 每根触手最长多长 |
| 触手粗细 | 触手的半径（黏丝更细） |
| 触手速度 | 触手比边界快几倍，越快跑得越靠前 |
| 触手间的蹼 | 触手分叉的地方，主干和分支之间铺一张黏液的蹼（《毒液3》的做法） |
| 黏丝数量 | 最多拉出多少根黏丝（找不到那么多面对面的地方就少一些） |
| 黏液颜色 | 触手、黏丝和黏液内衬的颜色 |
| 黏液金属感 | 把黏液换成液态金属：1 再配银色就是终结者 2 的 T-1000（血管、触手、黏丝、黏液内衬一起变） |

- 触手是生成时在静止姿态上「走」出来的：每一步沿变身的方向往前挪一点，再落到最外层的表面上，所以能跨过 PMX 拆开的几千个小块；
  每个点绑在所在三角形的三个顶点上，所以跟着骨骼变形。走线只需要几十毫秒，改了数量或长度会自动重新走。
- 有旧服装时触手爬在旧服装上；只有新服装时爬在新服装上（新服装还没长出来的地方，触手像在空中先勾出身体的轮廓）。
- 蹼是触手分叉处的一小片面，自由的那一边向里弯，像脚蹼；每个顶点和触手一样绑在身体上，跟着触手一起长出来、被吞回去。
- 黏丝除了在静止姿态里找，还会在变身期间动作的几帧里找（模型有动画时）：手臂贴着身体、两腿并拢的那一刻也能拉出黏丝，
  身体张开时它们被拉长、拉断。生成时插件会把这几帧过一遍（只算骨骼变形，很快），时间轴最后回到原来的帧。
  改了舞蹈动作要重新生成，或者改一下黏丝数量让它重新找。
- 「毒液共生体」预设：从胸口沿体表流动，黑色血管 + 触手 + 黏丝 + 黏液内衬，不发光。新服装是黑色紧身衣时最像毒液。
- 「液态金属」预设：同样的流程，但黏液是银色的液态金属（终结者 2 的 T-1000）。金属靠反射显得亮，场景里要有环境光（HDRI）或灯光；
  在全黑的环境里，镜面一样的金属也是黑的。

## 十一、旧服装表面：黑色血管、结霜、烧焦、水墨、石化、镀金、蚕丝茧、数字雨、剪纸窗花

「旧服装表面」面板决定边界到来之前旧服装先变成什么样：

| 样式 | 效果 |
| --- | --- |
| 无 | 不变 |
| 黑色血管 | 皮肤下爬出黑色血管，越靠近边界越粗、越密，最后整片变黑（毒液） |
| 结霜 | 一片片结霜，变成清透的冰面，上面长着羽毛状的白霜，少数晶面闪光；还能长出冰晶 |
| 烧焦 | 一片片烧黑，快到边界时裂纹发光（发光颜色），最后整片烧红 |
| 水墨 | 一片片洇成水墨画（按衣服本来的颜色换成浓淡不同的墨色），快到边界时整片被墨浸透；纸色和墨色在「线稿与水墨」面板（见第十二节） |
| 石化 | 一片片变成灰色、粗糙、带颗粒的石头，快到边界时裂开纹路，越近越宽（美杜莎） |
| 镀金 | 金子一片片漫过去，漫开的那条边像熔化的金子一样发亮，之后是抛光的金（点金术；颜色就是金色） |
| 蚕丝茧 | 白色的丝一片片裹上去，带丝光和细纤维纹，把旧服装往外鼓起一点；还可以有丝线缠住身体（见下面） |
| 数字雨 | 一列列发光的字符沿身体往下流（黑客帝国）；颜色用「发光颜色」 |
| 剪纸窗花 | 一块块变成纸（表面颜色：红色就是红纸），按身体正面排成方格，每格镂空出一朵八瓣窗花，镂空的地方透明（Blender 3.6 会临时改成 Alpha 哈希，移除时改回）；配粒子「纸鸟」 |

| 参数 | 作用 |
| --- | --- |
| 范围 | 边界前方多远开始变 |
| 颜色 | 血管 / 冰 / 焦黑 / 石头 / 金 / 丝的颜色 |
| 冰的透明度 | 结霜时白霜之间的冰有多透明：0 是乳白的冰，越大越像玻璃，能看到下面正在长出来的新服装 |
| 冰晶数量 / 冰晶大小 | 结霜时沿表面法线长出的冰晶（用粒子颜色），边界一到就碎掉；0 就没有冰晶 |
| 茧鼓起高度 | 蚕丝茧把旧服装往外鼓起多少（脸、头发这些共用部分不鼓） |
| 缠绕丝线 / 丝线圈数 | 蚕丝茧时，四股丝线（两两交叉）跟着丝缠住手臂、腿和身体，旧服装退场时断开；每段缠几圈（需要 MMD 标准骨骼） |

- 边界扫过以后飞出去的碎片、装甲块也带着这个样子：结霜后碎开的装甲块是冰块，烧焦后飞散的碎片是带火星的灰。
- 冰晶和冰片是透明的玻璃冰，会折射后面的东西。透明的冰需要 EEVEE 的折射：Blender 4.2 以上打开「光线追踪」，
  3.6 打开「屏幕空间反射」里的「折射」（「冰封碎裂」预设会自动打开）；材质里需要的设置插件会改好，移除时改回去。
- 「冰封碎裂」预设：从脚往上结霜、长冰晶，旧服装冻成透明的冰（下面的新服装隐约可见），整身冻住后一起碎开，
  冰块弹开，同时飞出冰片（退场时机是「最后一起退场」，见第六节）。
- 「燃烧成灰」预设：从手脚开始烧焦、裂纹发光，旧服装化成发光的灰烬，余烬往上飘，新服装在一圈火光后面出现。
- 丝线贴着身体的轮廓缠：插件把旧服装的表面点按最近的骨骼分到各段（手臂、腿、下半身、上半身、脖子），
  每段沿骨骼分 10 站、绕一圈分 12 个扇区，量出最外面一层，丝线在它外面一点绕。丝线是曲线物体（名字以「MMD Disperse Thread」开头），
  绑在骨骼上跟着跳舞；改了圈数或鼓起高度会重新缠。
- 数字雨的字按静止姿态的坐标排成列，跳舞时贴着身体；滚动用的帧号由几何节点存在网格上，不需要驱动器。
- 「石化崩裂」预设：石头从脚往上爬，整个人变成带裂纹的石像，再一起碎成大块和碎石往下掉，新服装站在那里。
- 「点金术」预设：金子从手脚漫开，整个人变成金像，再一起炸成金片和金币。
- 「破茧而出」预设：丝从脚往上裹，丝线缠住全身，鼓成蚕茧，然后裂开掉落、飞出蝴蝶，新服装闪光出现。

## 十二、线稿上色和水墨晕染

「线稿与水墨」面板的「画稿」决定新服装以什么样子出现：

| 画稿 | 效果 |
| --- | --- |
| 无 | 新服装直接以自己的颜色出现 |
| 线稿上色 | 边界前方，新服装先显示成纸上的线稿：纸色打底，颜色深的地方是漫画网点，外面一圈描边；边界后面颜色像水彩一样晕开，边上有一道颜色更深的水痕 |
| 水墨 | 新服装在边界处以水墨画出现（按自己的颜色换成浓淡不同的墨色），颜色在后面浮出来 |
| 数字雨 | 新服装在边界处是一列列往下流的发光字符，颜色在后面浮出来（颜色用「发光颜色」，没有描边） |

| 参数 | 作用 |
| --- | --- |
| 上色范围 | 边界后面多远颜色才完全铺满 |
| 线稿提前量 | 线稿在边界前方多远就开始显示（只有线稿上色） |
| 描边宽度 | 外面那圈描边的粗细，0 就没有描边 |
| 纸色 / 墨色 | 纸和墨的颜色；旧服装的「水墨」表面也用这两个颜色 |

- 描边是新服装外扩一点、翻过来的一层外壳，只画背面（材质开了背面剔除），所以从正面看是一圈线，不投阴影。
- 网点和水墨的晕染按静止姿态的坐标画，跳舞时贴着身体，不会在衣服上滑动。
- 画稿只在新服装的材质里加了一层混合（几何节点多存一个属性 `disperse_paint`），把画稿改回「无」或移除效果时删掉。
- 线稿上色建议关掉边缘发光，配「从下往上扫」：「线稿上色」预设就是这样。
- 「水墨晕染」预设：从胸口沿体表流动，旧服装先洇成水墨、碎成墨点飞散，新服装在后面以水墨出现、慢慢上色。
- 「数字雨」预设：从头往下，旧服装先流满字符，碎成发光的碎片和往下掉的代码字符，新服装先是字符、再浮出颜色。

## 十三、电弧闪电

「电弧闪电」面板（标题栏的勾是开关，雷神、沙赞）：变身边界上爬满跳动的电弧，每帧换一批。

| 参数 | 作用 |
| --- | --- |
| 电弧数量 | 边界横过身体时大约同时有多少条（边界长的时候多一些） |
| 电弧长度 | 每条电弧多长 |
| 电弧范围 | 边界两侧多远以内有电弧 |
| 电弧粗细 | 电弧的半径 |
| 电弧亮度 | 发光强度；颜色用线框层的「发光颜色」 |
| 开场落雷 | 变身开始的头几帧，一道闪电从头顶高处劈到起点上（带三条分叉、一闪一闪） |

- 电弧顺着边界的方向摆，中间拱出表面，折成锯齿；有新服装时爬在新服装上，只有旧服装时爬在旧服装上。
- 落雷时想让画面闪白：点面板里的「添加闪白」，强度用「闪白强度」（和收尾闪光共用同一个闪白节点）。
- 电弧和落雷都不投阴影；开着「卡音乐节拍」时，电弧在拍点上变粗变亮。
- 「雷霆变身」预设：落雷劈在胸口、全屏闪白，变身从胸口沿体表流开，边界上电弧乱窜，旧服装碎成发光的碎片，新服装完整时闪光。

## 十四、跟着舞蹈动作变

主面板的**开始时机**（「起点」下面）：变身不从开始帧开始，而是等舞蹈里的某个动作。抖音上很多变装视频就是这样卡的（拍手变装、飞吻变装、转身变装）。

1. 先给旧模型加载舞蹈动作（VMD），把开始帧设在想开始找的地方。
2. 开始时机选一个动作，点「生成变身效果」。插件把动作从开始帧播到场景的结束帧（只算骨骼，四百帧三四秒），
   找到第一个这样的动作，把整个变身挪过去（开始帧、结束帧跟着改），面板上显示「在第 N 帧找到」。
   找不到的话照原来的帧，面板提示「到场景结束帧都没找到」。舞蹈比场景长时，先把场景的结束帧设到舞蹈结尾
   （mmd_tools 导入动作时默认会这样设）。

| 开始时机 | 找什么 | 从哪里开始变 |
| --- | --- | --- |
| 拍手 | 两只手掌快速合拢（0.4 秒里合拢了身高的 10% 以上，最后靠到 6% 以内） | 两只手腕 |
| 飞吻 | 一只手的手指碰到嘴边（眼睛以下，另一只手不在脸旁），然后半秒内离开 | 这只手 |
| 敬礼 | 一只手的手指放在眉骨上、高过眼睛，停住一下（比耶贴在眼角也算） | 这只手 |
| 甩头 | 头相对身体快速点头或侧甩（每秒 350 度以上；水平转头不算） | 头 |
| 转身背对镜头 | 身体背对相机 | 一下子换装的那一刻（或者波纹走到一半）正好落在背得最彻底的那一帧 |
| 下蹲（1.11） | 臀部（「センター」骨骼）降到站着的高度以下身高的 12% | 蹲到最低的那一刻换装（Buss It 变装：蹲下去是旧衣服，站起来是新衣服） |
| 起跳（1.11） | 两只脚都离地超过身高的 3.5%，至少 0.1 秒 | 跳到最高的那一刻换装 |
| 落地（1.11） | 起跳后第一帧回到地面，或者一只脚踢到 25% 高、0.6 秒内落下 | 落地那一帧换装，配地面冲击波 |
| 落脚（1.11） | 一只脚先抬起 2%，再落回地面、停稳（开头站着不算） | 这只脚 |
| 举手向天（1.11） | 一只手腕高过头顶身高的 8% | 这只手 |
| 比心（1.11） | 单手：拇指尖和食指尖捏在一起（1.5% 以内），食指过了指根基本伸直，中指弯回掌心，手高过胸口，停住 0.2 秒；或者两只手食指尖碰食指尖、拇指尖碰拇指尖（双手比心） | 这只手 / 两只手 |
| 眨眼（1.11） | 表情动画里「ウィンク」「ウィンク右」这类眨眼表情超过 0.6（直接读曲线，不用播放） | 这只眼睛 |
| 拉绳（1.11） | 一只手掌贴在胸口或脖子前，0.3 秒内往外扯开身高的 18%，另一只手不在那里（电锯人拉绳） | 这只手 |

- 「从哪里开始变」用于球形扩散和沿体表流动；其他路径只挪时间。下蹲、起跳、落地和转身一样，挪的是关键时刻。
- 1.11 的阈值也在本机二十支舞上调过：比心要看手指，握拳、爪子、点赞、OK 手势时拇指尖和食指尖一样靠得很近，都不算；
  二十支舞里找到四个双手比心，逐个拍了手部特写，都是真的。眨眼要模型有眨眼表情、舞蹈带表情动画。
- 转身最好配「瞬间换装」这类一下子换好的登场方式（神奇女侠转一圈就换好），「转身变装」预设就是这样。
- 开着「卡音乐节拍」时，找到的帧吸到 0.3 秒内最近的拍点上。
- 很多动作开头是默认的 T 字或 A 字姿势，第一帧之后一下跳进舞姿；离开默认姿势后的一秒内不算（那一下看起来像双手猛地合拢）。
  想从开头附近找，把开始帧设在默认姿势之后。
- 嘴和眉的位置按眼睛骨骼推算（「目.L」「目.R」，没有就按「頭」骨骼估计）。
- 改了舞蹈动作、开始帧或开始时机要重新生成。
- 路径选「手扫过的地方」时，手扫到哪就先变哪（见第五节）。

## 十五、卡通火焰

「卡通火焰」面板（标题栏的勾是开关；女神异闻录 5 的蓝火、假面骑士响鬼、超级赛亚人）：不用烟雾火焰模拟，是动画式的火：

- 身体表面浮起一层「火壳」，材质里往上滚动的噪波按色阶切成几档颜色（硬边的动画火），里面亮、边上透明；
- 火壳上竖着一片片火舌，始终转向相机，各自闪动、高矮不一。

| 参数 | 作用 |
| --- | --- |
| 火焰范围 | 沿着边缘：火只在边界两侧的一条带子里烧；全身气焰：从变身开始烧起，到关键时刻（一下子换装，或新服装完整）最旺，之后熄掉 |
| 火焰颜色 / 火焰亮度 | 最外一档的颜色和发光强度（里面几档自动更亮、更白） |
| 火舌高度 | 火舌多高 |
| 火焰带宽度 | 沿着边缘时，边界两侧多远以内着火 |
| 火舌数量 | 整件服装着火时大约有多少片火舌 |

- 两套服装都会着火：旧服装在边界前面烧，新服装在边界后面烧。
- 火壳和火舌在 Blender 4.2 以下用 Alpha 哈希透明。
- 「蓝焰觉醒」「浴火重生」「金色气焰」三个预设用的就是它。

## 十六、冲击帧、集中线、地面冲击波和魂环

**冲击帧**（「冲击帧」面板，标题栏的勾是开关）：变身完成的那一刻（开始时机是拍手、飞吻、敬礼、甩头时，是变身开始的那一刻），
画面变成黑白，连续几帧，第一帧和第三帧反色，像动画里的冲击帧。

1. 勾上「冲击帧」，点面板里的「添加冲击帧」，合成器里会加三个节点（去色、压成黑白两色的 RGB 曲线、反色），用驱动器按帧开关。
   从哪一帧开始，在生成和改设置时按遮罩的关键帧算好；手动挪了遮罩的关键帧，改一下「帧数」就会重新对上。
2. **帧数**：黑白持续几帧（默认 3）。
3. **集中线**：镜头前挂一片网格，白色的集中线从画面四周往人物的胸口冲，每两帧换一批，冲击帧之后几帧淡出。
   要场景里有相机（挂在相机上，跟着相机走）。
4. **地面冲击波**：脚下一道光圈往外扩散，后面跟一圈淡的宽光环，还踢起一圈尘土；**冲击波范围**是扩到多远。

**魂环**（「魂环」面板，标题栏的勾是开关，斗罗大陆）：身体周围一个接一个升起光环，各自停在自己的高度（从膝盖到头顶以上），
绕着身体轻轻倾斜、上下浮动，开着「卡音乐节拍」时拍点上一亮；变身结束后淡出。

- **魂环数量**：1 到 9 个；颜色按魂环的年份：黄、黄、紫、紫、黑、黑、黑、红、红。
- **魂环亮度**：发光强度（黑色的魂环只有边上发光）。
- 「魂环」预设：七个魂环，变身从胸口沿体表流开。

## 十七、卡音乐节拍

「音乐节拍」面板（标题栏的勾就是「卡音乐节拍」）：

1. 在「音乐」里选一个音乐文件（默认从场景的开始帧开始播放）；留空的话，用视频序列编辑器里的第一条音频（按它的起始帧对齐）。
2. 点「找节拍」（音符按钮）。插件会读出音乐，找出鼓点（低音加权），报告找到多少拍、大约每分钟多少拍，并自动勾上「卡音乐节拍」。
3. 之后这些效果都跟着鼓点走：
   - 故障风：切片每一拍重新洗一次牌，拍点上跳得多、闪得多；「添加色散」的红绿蓝分离也在拍点上冲高。
   - 线框层在拍点上变粗、变亮，新服装的边缘发光也亮一下。
   - 碎片在拍点上变亮，粒子和收尾的星星在拍点上变大。
   - 收尾闪光：开始的时刻推到下一拍，之后每一拍再闪一次（越往后越弱）；光扫在拍点上更亮。全屏闪白跟着收尾一起落在拍点上。
   - 前后两半夹合、残影汇合、冻住后一起碎开这些「关键时刻」也推到下一拍。最多等 2 秒，等不到就照原来的时间。
- 拍子太少就把「灵敏度」调高，太碎（把半拍也算进来）就调低，再点一次「找节拍」。
- 节拍存在一个隐藏的空物体「MMD Disperse Beat」的关键帧里（X 位置是节拍脉冲，Y 位置是拍数），节点和合成器直接读它，
  不装插件也能渲染。重新生成变身效果不影响它；换歌就再找一次。
- 「卡点变身」预设：线框、故障风、碎片和星光、收尾闪光和闪白一起打开，并勾上「卡音乐节拍」（先找节拍才有效果）。
- 渲染出来的画面不带声音，用剪辑软件或 ffmpeg 把这首歌从第 1 帧对齐合进去。

## 十八、领域展开

「领域展开」面板（标题栏的勾是开关；咒术回战的领域展开）：变身时从舞者身上撑开另一个世界。
开始时它只是人身后的一扇圆窗，透过窗看得到新世界；等它长过相机，整个画面都换成新世界；关键时刻之后停一会儿，再碎掉或收回。

| 参数 | 作用 |
| --- | --- |
| 世界 | 星空虚空 / 赤红荒原 / 花海 / 天空之镜 / 演唱会（见下表） |
| 展开用时 | 从开始到撑满用多久，占到关键时刻为止这段时间的多少 |
| 停留时长 | 关键时刻之后停多久（按变身时长的比例） |
| 之后 | 碎裂：碎成方块飞走，地面往回收；收回：原路缩回人身上 |
| 道具数量 | 光晶、剑、花、羽毛有多少（演唱会固定十道光束） |

| 世界 | 天空 | 地面 | 道具 |
| --- | --- | --- | --- |
| 星空虚空 | 星云、银河、闪烁的星星 | 暗色镜面，映着星星 | 漂浮的光晶 |
| 赤红荒原 | 红天、黑色的太阳和黑云（星穹铁道的白厄） | 发光的裂缝 | 从地里升起的剑 |
| 花海 | 粉色的天空和云 | 遍地的花 | 花，飘落的花瓣 |
| 天空之镜 | 蓝天白云 | 会起涟漪的水面 | 飘落的白羽毛 |
| 演唱会 | 黑色大厅，四周挥舞的荧光棒 | 黑色舞台，脚下一圈光 | 身后十道扫动的光束，头顶的追光 |

- 世界是一个单独的物体（名字以「MMD Disperse World」开头）：一个法线朝里的球加一块跟着长大的地面圆盘，用背面剔除做成「窗」。
- 生成时会看场景相机在变身期间走到哪，球就开到相机外面去；改了相机要重新生成。没有场景相机时按身高的三倍开。
- 道具总是放在人的身后，不会挡在相机和人之间。世界自己发光，不投影，也不受场景灯光影响。
- 镜头很窄（比如 85mm 竖屏）时，窗只在开头几帧看得见，很快就撑满画面；用广一点的镜头（50mm）看得更清楚。
- 「领域展开」「赤红荒原」「花海」「天空之镜」「演唱会」五个预设各用一个世界。

## 十九、镜头与时间、卡通物理

「镜头与时间」面板。

**镜头运动**：勾上后，关键时刻（一下子换装，或者新服装完整）镜头动一下：

| 运镜 | 效果 |
| --- | --- |
| 甩镜头 | 镜头猛地甩开、画面拖出残影，再甩回来，衣服就在模糊里换好（短视频的甩镜转场）；摆幅按画面宽度算 |
| 旋转 | 画面绕中心转开再转回来 |
| 冲焦 | 一下子推近，往外拖出残影，再退回 |
| 推拉变焦 | 镜头往后退、同时拉长焦，人大小不变、背景被拉远（希区柯克变焦），再回来 |
| 环绕 | 镜头绕着人转（「环绕角度」，一整圈回到原处）；配「定格」就是子弹时间 |
| 终结技分镜 | 像游戏放大招时的快切：先是从前下方仰拍、慢慢推近，再切到双眼特写（相机挂在头骨上，跟着头走），换装那一刻切到高处斜侧的远景，最后切回场景相机；三段的长短按「运镜时长」分配，仰拍和远景跟着人走 |

- **运镜时长**：推拉变焦、环绕和终结技分镜用多久（秒）。
- 插件加的相机用「子级」约束骑在场景相机上；时间线上加几个标记（名字以「MMD Disperse Shot」开头），只在运镜那几帧切到它，
  之后切回场景相机，场景相机自己的动画不动。环绕用另一个相机，绕着人中心的空物体转。
- 甩、转、冲的时候，合成器里的方向模糊（自动加，名字「MMD Disperse Camera Blur」）拖出残影。
- 需要场景相机。关掉或移除效果时，相机、标记和模糊都删掉，场景相机回到原样。

**时间**：

| 时间 | 效果 |
| --- | --- |
| 原样 | 不变 |
| 定格 | 关键时刻前后舞蹈停住，头发、裙子悬在空中，变身照常进行，之后接上音乐（子弹时间） |
| 慢放 | 舞蹈慢到四分之一，之后加速追回 |
| 一拍二 | 关键时刻前后每个姿势停两帧，像定格动画 |

- **变速时长**：停住、慢放或一拍二持续多久（秒）。
- 做法：两套模型的动作（骨架和表情）放进 NLA 片段，给片段的时间打关键帧；刚体世界（头发、裙子的物理）的速度也打关键帧，
  停住时是 0.0001。移除效果（或者把时间改回「原样」）后，动作放回原处，刚体速度还原。

**卡通物理**：

| 卡通物理 | 效果 |
| --- | --- |
| 压扁回弹 | 关键时刻身体像被从上面压扁（体积不变，横向变胖），最扁的那一刻换装，再弹回来、晃几下（Pika 的 Squish） |
| 纸片翻面 | 身体压成一张正对相机的纸，翻过去，另一面是新衣服，再鼓回来（纸片马力欧） |
| 卡牌翻面 | 同样翻面，身后跟着一张紫底金框、中间有星星的魔法卡一起翻（塔罗牌、集换卡） |

- 三种都要配「瞬间换装」这类一下子换好的登场方式（面板会提示），以人脚下的中心为轴。
- **浮空**：变身过程中人浮起来、上下飘，关键时刻落地；**浮空高度**是身高的几成。做法是给旧模型骨架的「增量位置」加一个驱动器
  （新服装跟着旧骨架），移除时删掉。

## 二十、舞蹈绸带与步步生莲

「舞蹈绸带与步步生莲」面板。

**舞蹈绸带**：变身前后，手上拖着绸带跟着舞步飞。生成时把舞播一遍（每帧两次），记下指尖在哪；绸带显示最近零点几秒手走过的路，
所以和舞蹈完全对得上，任意一帧都能直接看。

| 绸带样式 | 效果 |
| --- | --- |
| 光带 | 细细的光，像长曝光拍的荧光棒；颜色用发光颜色，芯是白的，往尾巴渐暗 |
| 水袖 | 白色的丝，半透明、边上密一点，往下垂、随风飘（戏曲的水袖） |
| 混天绫 | 红绸金边（哪吒） |
| 花瓣 | 手走过的路上撒下花瓣，越往后越小、往下落 |

| 参数 | 作用 |
| --- | --- |
| 脚也拖尾 | 脚尖也拖一条 |
| 绸带长度 | 显示最近多少秒走过的路 |
| 绸带宽度 | 丝在手上有多宽（从中线到边）；光带细得多 |
| 绸带亮度 | 光带的亮度（丝也会微微发光） |

- 绸带从变身开始前 0.4 秒出现，变身结束后 1 秒内淡出。要有舞蹈动作，手不动绸带就只是垂着的一截。
- 绸带是生成时记下的位置，之后挪动模型绸带不会跟着走，要重新生成。
- 路径选「手扫过的地方」时，水袖和混天绫扫过的范围再加上绸带的宽度：绸带扫到哪，哪里就变。

**步步生莲**：变身期间每次落脚，脚下开一朵莲花、荡开一圈波纹，过一会儿合上消失；「脚下」也可以选「光印」，
亮起一个两圈光环围着五角星的光印。落脚是从同一遍播放里找出来的：脚先抬起来，再落回地面、停稳才算。
莲花的颜色是粒子颜色，边上用发光颜色，和「花苞绽放」共用材质。

## 二十一、画面风格

「画面风格」面板：关键时刻前后一段时间，整个画面换一种样子（在合成器里做）：

| 画面风格 | 效果 |
| --- | --- |
| 逆光剪影 | 人变成黑色剪影、带一圈白边，衬在一种纯色上（「背景色」，默认红色）；换装就在剪影里完成（魔法少女动画） |
| 去色留色 | 画面变成黑白，只留下舞者的颜色（星穹铁道的黄泉；卡点时用） |

## 二十三、渲染

1. 点线框层面板里的 **添加辉光**，线框、边缘、碎片、全息和光带才会真正发光。
   - Blender 4.2 及以上：在合成器里加 Glare 节点。想在视图里也看到辉光，把视图着色里的「合成器」设为「总是」。
   - Blender 3.6：直接打开 EEVEE 的泛光（Bloom）。
2. 想要收尾时全屏闪白，在「收尾闪光」面板点 **添加闪白**（见第九节）。卡节拍的视频渲染完再把音乐合进去（见第十七节）。
   透明的冰要打开 EEVEE 的折射（见第十一节）。左右扫描的光环从正面看只是一条线，镜头放到斜侧面（见第五节）。
3. `F12` 渲染单帧，`Ctrl + F12` 渲染动画。
4. 效果只由几何节点、关键帧、材质和合成器节点组成，保存后的 .blend 发给别人，对方不装插件也能渲染。

## 二十四、其他

- **移除**：点「生成变身效果」右边的垃圾桶按钮，模型、材质（发光、全息、背面发光、内衬、表面效果、画稿、影子）、骨骼绑定和跟随约束、
  到达时间和脱落位置属性、记录模型运动的空物体、毒液的触手骨架、光环、粒子和冰晶形状、光带和丝线全部还原或删除。
  节拍空物体留着，下次生成还能用。
  合成器里的辉光、色散和闪白节点会留着（闪白不再闪），不需要的话在合成器里手动删掉。
- **反向变身**：方向选「脱下（新→旧）」。
- **只有新服装**：旧服装留空，新服装会从无到有地「长」出来。
- **只有旧服装**：新服装留空。配合「碎片飞散」，就是整个人化成灰飞走（灭霸响指）。
- **卡顿**：线框层最耗性能，调动画时先关掉，渲染前再打开。碎片、零件、装甲模式下每帧大约多花 1 秒。
- **新服装多出几根骨骼**（裙摆、飘带等）：网格没法直接绑到旧骨架上，插件改为让新服装骨架里两边都有的骨骼复制旧骨架的姿态，
  多出来的骨骼跟着父骨骼走，效果和给两个模型加载同一个动作一样。移除效果时这些约束会删掉。
- **两个模型骨骼名不一样**：插件会提示不跟随旧骨架，这时给两个模型加载同一个 VMD 动作即可。
- **跳舞**：先给旧模型加载 VMD，再生成。变身波纹、光剪影、光带都贴着身体走；碎片、零件、星星想留在原地就勾「留在原地」（见第六节）。
- **整个人移动、转圈**：给旧模型的根物体打位置或旋转关键帧。新服装的根物体用「复制变换」约束跟着旧模型走
  （约束名 `MMD Disperse Follow`，移除效果时删掉）；勾了「留在原地」的话，碎片留在空中，转圈时会甩出一圈螺旋。
  球形扩散的球心（遮罩）用「子级」约束跟着模型走，人走开、转身时变身范围始终贴在身体上；风向、碎片打旋和粒子朝向按世界方向算。
