# 毒液变身使用手册（mmd_disperse 1.31.1）

用 mmd_disperse 给 MMD 模型做一段「毒液」（共生体）变身：皮下血管先跟着心跳搏动，黏液从手脚往上爬，触手盘着四肢，
头最后被盖住，白眼睁开、咧嘴露獠牙，张大嘴吐出长舌头仰头咆哮（上下牙之间拉着黏液丝，1.31），后背长出粗触手，
面罩从中间裂开露出她的脸再合上，最后整个人留在毒液的样子里——或者黏液「啪」地一下缩回胸口（边缘鼓起一道脊往里卷，1.31），
她又是自己（1.29）。
本手册按 Blender 3.6 的界面写，4.x 一样；括号里是英文界面的名字。

目录：一、准备 ／ 二、物理 ／ 三、新服装 ／ 四、插件面板 ／ 五、把亮点拍出来 ／ 六、渲染 ／ 七、常见问题 ／
八、几个毒液预设的区别 ／ 九、原理 ／ 十、命令行

---

## 一、准备

1. **装插件**：编辑 › 偏好设置 › 插件 › 安装（Edit › Preferences › Add-ons › Install），选
   `dist/mmd_disperse-1.31.1-legacy.zip`（Blender 3.6 用这个；1.31 起只在 3.6 上测试），勾选启用。
   3D 视图按 N 打开侧栏，会多一个 **MMD 变身**（MMD Disperse）页签。装的插件多时侧栏页签一列放不下，「MMD 变身」会被挤到
   看不见的地方：鼠标放在页签那一列上滚滚轮（或 Ctrl+滚轮）把它翻出来。侧栏窄时标签会被截断（「旧服…」），把侧栏拉宽一点。
2. **装 mmd_tools**：导入 PMX、导入舞蹈、构建物理都靠它。
3. **模型要求**：MMD 骨架（センター、頭 等标准骨骼名）；要睁眼、咧嘴、裂面罩，还得有眼睛骨骼 `目.L`、`目.R`。
   没有眼睛骨骼时其他效果照常，只是脸上不会出现眼睛和牙。
4. **导入模型**：mmd_tools › 导入模型（Import Model），或者直接打开做好的 .blend。
5. **导入舞蹈**：选中模型的骨架，N 侧栏「MMD」页签 › 操作项面板 › **运动: 导入**（Motion: Import），选 VMD。
   模型是 MMD 单位（二十来个单位高）时缩放填 1；mmd_tools 按 0.08 导入的小模型填 0.08。
6. **摄像机**：Shift+A › 摄像机，选中它按 Ctrl+小键盘 0 设为场景摄像机；N 侧栏 › 视图里勾上「锁定摄像机到视图方位」，
   转动视图到能看到她全身，再取消勾选。推镜头要用这台场景摄像机。

## 二、物理（最容易漏的一步）

导入的 PMX 自带刚体，但**刚体不会自动带动骨骼**，头发、裙子只会跟着骨骼僵着动。要做三件事（要做第二份模型当新服装的，
只构建原来那份；用第三节的复制按钮的话构建前后都行，手动复制的话**先复制再构建**）：

1. **构建**：选中模型的根物体（名字和模型同名的空物体），N 侧栏「MMD」页签 › 操作项面板 › **物理: 建立**
   （英文界面是 Operator › Physics: Build；Blender 4.x 的 mmd_tools 在 Model Setup 面板，按钮叫 Physics）。
   构建完骨架上会多出 `mmd_tools_rigid_track` 约束，刚体开始带动骨骼。
2. **重力**：属性编辑器 › 场景（Scene）› 重力（Gravity）：Z 填 **−98.1**。
   Blender 默认的 9.81 是按米算的，MMD 模型二十多个单位高，默认重力下头发会往上飘；mmd_tools 自己的公式就是 −9.81 × 10 × 缩放。
   小模型（0.08 导入）就填 −7.85。
3. **烘焙**（**生成变身效果之后**再做：预设里的慢放会改舞蹈的时间和刚体的速度）：属性编辑器 › 场景 › 刚体世界环境
   （Rigid Body World）› 缓存：「模拟起始帧」改成舞蹈的第一帧，结束帧盖过要渲染的最后一帧，点 **烘焙**（Bake）。
   烘焙过以后拖到任何帧都是对的；不烘焙就必须从第一帧连着往后播，中间跳帧物理就不对。
   之后改了开始帧、结束帧或慢放，先「删除烘焙」再重新烘焙。

长飘带、长裙摆要是跳舞时乱甩（她站着不动时很安静、一跳就甩），是被腿和裙子的刚体不停顶出来的。Blender 4.x 的
mmd_tools：点完构建后，左下角「调整上一步操作」里把 **Non-Collision Distance Scale** 从 1.5 改成 5，就安静了。
Blender 3.6 的 mmd_tools 构建时没有这个参数，飘带会甩得厉害一些（演示是用 4.5 渲染的）。

## 三、新服装

插件的变身是「旧服装 → 新服装」。毒液有两种玩法：

| 玩法 | 新服装用什么 | 结果 |
| --- | --- | --- |
| **她变成毒液** | 同一个模型再导入一份 | 黏液盖满后留在身上（预设「毒液·经典变身」） |
| **换成一身黑衣** | 另一个穿黑色紧身衣的同骨架模型 | 黏液盖满后变成那身衣服（预设「毒液共生体」） |

**一键复制**（1.31）：先在主面板填好「旧服装」，点「新服装」一栏右边的**复制按钮**（两个方块的图标，在吸管右边）。
插件把旧服装的模型复制一份填进「新服装」：网格、骨架、材质都是新的一份（黏液不会同时画到两份上），刚体和关节不复制
——新服装跟着原模型的骨架和物理动，「跟随旧模型骨架」自动勾上。构建物理之前、之后都能点；旧服装上还带着生成的效果时，
它会提示先点「移除」。

手动复制也行（**在构建物理之前**）：

1. 编辑 › 偏好设置 › 编辑 › 物体 › 复制数据（Duplicate Data）：把**材质**勾上（网格、骨架默认已勾）。
   不勾的话两份共用材质，黏液会同时画到两份上。
2. 大纲视图里右键模型的根物体 › 选择层级（Select Hierarchy）。
3. 鼠标移到 3D 视图，Shift+D，马上点右键（原地复制，不挪动）。复制出来的那份名字带 `.001`。

也可以用 mmd_tools 把同一个 PMX 再导入一次（不要构建它的物理）。「文件 › 追加」不能从当前打开的文件里追加；
要追加就先「另存副本」，从副本里追加。第二份不用构建物理，它会跟着原模型的骨架走。

## 四、插件面板（N 面板 › MMD 变身）

### 4.1 主面板

| 项 | 填什么 |
| --- | --- |
| 旧服装（Old Outfit） | 原模型的根物体 |
| 新服装（New Outfit） | 第二份模型的根物体（或黑衣模型）；同一个模型就点右边的复制按钮（1.31） |
| 跟随旧模型骨架 | 勾上（默认） |
| 开始帧 / 结束帧（3.6 中文界面显示「起始」「结束点」） | 舞里想变身的那一段，比如 130～250；100 帧左右的变身最像电影 |
| 预设 | 选 **毒液·经典变身**（或 **毒液·一下缩回**；165 个预设里不好找，1.30 起毒液面板顶上有这两个的快捷按钮），下面的面板会一次填好。1.31 起先选预设、后选模型也行：按身高算的尺寸在生成时按模型身高重算（1.30 以前要先选好模型再选预设） |
| 旧服装处理 › 保留共用部分、材质 | 勾上「保留共用部分」，「材质」一栏只留头发和头饰，比如 `*hair*;*Hair*;*Leaf*;*Headgear*`。1.31 起选毒液预设时会自动把 face、eye、mouth 这些去掉（默认那串里有，会把脸锁住），头发等留着；黏液盖不到脸就不会睁眼、咧嘴、吐舌 |

填完点 **生成变身效果**（Build Transformation）。女武神这种十万顶点的模型在 3.6 上要等两分钟左右（大部分时间在走触手的线、
给惯性甩动播一遍舞蹈）。生成后改面板上的大多数参数会实时同步；改触手数量、长度、盘绕比例会自动重新走线；
改了舞蹈动作要再点一次生成。

### 4.3 时间轴上发生什么

以开始帧 S、结束帧 E 为例（前沿从手脚出发走到头大约用 70% 的时间）：

| 时刻 | 发生 |
| --- | --- |
| S 之前 1.5 秒 | 前奏：手脚皮下的血管开始跟着心跳跳，越来越快、越来越粗 |
| S | 黏液从手脚开始漫，触手跑在前面 |
| 中段 | 触手盘上手臂和腿，腋下、腿间拉黏丝，黏丝断开滴落 |
| 前沿到脸 | 黏液盖住脸（镜头从前半秒开始推近） |
| +3～7 帧 | 睁眼 ＝ 关键时刻：冲击帧闪三帧，舞蹈慢放 |
| +8～13 帧 | 咧嘴；胸口肩膀变宽 |
| 黏液盖住后背 | 后背长出粗触手，往上往外甩 |
| 咧嘴后 0.25 秒 | 咆哮 1.4 秒：上下牙分开（中间拉着黏液丝，张开途中断掉几根）、舌头垂下来晃、脖子后仰 |
| 咆哮后 0.15 秒 | 面罩从鼻梁裂开，露脸 1 秒，再合上 |
| 之后 | 留在毒液的样子（或黏液层过去后变成新服装） |
| 睁眼后 4.5 秒（一下缩回） | 不到半秒黏液从手脚、头往胸口缩回（边缘鼓起一道脊跟着往里卷），后背触手先抽回，变宽收回 |

开着「变身也一起慢」时，上表里睁眼之后的时刻在画面上都再晚约 0.6 秒（慢放落下的那段，之后不追）。

## 五、把亮点拍出来

毒液最出彩的是脸，全身远景里看不清。「毒液·经典变身」预设（1.28 起）已经一键带上下面 1、2 两条；想自己调：

1. **推近**：「镜头与时间」面板 › 「关键时刻在」选「前沿到脸」，「镜头运动」勾上、运镜选「推近看脸」，运镜时长就是
   停在脸上多久（2.8 秒从睁眼到面罩合上）。想换别的运镜也行，都会落在睁眼那一帧。面板上的「关键时刻：第 N 帧」就是睁眼
   那一帧；要是显示「前沿到不了脸」，回去检查「旧服装处理 › 材质」里有没有 face、eye。
2. **慢放加冲击帧**：同一面板 › 时间选「慢放」，变速时长 1.2 秒，舞蹈在睁眼前后慢到四分之一；「冲击帧」面板勾上，3 帧，
   睁眼那一拍去色闪一下，集中线冲向脸；地面冲击波关掉（镜头在脸上看不到）。合成器里没有冲击帧节点时点一下「添加冲击帧」。
3. **灯光**：黏液全靠反射和油光。暗背景 + 一盏侧逆光（太阳光，从背后 45° 斜打，强度 2 左右）最出效果；
   液态金属要有环境光（HDRI），全黑环境里镜面金属也是黑的。
4. **卡节拍**：主面板点「找节拍」，打开「卡音乐节拍」，关键时刻会落到拍点上。

## 六、渲染

1. 渲染引擎 EEVEE；「MMD 变身」› 「线框层」子面板最下面点 **添加辉光**（3.6 打开泛光，4.2 以上在合成器里加 Glare）。
2. 输出 1080×1920（竖屏）或 1920×1080，帧范围就是舞的那一段，物理记得烘焙到最后一帧。
3. 生成一次大概几秒到半分钟（女武神这种十万顶点的模型要半分钟，大部分时间在走触手的线）。

## 七、常见问题

| 现象 | 原因 | 办法 |
| --- | --- | --- |
| 头发、裙子跟着骨骼僵着动 | 物理没构建 | 第二节第 1 步 |
| 头发往上飘、裙子轻飘飘 | 重力还是 9.81 | 重力 Z 改 −98.1 |
| 拖时间轴物理乱跳 | 没烘焙 | 刚体世界 › Bake |
| 长飘带乱甩 | 被腿、裙子的刚体顶 | Non-Collision Distance Scale 改 5 再构建 |
| 脸没被盖住、没有眼睛 | 「旧服装处理 › 材质」里锁着 face、eye（默认那串就有） | 只留头发、头饰的名字（1.31 起选毒液预设时自动去掉；选完预设又手动加回去的要再删） |
| 盖住了但没眼睛 | 模型没有 目.L / 目.R 骨骼 | 只能没有眼睛和牙 |
| 黏液过去后她变回原来的衣服 | 「黏液留在身上」没开 | 毒液共生体面板里勾上 |
| 第二份模型跟着一起变成了旧服装 | 两份共用材质 | 用新服装旁边的复制按钮（1.31）；手动复制时勾「复制数据」的材质，或重新追加 |
| 点复制按钮提示先移除效果 | 旧服装上还带着生成的效果 | 主面板点「移除」，再复制、再生成 |
| 找不到「MMD 变身」页签 | 侧栏页签太多，被挤出去了 | 鼠标放在页签那一列上滚滚轮（或 Ctrl+滚轮） |
| 触手没有、面板提示没有刚体 | 新服装里没有可爬的网格 | 检查新服装选对了根物体 |
| 眼睛一闪就没 | 内衬宽度太窄 | 内衬宽度调到 0.3 身高以上 |
| 面板说「前沿到不了脸」，镜头落在换装时刻 | 脸被锁定，或没有眼睛骨骼 | 锁定里删掉 Face*、Eye*；没有眼睛骨骼的模型只能用换装时刻 |
| 推近时脸不在画面里 | 场景没有相机，或相机自己有标记切换 | 设一台场景相机；运镜用随行相机，标记会自动切 |
| 液态金属全黑 | 没有环境光 | 加 HDRI 或灯 |
| 没有舌头、头不后仰 | 没有头骨骼或眼睛骨骼，或没开共生体之眼 | 咆哮要眼睛骨骼（目.L/目.R）和头骨骼 |
| 后背触手少了几根 | 那几处射线没找到朝后的表面（披风、背包挡着） | 少一两根正常；全没有就是没有胸骨、脖子骨骼 |
| 缩回后看不出变化 | 新服装本身就是黑色紧身衣 | 用颜色差别大的新服装（或同一模型的第二份） |

## 八、几个毒液预设的区别

| 预设 | 从哪开始 | 脸 | 结尾 | 适合 |
| --- | --- | --- | --- | --- |
| 毒液共生体 | 胸口 | 睁眼、咧嘴 | 黏液过去，变成新衣服 | 换装 |
| 毒液·从手开始 | 手脚 | 睁眼、咧嘴 | 变成新衣服 | 换装，电影式开场 |
| 毒液·甩头变脸 | 甩头那一下从头开始 | 先出黏液脸 | 变成新衣服 | 短视频的甩头变身（要有甩头动作） |
| 毒液·经典变身 | 手脚（前奏血管） | 睁眼、咧嘴、咆哮吐舌、面罩裂开再合上；后背触手、变壮；镜头推近看脸、慢放、冲击帧 | 黏液留在身上 | 她变成毒液（新服装用同一模型第二份） |
| 毒液·一下缩回 | 同上 | 同上 | 黏液一下缩回胸口，她又是自己 | 完整的电影片段 |
| 液态金属 | 胸口 | 无 | 变成新衣服 | T-1000 |

## 九、原理（想改细节时看）

- **血管**：几何节点给旧衣服每个顶点写「离前沿还有多远」，材质按它画 Voronoi 格子的边线，越近越粗，乘一个随帧跳动的正弦就是搏动。
- **触手**：生成时在静止姿态上「走」出来——每步沿变身方向挪一点，再向下打射线落到最外层表面，所以能跨过 PMX 拆开的几千个小块；
  每个点记住它在哪个三角形和重心坐标，几何节点每帧用「按索引采样」取变形后的顶点重建，跳舞时也贴着身体。
  盘绕只是让走线每步多转一个固定角度，在肢体上就是螺旋。鼓包是半径乘一个沿触手长度跑的正弦。
- **黏丝**：找面对面、离得近的两处表面，两端各绑一个三角形；拉长变细，拉到三倍断开，断开时实例化一颗小球往下落。
- **黏液壳**：几何节点在新衣服上写「黏液层」属性（前沿后面一段为 1），材质用它把黏液着色器混进来；
  「留在身上」就是混合系数取 max(属性, 1)。
- **脸**：在同一个黏液着色器里，按静止坐标到两只眼睛中心的距离画两个倾斜的杏仁（眼）、眼线下一个眼距处画一条锯齿带（牙）、
  沿脸中线画一条竖带（裂口）；三个强度各挂一个按帧的驱动器，时刻从脸那块网格的到达时间算出来。
- **黏液质感**：四维噪波（第四维接帧号）让湿干斑块蠕动；Voronoi 到边距离做皮下脉管，每格自己的相位搏动；
  Layer Weight 的 Facing 过色带做油膜虹彩。
- **关键时刻在脸、推近看脸**（1.28）：脸的时刻 = 新服装顶点「到达」属性在两眼中心附近的中位数换成帧，再加睁眼的那几帧；
  运镜、慢放、冲击帧都从这一个函数取时刻。推近是场景相机上挂的一台随行相机：焦距 = 场景相机 × 系数，系数和一个指向头骨骼的
  「阻尼跟踪」约束的影响度一起打关键帧，推近时转向脸、拉回时回到原构图；时间轴标记负责切相机。
- **前奏**（1.29）：旧服装节点组里「前方区域」原来随前沿半径从 0 长起；前奏期间按帧把它推满，再乘一个心跳包络（重拍加轻拍，越来越快）。
- **后背触手**（1.29）：骨架里的第 3 类链，每个点都绑在后背的同一个三角形上；节点组从根往「向外 + 向上 + 向两侧」伸出，
  两组沿长度跑的正弦让它甩，按长度平方往下坠。
- **咆哮**（1.29）：张嘴、牙分两行画在黏液着色器里；舌头是挂在头骨上的一个几何节点物体（每帧从一条线长出来，越往尖越朝
  世界向下垂）；仰头是脖子骨骼上叠加的一个旋转约束，舞蹈动作不动。
- **一下缩回**（1.29）：黏液外壳的材质里有一个以胸骨为中心、按帧缩小到 0 的球，球外的黏液消失；触手按同样的时间缩短。
  1.31：新服装的几何节点按同一个球在它的边缘里面沿法线鼓起一道脊；黏液着色器的坐标按帧往胸口中心拉，纹路就往里流。
- **拉丝**（1.31）：和舌头一样挂在头骨上的一个几何节点物体，顶点是每根丝的上下两半；按脸上张嘴的同一个时间算两排牙之间的
  距离，每半根从自己那排牙往中间排开，越长越细；到了自己断开的那一帧，两半在 0.18 秒里各自缩回牙上（上半截末端变成一滴）。
- **一键复制**（1.31）：模型的每个物体、网格、骨架、材质都复制一份，指向原模型的父级、修改器、约束改指复制品；刚体、关节和装
  它们的空物体不复制。
- **变身也一起慢**（1.30）：变身有一条自己的时间曲线：慢放窗口里四分之一速度并经过关键时刻那一帧，窗口前稍快补上，窗口后
  一直落后。变身半径、几何节点、脸上和仰头的驱动器都按这条曲线走，所以推镜、冲击帧不用挪。
- **惯性甩动**（1.30）：生成时把骨架按舞蹈播一遍，一根阻尼弹簧跟着舌根和后背，把落后量逐帧打成关键帧；不是实时模拟，
  拖时间轴到哪一帧都一样。改了舞蹈要再点一次生成。

## 十、命令行（批量渲染用）

`demo/render_hd.py` 会自动构建物理、设重力、从舞蹈第一帧预滚模拟：

```
blender -b "inase_a08_g05.blend" --python demo/render_hd.py -- ^
  --base-root "Pc A08 Hd Full 穿G05衣服 V2" --target-blend "inase_a08_g05.blend" --target-root "Pc A08 Hd Full 穿G05衣服 V2" ^
  --preset VENOM_SNAP --vmd "回レ！雪月花.vmd" --wave 130:250 --view 1.15 ^
  --set "lock_patterns=*hair*;*Hair*;*Leaf*;*Headgear*" --physics-reach 5 ^
  --out frames --anim 80:372
```

`--target-blend` 和打开的文件相同时自动复制一份当新服装；`--physics-reach 5` 就是第二节说的非碰撞距离。
