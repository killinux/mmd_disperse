# 毒液变身使用手册（mmd_disperse 1.28）

用 mmd_disperse 给 MMD 模型做一段「毒液」（共生体）变身：皮下血管先搏动，黏液从手脚往上爬，触手盘着四肢，
头最后被盖住，白眼睁开、咧嘴露獠牙，面罩从中间裂开露出她的脸再合上，最后整个人留在毒液的样子里。
本手册按 Blender 3.6 的界面写，4.x 一样；括号里是英文界面的名字。

目录：一、准备 ／ 二、物理 ／ 三、新服装 ／ 四、插件面板 ／ 五、把亮点拍出来 ／ 六、渲染 ／ 七、常见问题 ／
八、三个毒液预设的区别 ／ 九、原理 ／ 十、命令行

---

## 一、准备

1. **装插件**：编辑 › 偏好设置 › 插件 › 安装（Edit › Preferences › Add-ons › Install），选
   `dist/mmd_disperse-1.28.0-legacy.zip`（3.6～4.1 用这个；4.2 以上用 `mmd_disperse-1.28.0.zip`），勾选启用。
   3D 视图按 N 打开侧栏，会多一个 **MMD 变身**（MMD Disperse）页签。
2. **装 mmd_tools**：导入 PMX、导入舞蹈、构建物理都靠它。
3. **模型要求**：MMD 骨架（センター、頭 等标准骨骼名）；要睁眼、咧嘴、裂面罩，还得有眼睛骨骼 `目.L`、`目.R`。
   没有眼睛骨骼时其他效果照常，只是脸上不会出现眼睛和牙。
4. **导入模型**：mmd_tools › 导入模型（Import Model），或者直接打开做好的 .blend。
5. **导入舞蹈**：选中模型的骨架，mmd_tools › 导入动作（Import Motion）选 VMD。
   模型是 MMD 单位（二十来个单位高）时缩放填 1；mmd_tools 按 0.08 导入的小模型填 0.08。

## 二、物理（最容易漏的一步）

导入的 PMX 自带刚体，但**刚体不会自动带动骨骼**，头发、裙子只会跟着骨骼僵着动。要做三件事：

1. **构建**：选中模型的根物体（名字和模型同名的空物体），mmd_tools 面板 › Physics › **Build**。
   构建完骨架上会多出 `mmd_tools_rigid_track` 约束，刚体开始带动骨骼。
2. **重力**：属性编辑器 › 场景（Scene）› 重力（Gravity）：Z 填 **−98.1**。
   Blender 默认的 9.81 是按米算的，MMD 模型二十多个单位高，默认重力下头发会往上飘；mmd_tools 自己的公式就是 −9.81 × 10 × 缩放。
   小模型（0.08 导入）就填 −7.85。
3. **烘焙**：属性编辑器 › 场景 › 刚体世界（Rigid Body World）› 缓存（Cache）：
   起点改成舞蹈的第一帧，终点盖过要渲染的最后一帧，点 **Bake**。
   烘焙过以后拖到任何帧都是对的；不烘焙就必须从第一帧连着往后播，中间跳帧物理就不对。

长飘带、长裙摆要是跳舞时乱甩（她站着不动时很安静、一跳就甩），是被腿和裙子的刚体不停顶出来的：
Build 按钮旁边的 **Non-Collision Distance Scale** 从 1.5 改成 5 再构建一次，就安静了。

## 三、新服装

插件的变身是「旧服装 → 新服装」。毒液有两种玩法：

| 玩法 | 新服装用什么 | 结果 |
| --- | --- | --- |
| **她变成毒液** | 同一个模型再导入一份 | 黏液盖满后留在身上（预设「毒液·经典变身」） |
| **换成一身黑衣** | 另一个穿黑色紧身衣的同骨架模型 | 黏液盖满后变成那身衣服（预设「毒液共生体」） |

再导入一份的办法：文件 › 追加（File › Append），选同一个 .blend 里模型的整个集合（Collection）；
或者在大纲里选中模型根物体，右键 › 选择层级（Select Hierarchy），Shift+D 复制——
复制前把偏好设置 › 编辑 › 复制数据（Duplicate Data）里的网格、材质勾上，两份才不共用材质。
第二份不用再构建物理，它的骨骼会跟着原模型的骨架走。

## 四、插件面板（N 面板 › MMD 变身）

### 4.1 主面板

| 项 | 填什么 |
| --- | --- |
| 旧服装（Old Outfit） | 原模型的根物体 |
| 新服装（New Outfit） | 第二份模型的根物体（或黑衣模型） |
| 跟随旧模型骨架 | 勾上（默认） |
| 开始帧 / 结束帧 | 舞里想变身的那一段，比如 130～250；100 帧左右的变身最像电影 |
| 预设 | 选 **毒液·经典变身**，下面的面板会一次填好 |
| 锁定部件（Lock） | 默认锁着 `Face*;Hair*;Eye*…`。**把 Face\* 和 Eye\* 删掉**，只留头发和头饰，比如 `*hair*;*Hair*;*Leaf*;*Headgear*`。黏液盖不到脸就不会睁眼 |

填完点 **生成**（Build）。生成后改面板上的大多数参数会实时同步；改触手数量、长度、盘绕比例会自动重新走线；
改了舞蹈动作要再点一次生成。

### 4.2 预设填进去的东西（想微调看这里）

**路径（Path）面板**

| 项 | 预设值 | 作用 |
| --- | --- | --- |
| 路径 | 沿体表流动 | 黏液顺着身体表面漫 |
| 出发点 | 只从手脚 | 电影里手先变、头最后；改「只从起点」就从胸口开始 |

**旧服装表面（Old Outfit Surface）面板**

| 项 | 预设值 | 作用 |
| --- | --- | --- |
| 样式 | 黑色血管 | 前沿前方皮下爬出黑血管，越近越粗、会搏动，最后整片变黑 |
| 范围 | 0.18 身高 | 血管在前沿前方多远开始 |

**毒液共生体（Symbiote）面板**

| 项 | 预设值 | 作用 |
| --- | --- | --- |
| 触手数量 | 240 | 大约多少根触手（每根还会分叉） |
| 触手长度 / 粗细 | 自动按身高 | |
| 触手速度 | 3 | 比前沿快几倍，越快跑得越靠前 |
| 盘绕的触手 | 0.45 | 多大比例像螺丝一样盘着四肢和身体绕上去 |
| 触须 | 开 | 每根触手尖端分出两根又短又细的触须 |
| 触手间的蹼 | 开 | 分叉处铺一张黏液蹼 |
| 黏丝数量 | 90 | 腋下、两腿之间、裙和腿之间拉出的黏丝 |
| 黏液滴落 | 开 | 黏丝绷断时甩下一滴 |
| 黏液颜色 / 金属感 | 黑 / 0 | 银色 + 金属感 1 就是液态金属 |
| 油光虹彩 | 0.6 | 转开的面上一层深蓝、紫、青的油膜 |
| 黏液脉动 | 1 | 触手里的鼓包往尖端泵、尖端甩动、黏液外壳皮下的脉管搏动；0 就静止 |
| 共生体之眼 | 开 | 黏液盖住脸时睁开两只白眼睛（按眼睛骨骼定位） |
| 咧嘴獠牙 | 开 | 睁眼后几帧咧开一排白牙 |
| 面罩中分露脸 | 开 | 面罩从鼻梁裂开露出她的脸，再合上 |
| 盖住后几秒裂开 | 1.2 | 从黏液盖住眼睛算起 |
| 露脸停留 | 1.0 | 开多久合上；0 一直开着 |

**深色内衬（Dark Undersuit）面板**

| 项 | 预设值 | 作用 |
| --- | --- | --- |
| 内衬 | 开，样式 **共生体黏液** | 新服装先是一层湿黑黏液 |
| 内衬宽度 | 0.3 身高 | 黏液层在前沿后面拖多长 |
| 黏液留在身上 | 开（经典变身）/ 关（毒液共生体） | 开着她就留在毒液的样子里，关了黏液过去后变成新服装 |

**镜头与时间（Camera and Time）面板**（1.28，经典变身预设带上的）

| 项 | 预设值 | 作用 |
| --- | --- | --- |
| 关键时刻在 | 前沿到脸 | 下面的运镜、慢放、冲击帧都落在黏液盖住脸、睁眼那一帧；面板显示「关键时刻：第 N 帧」 |
| 镜头运动 / 运镜 | 开，推近看脸 | 睁眼前半秒推到头占画面三分之一，跟着头，停「运镜时长」秒再拉回 |
| 运镜时长 | 2.8 秒 | 从睁眼停到面罩合上（1.2 + 1 秒再加开合） |
| 时间 | 慢放，1.2 秒 | 舞蹈在睁眼前后慢到四分之一，之后加速追上音乐；黏液本身不慢 |
| 冲击帧（自己的面板） | 开，3 帧，速度线开，冲击波关 | 睁眼那一拍去色闪三帧，速度线冲向脸 |

### 4.3 时间轴上发生什么

以开始帧 S、结束帧 E 为例（前沿从手脚出发走到头大约用 70% 的时间）：

| 时刻 | 发生 |
| --- | --- |
| S 之前 0.18 身高的距离 | 血管开始爬 |
| S | 黏液从手脚开始漫，触手跑在前面 |
| 中段 | 触手盘上手臂和腿，腋下、腿间拉黏丝，黏丝断开滴落 |
| 前沿到脸 | 黏液盖住脸（镜头从前半秒开始推近） |
| +3～7 帧 | 睁眼 ＝ 关键时刻：冲击帧闪三帧，舞蹈慢放 |
| +8～13 帧 | 咧嘴 |
| +1.2 秒 | 面罩从鼻梁裂开，露脸 1 秒，再合上 |
| 之后 | 留在毒液的样子（或黏液层过去后变成新服装） |

## 五、把亮点拍出来

毒液最出彩的是脸，全身远景里看不清。「毒液·经典变身」预设（1.28 起）已经一键带上下面 1、2 两条；想自己调：

1. **推近**：「镜头与时间」面板 › 「关键时刻在」选「前沿到脸」，「镜头运动」勾上、运镜选「推近看脸」，运镜时长就是
   停在脸上多久（2.8 秒从睁眼到面罩合上）。想换别的运镜也行，都会落在睁眼那一帧。面板上的「关键时刻：第 N 帧」就是睁眼
   那一帧；要是显示「前沿到不了脸」，回去检查锁定部件里有没有 Face*、Eye*。
2. **慢放加冲击帧**：同一面板 › 时间选「慢放」，变速时长 1.2 秒，舞蹈在睁眼前后慢到四分之一；「冲击帧」面板勾上，3 帧，
   睁眼那一拍去色闪一下，速度线冲向脸；地面冲击波关掉（镜头在脸上看不到）。合成器里没有冲击帧节点时点一下「添加冲击帧」。
3. **灯光**：黏液全靠反射和油光。暗背景 + 一盏侧逆光（太阳光，从背后 45° 斜打，强度 2 左右）最出效果；
   液态金属要有环境光（HDRI），全黑环境里镜面金属也是黑的。
4. **卡节拍**：主面板点「找节拍」，打开「卡音乐节拍」，关键时刻会落到拍点上。

## 六、渲染

1. 渲染引擎 EEVEE；主面板点 **一键 Bloom**（4.2 以上会在合成器里加 Glare）。
2. 输出 1080×1920（竖屏）或 1920×1080，帧范围就是舞的那一段，物理记得烘焙到最后一帧。
3. 生成一次大概几秒到半分钟（女武神这种十万顶点的模型要半分钟，大部分时间在走触手的线）。

## 七、常见问题

| 现象 | 原因 | 办法 |
| --- | --- | --- |
| 头发、裙子跟着骨骼僵着动 | 物理没构建 | 第二节第 1 步 |
| 头发往上飘、裙子轻飘飘 | 重力还是 9.81 | 重力 Z 改 −98.1 |
| 拖时间轴物理乱跳 | 没烘焙 | 刚体世界 › Bake |
| 长飘带乱甩 | 被腿、裙子的刚体顶 | Non-Collision Distance Scale 改 5 再构建 |
| 脸没被盖住、没有眼睛 | 锁定部件里锁着 Face*/Eye* | 把它们从锁定里删掉 |
| 盖住了但没眼睛 | 模型没有 目.L / 目.R 骨骼 | 只能没有眼睛和牙 |
| 黏液过去后她变回原来的衣服 | 「黏液留在身上」没开 | 深色内衬面板勾上 |
| 第二份模型跟着一起变成了旧服装 | 两份共用材质 | 复制时勾「复制数据」的材质，或重新追加 |
| 触手没有、面板提示没有刚体 | 新服装里没有可爬的网格 | 检查新服装选对了根物体 |
| 眼睛一闪就没 | 内衬宽度太窄 | 内衬宽度调到 0.3 身高以上 |
| 面板说「前沿到不了脸」，镜头落在换装时刻 | 脸被锁定，或没有眼睛骨骼 | 锁定里删掉 Face*、Eye*；没有眼睛骨骼的模型只能用换装时刻 |
| 推近时脸不在画面里 | 场景没有相机，或相机自己有标记切换 | 设一台场景相机；运镜用随行相机，标记会自动切 |
| 液态金属全黑 | 没有环境光 | 加 HDRI 或灯 |

## 八、三个毒液预设的区别

| 预设 | 从哪开始 | 脸 | 结尾 | 适合 |
| --- | --- | --- | --- | --- |
| 毒液共生体 | 胸口 | 睁眼、咧嘴 | 黏液过去，变成新衣服 | 换装 |
| 毒液·从手开始 | 手脚 | 睁眼、咧嘴 | 变成新衣服 | 换装，电影式开场 |
| 毒液·甩头变脸 | 甩头那一下从头开始 | 先出黏液脸 | 变成新衣服 | 短视频的甩头变身（要有甩头动作） |
| 毒液·经典变身 | 手脚 | 睁眼、咧嘴、面罩裂开再合上；镜头推近看脸、慢放、冲击帧 | 黏液留在身上 | 她变成毒液（新服装用同一模型第二份） |
| 液态金属 | 胸口 | 无 | 变成新衣服 | T-1000 |

## 九、原理（想改细节时看）

- **血管**：几何节点给旧衣服每个顶点写「离前沿还有多远」，材质按它画 Voronoi 格子的边线，越近越粗，乘一个随帧跳动的正弦就是搏动。
- **触手**：生成时在静止姿态上「走」出来——每步沿变身方向挪一点，再向下打射线落到最外层表面，所以能跨过 PMX 拆开的几千个小块；
  每个点记住它在哪个三角形和重心坐标，几何节点每帧用「按索引采样」取变形后的顶点重建，跳舞时也贴着身体。
  盘绕只是让走线每步多转一个固定角度，在肢体上就是螺旋。鼓包是半径乘一个沿触手长度跑的正弦。
- **黏丝**：找面对面、离得近的两处表面，两端各绑一个三角形；拉长变细，拉到三倍断开，断开时实例化一颗小球往下落。
- **黏液壳**：几何节点在新衣服上写「黏液层」属性（前沿后面一段为 1），材质用它把黏液着色器混进来；
  「留在身上」就是混合系数取 max(属性, 1)。
- **脸**：在同一个黏液着色器里，按静止坐标到两只眼睛中心的距离画两个倾斜的杏仁（眼）、眼线下一个眼距处画一条锯齿带（牙）、
  沿脸中线画一条竖带（裂口）；三个强度各挂一个按帧的驱动器，时刻从脸那块网格的到达时间算出来。
- **黏液质感**：四维噪波（第四维接帧号）让湿干斑块蠕动；Voronoi 到边距离做皮下脉管，每格自己的相位搏动；
  Layer Weight 的 Facing 过色带做油膜虹彩。
- **关键时刻在脸、推近看脸**（1.28）：脸的时刻 = 新服装顶点「到达」属性在两眼中心附近的中位数换成帧，再加睁眼的那几帧；
  运镜、慢放、冲击帧都从这一个函数取时刻。推近是场景相机上挂的一台随行相机：焦距 = 场景相机 × 系数，系数和一个指向头骨骼的
  「阻尼跟踪」约束的影响度一起打关键帧，推近时转向脸、拉回时回到原构图；时间轴标记负责切相机。

## 十、命令行（批量渲染用）

`demo/render_hd.py` 会自动构建物理、设重力、从舞蹈第一帧预滚模拟：

```
blender -b "inase_a08_g05.blend" --python demo/render_hd.py -- ^
  --base-root "Pc A08 Hd Full 穿G05衣服 V2" --target-blend "inase_a08_g05.blend" --target-root "Pc A08 Hd Full 穿G05衣服 V2" ^
  --preset VENOM_CLASSIC --vmd "回レ！雪月花.vmd" --wave 130:250 --view 1.15 ^
  --set "lock_patterns=*hair*;*Hair*;*Leaf*;*Headgear*" --physics-reach 5 ^
  --out frames --anim 100:330
```

`--target-blend` 和打开的文件相同时自动复制一份当新服装；`--physics-reach 5` 就是第二节说的非碰撞距离。
